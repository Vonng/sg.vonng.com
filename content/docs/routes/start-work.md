正在找工作，先用[求职篇](/book/work/career/job-search/)选择渠道、核雇主与中介，准备履历和面试。已经拿到或正在比较机会，用[录用与入职](/book/work/career/offer/)核真实雇主、固定工资、福利、附件及前置条件，再查[身份与资格](/book/life/documents/status-and-eligibility/)的本人工作权限。

1. 需要工作准证，按[工作准证](/book/life/documents/work-passes/)对照类别、行业、年龄及固定月薪，向雇主取到申请安排。获IPA后，再按[MOM签发与领卡](/book/life/documents/pass-management/)核开始工作前的手续。
2. 家属或学生身份想工作，先走身份页对应分支，核对签发机构、学校和授权。
3. 按[开户与工资账户](/book/work/finance/banking/)准备收薪安排；公民或PR另核[CPF缴纳](/book/work/finance/cpf-basics/)，尤其刚取得PR、兼有自雇收入或从事平台工作的情况。
4. 向雇主要医疗福利和保单，使用[医疗支付](/book/people/healthcare/healthcare-payments/)核对哪些费用要自行承担。
5. 用[公共交通](/book/life/transport/public-transport/)试走通勤，在[多语沟通](/book/people/language/everyday-language/)中准备汇报、确认时间和询问的表达。

准证状态或申报资料不符时，从准证页的MOM查询与更正入口处理，再安排开始工作的日期。

签约前结合[劳动权益](/book/work/employment/employment-rights/)核适用保障；有个人保证、电子签署或一般付款责任，另用[签约前检查](/book/rights/contracts/before-signing/)。报到、试用或开工前需要延期、撤回时，回录用篇按实际阶段处理；保留完整合同和双方书面决定。
