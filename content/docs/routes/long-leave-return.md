先列出每位成员的护照、国籍、准证、预计离境与返新日期，再分别处理身份、学校工作和日常合约。把出发前要交的申请与境外等待的结果放在同一张时间表，保存通知、批准及可在境外使用的联系方法。

1. 用[出入境准备](/book/rights/outdoors/travel-borders/)核本人证件、准证及返新条件；PR接[REP与身份](/book/life/documents/permanent-residence/)，有NS义务的成员接[NS家庭事项](/docs/routes/ns-family/)核年龄、服役阶段、许可和担保。
2. 离职、换雇主或结束工作，用[离职事项](/docs/routes/leaving-job/)衔接工资、准证及家属；MOM和ICA准证分别接[准证管理](/book/life/documents/pass-management/)与[ICA证件](/book/life/documents/arrival-renewal/)，按本人的申请、续期或取消路线办理。
3. 海外工作、收入或居住变化，用[跨境税务](/book/work/tax/cross-border/)和[离境税清](/book/work/tax/leaving-singapore/)核税务居民、报税与雇主手续；银行账户及付款安排接[银行服务](/book/work/finance/banking/)。
4. 孩子海外就读或准备返校，用[学校生活](/book/people/school/school-life/)核原校联系与衔接；高等教育的学费补助、服务及延期接[Tuition Grant](/book/people/learning/tuition-grant/)。每位学生的居留、学习和NS安排分别办理。
5. 搬走、退房或保留住处，用[租约与退房](/book/life/housing/tenancy/)和[合同履行](/book/rights/contracts/performance/)安排通知、交还、付款及后续联系；有房产或出租收入，接[房产税与租金](/book/work/tax/property-tax/)处理地址和用途变化。
6. 家人需要照护，用[照护事项](/docs/routes/caregiving/)落实接替、记录和授权；带药、宠物及其他物品，用[跨境携带品](/book/rights/outdoors/travel-borders/)核主管批准、检疫、税务与返程准备。
7. 返回前再次核本人当前准证或REP、护照及入境申报，并按[跨境往返事项](/docs/routes/cross-border-trip/)安排交通。丢证、网上操作失败或本人无法办理时，从出入境正文的对应机构、线下与授权分支求助。
