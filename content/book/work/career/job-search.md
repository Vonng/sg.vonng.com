找工作先做两件事：确认自己可做什么工作、何时能合法开工，再把目标职位和能证明的经验写清。随后选择渠道、核招聘方、递交材料并准备面试；每次申请留一条记录，便于跟进和调整。公民、PR与各类准证的工作条件不同；外籍求职者收到offer后，还要完成相应工作权限的申请、签发或通知。[ICA：PR工作与职业注册](https://ask.gov.sg/ica/questions/clxwhkiyj00fkdsotb37zlufh)、[MOM：工作准证与申请状态查询](https://www.mom.gov.sg/eservices/services/check-work-pass-and-application-status)

## 先确认自己可以怎样工作

准备当前准证名称、签发机构、到期日、国籍及拟做的工作。向招聘方说明需要哪种工作授权，把最早入职日与旧工作的通知期、学校安排及获准停留期限放在同一张时间表上。准证类别和薪资、行业、配额等完整判断在[工作准证]({{< relref "/book/life/documents/work-passes" >}})，家属与学生身份选路在[身份与资格]({{< relref "/book/life/documents/status-and-eligibility" >}})。

| 当前身份 | 与求职和开工直接有关的条件 |
| --- | --- |
| 公民、PR | 不需要外籍工作准证；受监管职业仍须符合执业注册等条件。准备履历时写清当前身份，未成年者及有国民服役安排者另外核入职时间和工作限制。[ICA：PR就业](https://ask.gov.sg/ica/questions/clxwhkiyj00fkdsotb37zlufh) |
| EP | 换雇主由新雇主申请新EP；申请前无需先取消现有EP，新申请按当期条件评估。谈清旧工作结束、新证签发和新工作开始日期。[MOM：EP换工作](https://www.mom.gov.sg/faq/employment-pass/what-if-i-want-to-change-jobs-while-i-am-on-an-ep) |
| S Pass、行业Work Permit（WP） | S Pass同一时间只能为一个雇主工作；WP只能为准证指定雇主、职业和行业工作。WP转雇的原雇主同意、申请窗口及新证签发按行业和来源地判断；有无需原雇主同意的限定路径，不因有人愿意聘用就直接换公司开工。[S Pass](https://www.mom.gov.sg/faq/s-pass/can-an-s-pass-holder-work-for-more-than-one-employer-at-the-same-time)、[WP条件](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-worker/sector-specific-rules/work-permit-conditions)、[制造与服务业转雇示例](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-worker/sector-specific-rules/hiring-an-existing-manufacturing-or-services-worker) |
| 家政移工（MDW） | 为指定雇主在申报住宅做家务，不能为其他雇主兼工或到商店帮工。替雇主照护其子女或父母而在亲属家工作，须事先通知MOM、取得MDW书面同意，不承担两家全部家务；如留宿还须满足住宿条件。找新雇主按家政转雇程序，具体步骤和双方责任见[雇用家政移工]({{< relref "/book/people/family/domestic-workers" >}})。[MOM：家政工作规则及亲属家照护条件](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/employers-guide/employment-rules) |
| Student’s Pass | 学期内须是MOM名单院校的全日制在读学生并持有效学生准证；每周最多16小时，或参加学校安排、计入毕业要求的实习。假期同样须全日制在读、持有效准证，按假期院校名单核资格且年满14岁。交换生不适用这项学生工作豁免；毕业且学生准证到期后须取得工作准证再工作。[MOM：两份名单和完整条件](https://www.mom.gov.sg/passes-and-permits/work-pass-exemption-for-foreign-students) |
| 普通MOM Dependant’s Pass（DP） | 雇主可申请EP、S Pass或DP-Work Permit；DP-WP受配额和外劳税条件约束，有效期依托DP。现有DP-WP换雇主须先由旧雇主取消，才能提交新申请。ONE Pass配偶的专门LOC路径另看下文。[MOM：DP工作](https://www.mom.gov.sg/passes-and-permits/dependants-pass/working-in-singapore) |
| MOM Long-Term Visit Pass（LTVP） | 本地offer后，由雇主申请符合条件的EP、S Pass或WP。先看签发机构，不能凭同名准证使用ICA家属的LOC路径。[MOM：MOM LTVP工作](https://www.mom.gov.sg/passes-and-permits/long-term-visit-pass/working-in-singapore-for-ltvp-holders) |
| ICA LTVP／LTVP+的公民或PR配偶，或未满21岁未婚子女 | 可核Letter of Consent（LOC，同意书）或Pre-approved Letter of Consent（PLOC，预先批准同意书）资格。LOC须有本地offer及至少还有三个月有效的居留准证，雇主收到LOC后才能开工；持PLOC者须出示PLOC及有效LTVP／LTVP+，由雇主在开工前通知MOM，受限制职业另走LOC。[LOC](https://www.mom.gov.sg/passes-and-permits/loc-for-ica-issued-ltvp-holders/eligibility)、[PLOC资格](https://www.mom.gov.sg/passes-and-permits/pre-approved-letter-of-consent/eligibility)、[开工通知](https://www.mom.gov.sg/passes-and-permits/pre-approved-letter-of-consent/taking-up-employment) |
| ICA LTVP的公民／PR父母或陪读家长 | 公民／PR父母可由雇主申请WP；陪读家长在新第一年不得工作，满一年后可按该专门WP路径申请。祖父母陪读等其他关系须让MOM核本人路径。[MOM：不同亲属和陪读条件](https://www.mom.gov.sg/passes-and-permits/work-passes-for-holders-of-long-term-visit-passes-issued-by-ica) |
| 短期访客 | STVP期间不得从事有薪或无薪的工作、业务或职业活动，持有效工作准证或符合规定的Work Pass Exempt Activities者另核。求职进度不能自行延长停留；ICA与MOM签发的短访准证由各自主管处理。[ICA：工作限制和延留](https://www.ica.gov.sg/enter-transit-depart/extend-stay) |

**PEP** 换工作一般不须重新申请，但须继续满足持证的年度收入条件，连续失业不能超过六个月，也不适用于自由接单、创业或传媒、宗教等受限制职业。 **ONE Pass** 可按合同条件同时为多家公司工作，换工作无需重申；拟从事传媒、宗教等受限制职业，须先取得MOM批准，获准后才能开工。持DP的合法配偶及持MOM LTVP的获承认事实婚姻伴侣有专门LOC工作路径。已有这些准证者向新雇主出示真实有效身份，按相应更新和通知规则办理。[MOM：PEP功能](https://www.mom.gov.sg/passes-and-permits/personalised-employment-pass/key-facts)、[PEP持证条件](https://www.mom.gov.sg/passes-and-permits/personalised-employment-pass/eligibility)、[ONE Pass功能](https://www.mom.gov.sg/passes-and-permits/overseas-networks-expertise-pass/key-facts)、[ONE Pass受限制职业](https://www.mom.gov.sg/passes-and-permits/overseas-networks-expertise-pass/notify-mom)、[ONE Pass家属](https://www.mom.gov.sg/passes-and-permits/overseas-networks-expertise-pass/passes-for-families)

持DP等居留准证、人在新加坡而接远程项目时，MOM的公开说明按服务对象区分：为新加坡机构或客户提供获利服务须有工作准证，为境外机构或客户提供服务则不需要工作准证。开始前核客户所在地、实际活动及本人准证；短访者的ICA限制、EP／WP专门持证条件仍须按各自规则判断。[MOM：境外雇主与自雇服务](https://www.mom.gov.sg/faq/dependants-pass/do-i-need-a-work-pass-if-i-am-self-employed-or-working-for-an-overseas-based-employer)

## 选定职位，再组合求职渠道

先看一批真实职位说明，把工作内容、必要资格、语言、地点、班次和薪资范围记下来。选自己能证明能力、也能承担通勤和照护安排的岗位；不懂职位名时，用实际任务继续搜索，例如客户服务、仓库盘点、设备维护或数据分析。以下是求职准备建议，可与职业辅导员一起调整。

| 渠道 | 怎样使用和核实 |
| --- | --- |
| 雇主官网、行业组织及学校职业中心 | 从机构自己公开的招聘页寻找岗位，核任职公司、地点、联系方式和申请要求；学生请学校确认实习是否符合课程及工作豁免条件 |
| 公开招聘平台、招聘会和职业网络 | 比较同类工作，保存职位原页和日期；通过雇主独立公开渠道确认联系人的身份，熟人转发的广告也照样核 |
| MyCareersFuture | 无需Singpass登录即可浏览和搜索；站内申请须Singpass且只开放给公民和PR。外籍读者可查职位信息，再找雇主公开招聘入口询问工作准证条件。[主管详FAQ](https://ask.gov.sg/wsg/questions/clp9j4c1p0037azywcjj4xd8n) |
| e2i职业辅导和招聘会 | 公民和PR可使用免费职业辅导，讨论方向、简历、技能缺口与职位匹配；通过当前中心目录或预约页选面对面／视频服务，说明语言、设备或行动需要。[免费服务及面试准备](https://www.e2i.com.sg/insight/interview-tips/)、[预约及服务详问答](https://www.e2i.com.sg/individuals/meet-a-career-coach/) |
| 持牌就业中介（Employment Agency，EA） | 核公司与实际经办人注册，先把工作、全部收费和退款条件写清，再决定委托；具体核法见下一节 |

Skills and Workforce Development Agency（SWDA，技能与人力发展机构）于2026年7月承接原WSG和SSG的合并安排，当前统筹就业、职业与技能支持，并与e2i等合作。旧FAQ、链接和材料仍可能写WSG。职业辅导与培训计划各有适用对象，外国人先向服务提供者说明身份，核能受理什么、费用多少及能否转介。[MOM：成立与旧机构合并](https://www.mom.gov.sg/newsroom/press-releases/2026/0624-appointment-of-inaugural-board-for-swda)、[2026年9月现行就业支持说明](https://www.mom.gov.sg/newsroom/parliament-questions-and-replies/2026/0910-written-answer-to-pq-on-support-for-jobseekers-facing-longer-job-searches)

建立一个申请记录，列职位链接、雇主、递交日期、所用简历版本、联系人、面试日期及下一次跟进时间。收到自动回执时保存申请编号；对方给过回复期限，就过期后发简短跟进。没有回执先检查垃圾邮件和平台状态，再从原招聘入口询问，不重复把身份证明发给多个陌生联系人。

## 核中介、费用、合同和退款

打开MOM的 **EA Directory** ，同时查中介公司和经办人的姓名、照片及注册编号；对照对方注册卡，查其所属公司与有效注册。另看“Under revocation / suspension / surveillance”页签。通过目录或公司自己公开的电话核招聘联系，不只看对方发来的牌照号码或名片；警方已发现诈骗者冒用真实中介的有效牌照号码。[MOM：公司与人员查询](https://www.mom.gov.sg/eservices/services/employment-agencies-and-personnel-search)、[注册卡与目录对照](https://www.mom.gov.sg/faq/employment-agencies/why-should-i-work-with-a-licensed-ea-and-how-can-i-check-if-they-are-licensed)、[警方：冒用持牌中介](https://www.police.gov.sg/Media-Hub/News/2026/05/20260515_joint_advisory_on_job_scams_involving_the_impersonation)

签中介文件前，问清安置岗位、谁是雇主、固定薪资、合约期限、收费项目、收款主体、退款及争议渠道。2026年10月1日起适用的牌照条件要求EA解释文件、确保填妥、给客户阅读和提问时间，并用客户理解的语言清楚沟通。不要签空白或内容未懂的文件；要求解释后取回一份完成副本。[MOM：现行牌照条件，第1—2页](https://www.mom.gov.sg/-/media/mom/documents/employment-agencies/ea-alerts/2026/ea-alert-280926-amendments-to-ealc-to-take-effect-from-1-oct-2026.pdf#page=1)

按2026年10月查阅的MOM规定，新加坡EA须在成功安置后才收求职者费用，并出具列明服务及金额的明细收据。费用上限为每年服务最多 **一个月固定月薪，合计最多两个月** ；固定月薪包括基本月薪和固定津贴，不计奖金、加班等浮动部分。外籍WP求职者还须以准证有效期与合约期限较短者计算，并把IPA所列工资及本地EA费与约定核对。[MOM：成功安置、收据与上限](https://www.mom.gov.sg/newsroom/press-replies/2024/1108-forum-reply-on-employment-agencies)、[固定工资口径](https://www.mom.gov.sg/faq/employment-agencies/what-component-of-a-worker-s-salary-does-mom-base-the-fee-cap-on)、[IPA费用](https://www.mom.gov.sg/faq/employment-agencies/how-will-foreign-workers-know-the-amount-that-they-are-expected-to-pay-the-singapore-ea)、[移工指南第20—21页](https://www.mom.gov.sg/-/media/mom/documents/publications/mw-guides/mw-handy-guide-english.pdf#page=20)

**教学虚构算例：** 固定月薪S$1,800，WP有效两年而雇用合约仅一年，本地EA收费上限为S$1,800。合约及WP均两年，上限才是S$3,600。先让EA写出计算基数和期限，再对照实际文件。

雇主在开始就业六个月内终止雇用时，新加坡EA须退还求职者至少50%的代理费；自行辞职不享这项退款。若实际上遭终止，却被要求签辞职信，保存指示并向MOM求助。中介关门仍须履行退款责任；境外中介收费及争议不套用这一本地退款路径，应向当地主管或使领馆核求助方式。[MOM：六个月内终止的退款条件](https://www.mom.gov.sg/newsroom/press-replies/2024/1108-forum-reply-on-employment-agencies)、[辞职与被要求写辞职信](https://www.mom.gov.sg/faq/work-permit-for-foreign-worker/can-i-get-a-refund-for-my-employment-agency-fee-if-i-resign-from-my-employment)、[EA停业仍须退款](https://www.mom.gov.sg/faq/employment-agencies/can-a-foreign-worker-get-a-refund-of-agency-fees-if-their-employment-is-terminated-and-their-ea-has-shut-down)、[本地／境外边界，第21页](https://www.mom.gov.sg/-/media/mom/documents/publications/mw-guides/mw-handy-guide-english.pdf#page=21)

雇主应承担外劳税及工作准证申请、续期等行政费用，不得直接或间接转嫁给外籍员工；EA也不得向员工收准证续期代理费。遭超额收费、拒开收据、拒按条件退款时，保留合约、IPA、收据、转账和聊天；可向EA书面指出收费或退款问题，并从MOM目录页的反馈或费用FAQ求助入口报告。被索款才准许继续工作时，立即向MOM求助。欠薪、解雇申索和家政人员雇主争议按[劳动申索]({{< relref "/book/work/employment/employment-claims" >}})中的对应路径处理。[MOM：雇主行政成本与续期禁收费](https://www.mom.gov.sg/faq/employment-agencies/are-eas-allowed-to-charge-foreign-workers-fees-for-work-pass-renewals)、[EA违规反馈](https://www.mom.gov.sg/eservices/services/employment-agencies-and-personnel-search)

## 简历、职业资格与背景核验

按目标岗位准备简历：姓名和可用联系方式、简短职业说明、相关工作经历、教育和资格、能实际使用的语言与技能。经历列真实职位和起止年月，用任务、自己的行动及结果解释能力；换行业时挑可转移的经验。作品和推荐人可另备，联系推荐人前取得其同意。不把招聘广告上的每项技能照抄成自己的经历。[e2i：用实际经验说明技能](https://www.e2i.com.sg/insight/the-power-of-soft-skills-crafting-a-resume-that-stands-out/)

| 教学虚构表达 | 怎样让招聘方看得出能力 |
| --- | --- |
| “善于沟通” | “每周为门店新员工演示收银和退货流程，并整理常见问题说明” |
| “负责数据分析” | “用电子表格核对每月库存与进货记录，把差异交采购主管复核” |
| “有照护空档” | 写真实空档和预计可工作安排，再列此前经验、已完成的相关学习及可承担班次；无需编造一段工作填满日期 |

申请材料以岗位所需资格、知识、技能和经验为中心。TAFEP（公平雇用求助机构）的三方公平雇用指引要求雇主谨慎收集年龄、照片、婚育、残障及心理健康等资料；确有工作相关需要时须解释，照片、国民服役义务或NRIC等特定用途可在offer阶段索取，或说明收集理由。面对无关问题，可以询问它与职责有什么关系、是否有其他证明方式；涉及法定适任或执业要求的材料则据实处理。[TAFEP：公平申请表及例外](https://www.tal.sg/tafep/employment-practices/recruitment/preparing-job-application-forms)

准备证书、成绩或工作证明时，核姓名、授予机构、真实课程和时间；姓名与护照不同，补改名等解释材料。需要背景核验时，请招聘方写清核什么、由谁核、需要哪些材料和取得方式，再通过已核机构的正式渠道提供。EP若须提交学历核验，MOM只接受其规定的来源和格式；教育证书、公证件或学校信本身不能代替核验凭证，非英语材料须原件与英语译文一起提交。让雇主按MOM最新清单处理，不向陌生“认证员”购买保证通过的文件。[MOM：学历核验、译文与可接受凭证](https://www.mom.gov.sg/passes-and-permits/employment-pass/documents-required)

医生、护士、律师等受监管职业，还需对应专业机构的注册或证明。PR身份及境外学位不能自动取得这些执业权限；向拟入职机构及职业主管说明学历授予地、专业和拟任职责，查认可、注册及补充训练。培训和海外学历判断接[成人学习与职业资格]({{< relref "/book/people/learning/adult-learning" >}})。[ICA：PR仍须职业注册](https://ask.gov.sg/ica/questions/clxwhkiyj00fkdsotb37zlufh)、[MOM：专业机构材料](https://www.mom.gov.sg/passes-and-permits/employment-pass/documents-required)

## 面试时把工作和条件问具体

预约时核时间、地点或视频链接、联系人及要带的材料，需要无障碍或语言安排就先说明。准备一段与岗位相关的自我介绍，以及能解释实际任务、行动和结果的经历；找可信的人练习问答。看过雇主自己公布的业务和职位说明后，再准备为什么适合、哪里需要训练及自己想了解什么。[e2i：面试准备](https://www.e2i.com.sg/insight/interview-tips/)

面试中把以下事项问清，记下对方答复；这些是比较岗位的建议，不是所有岗位的统一格式：

- 谁签雇用合同、由谁发工资、向谁汇报；如由中介派驻另一公司，两个主体各负责什么。
- 实际工作、地点、班次、加班或值班、休息和安全训练；需要驾驶、搬重物、接触化学品等，就问具体任务和设备。
- 固定月薪、津贴、浮动奖金或佣金、扣款、试用和通知期；外籍工作者再问拟申请准证、谁负责以及预计步骤。
- 下一轮面试、测评或背景核验内容，录用还须满足什么条件，何时回复；测试会否被作为实际生产工作使用。

对“先来免费试做几天”的要求，先核具体任务和本人工作权限。短访准证连无薪工作也受限制，学生、WP和家政人员同样须守各自工作范围；需要生产性劳动或开始为新雇主服务的，先解决工作授权和雇用条件，再安排。[ICA：有薪／无薪工作限制](https://www.ica.gov.sg/enter-transit-depart/extend-stay)、[MOM：学生条件](https://www.mom.gov.sg/passes-and-permits/work-pass-exemption-for-foreign-students)、[WP指定雇主条件](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-worker/sector-specific-rules/work-permit-conditions)

收到offer后，要求保存完整书面条件与附件，把面试承诺、雇主、职位、固定薪资和拟申请准证逐项对上。工作准证申请人可用出生日期加FIN或护照号，在MOM公开查询中核申请和现证状态，无需交出Singpass密码；WP薪资另按查询要求核。资料有误，先让雇主／中介更正，赴新前解决与约定不符之处。正式签发、通知信和开工衔接见[准证办理]({{< relref "/book/life/documents/pass-management" >}})，工资、工资单及休假条件见[劳动权益]({{< relref "/book/work/employment/employment-rights" >}})。[MOM：状态、薪资、纠错及中文查询](https://www.mom.gov.sg/eservices/services/check-work-pass-and-application-status)

## 遇到假招聘、索款或证件要求

通过雇主或中介自己公开的渠道核职位及联系人；对方给出真实公司名、牌照号或写有“PDPA”的协议，仍可能是在冒用。警方2026年5月的案例中，假招聘者诱导申请人把Singpass登记邮箱、手机改成骗子资料，随后接管账户。求职时保留自己的注册联系方式，不把密码、验证码交给招聘者，也不扫描聊天软件传来的Singpass二维码来授权所谓“背景审查”。[警方：当前冒用中介与账户接管手法](https://www.police.gov.sg/Media-Hub/News/2026/05/20260515_joint_advisory_on_job_scams_involving_the_impersonation)、[ScamShield：职位真实性核对](https://www.scamshield.gov.sg/i-want-protection-from-scams/learn-to-recognise-scams/job-scams/)

若“工作”要求先充值、垫款购买、刷评分赚佣金，或用个人银行账户替别人收转款，立即停止操作。已转款或账户泄露，直接联系银行，保护受影响账户并报案，同时保存广告、对方号码、聊天和转账记录；不能使用线上报案时可到邻里警局／警岗。拿不准可拨全天候 **1799** ，海外拨 **+65 6869 1799** ；这条热线做防骗咨询，报案和案件跟进另走警方。[ScamShield：求职诈骗与处理](https://www.scamshield.gov.sg/i-want-protection-from-scams/learn-to-recognise-scams/job-scams/)、[受骗后的银行／报案步骤](https://www.scamshield.gov.sg/i-have-been-scammed/)、[热线职责](https://www.scamshield.gov.sg/check-for-scams/scamshield-helpline/)

材料审核需要出示证件时，先核接收机构、用途和安全提交方式，留存已交材料清单；原件核完要求返还。被要求把护照留下作“保证不离职”，或中介帮雇主扣证件时，保存要求并向MOM反映；现行EA牌照条件明确不得协助雇主违反规则，包括建议雇主保管工人护照。账户已受影响的恢复及恶意软件处理见[账户与诈骗处置]({{< relref "/book/life/digital/privacy-fraud" >}})。[MOM：中介不得协助违法，第2页](https://www.mom.gov.sg/-/media/mom/documents/employment-agencies/ea-alerts/2026/ea-alert-280926-amendments-to-ealc-to-take-effect-from-1-oct-2026.pdf#page=2)

## 被拒绝、遭歧视或需要线下支持

被拒后可向招聘方问一项可改进的岗位相关原因，再核简历、必要资格和面试准备；继续记录实际结果。若广告、申请表或面试涉及无关的年龄、种族、性别、宗教、婚育、残障或心理健康排除，保存原话、广告截图、日期、公司和经办人，向 **TAFEP** 反映。可用其报告入口或在办公时段拨 **6838 0969** ；担心它联系招聘公司时，在报告中写明顾虑和理由，让专员讨论如何跟进。按当前三方指引和公开受理渠道处理，不把普通拒绝直接当已成立的赔偿案件。[TAFEP：公平申请表](https://www.tal.sg/tafep/employment-practices/recruitment/preparing-job-application-forms)、[报告材料、电话及跟进](https://www.tal.sg/tafep/contact-us)

没有设备、不熟悉网上申请或英语沟通吃力的公民／PR，可先拨e2i **6474 0606** ，说明需要面对面帮助、语言及可到访时间；从当前中心目录查地点和营业时段，预约有优先，无预约可能等待。预约备NRIC、手机和可用邮箱，确认是否收到通知；如未填邮箱，公开FAQ说明不会发邮件通知。提前带已有简历、目标岗位和申请记录，交辅导员一起查看。[e2i：资料、等待及技术求助](https://www.e2i.com.sg/individuals/meet-a-career-coach/)、[当前中心与时段](https://www.e2i.com.sg/career-services/)

残障公民或PR可向 **SG Enable** 核就业安置与在职支持（JPJS）。当前转介条件包括年满16岁、已核验永久残障，按要求完成职业／心理评估及训练，日常活动能自理，且无需要中度监督的严重行为困难。类别包括身体残障、较好眼中度或以上视障、较好耳中度或以上听力损失、智力残障及自闭症；详页将身体残障描述为六项日常活动中至少一项需协助，转介表另列就业服务自理要求，须让机构结合本人实际评估。专员可评估岗位、工作场所及辅助技术，并作短期入职支持；说明能独立做什么、需要什么帮助，让服务机构核匹配或转介。[SG Enable：服务与类别](https://www.enablingguide.sg/im-looking-for-disability-support/training-employment/job-placement-and-job-support)、[当前转介表第5页](https://www.enablingguide.sg/docs/default-source/general-resource-documents/one-referral-form-_2026.pdf?sfvrsn=afbcf91a_8#page=5)

申请JPJS先查SupportGoWhere残障核验状态；已核验不须重复交Disability Verification Form（DVF，残障核验表），未核验请相应注册专业人员完成。可按主管入口网上申请，或交当前One Referral Form、所需NRIC副本、DVF、已有履历／学历及附的OneMSF个人资料同意书；不会网上办，可到Enabling Village的Information and Career Centre，或拨 **1800 8585 885** （周一至周五9:00—17:30）询问材料。转介表可写华语、马来语、泰米尔语等沟通语言，以及书面、唇读、手语或其他需要；具体人员和安排先约。外国残障者及其他未符合JPJS条件者，向招聘方说明所需调整，并询问SG Enable或相关机构可否转介，补助资格按实际服务判断。[申请与线下路线](https://www.enablingguide.sg/im-looking-for-disability-support/training-employment/job-placement-and-job-support)、[详问答第1—5问](https://www.enablingguide.sg/docs/default-source/for-ee/faqs---job-placement-and-job-support.docx?sfvrsn=18d924c0_3)、[当前表第1／3／5—6页](https://www.enablingguide.sg/docs/default-source/general-resource-documents/one-referral-form-_2026.pdf?sfvrsn=afbcf91a_8#page=1)

OneMSF同意书涉及个人资料的收集、使用和分享，签名前看清用途。父母／合法监护人为未满21岁子女代给同意时，表内要求双方身份证明及出生证明、监护令等关系凭据；为失去心智能力者代办须有合法LPA或法院权限并交规定证明，共同代理人另看附表。本人能否自行签、代办人须填哪一栏或材料不齐时，申请前请接收机构核具体要求。[随转介表附的同意书，第7—9／12页](https://www.enablingguide.sg/docs/default-source/general-resource-documents/one-referral-form-_2026.pdf?sfvrsn=afbcf91a_8#page=7)

## 一段时间没找到工作，怎样调整

把申请和面试记录带给职业辅导员，看问题是在目标过窄、材料无法说明能力、工作时间不合，还是缺少岗位要求的资格。可调整相关职位、班次或行业，也可问需要补哪一项训练及预计成本；先核培训是否适合、会否影响收入，再报名。MOM当前说明，较长时间求职者可与SWDA及伙伴的辅导员复看方向和培训需要，职业转换和培训计划按各自资格受理。[MOM：长期求职支持](https://www.mom.gov.sg/newsroom/parliament-questions-and-replies/2026/0910-written-answer-to-pq-on-support-for-jobseekers-facing-longer-job-searches)、[成人学习与转职]({{< relref "/book/people/learning/adult-learning" >}})

非自愿失业的公民／PR，及时按[求职援助]({{< relref "/book/work/employment/jobseeker-support" >}})核年龄、过去工资和就业记录、住房及其他申请条件，准备失业原因证明和求职活动记录；现金申请与职业辅导可以同时推进。基本生活费不足时，按[生活困难与援助]({{< relref "/book/work/employment/hardship" >}})准备本人及全户身份、收入、银行和支出材料，并核对应的SSO／社区服务。外籍工作者、学生、家属和访客另核各机构能提供的实际帮助与转介。

仍在职而准备离开者，先读[离职与换工作]({{< relref "/book/work/employment/leaving-job" >}})，把通知期、最后工资、准证与家属有效期、税务清算和离境安排写清。没有新工作时也持续核现有停留期限；工资或中介争议保留独立处理记录，不等下一份工作找到才求助。
