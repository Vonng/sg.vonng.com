开始接单或开店前，先确认自己可以经营这项业务、拟用场所允许该活动，以及是否需要行业牌照。再选企业形式、安排合伙人与负责人，通过ACRA的Bizfile完成注册；取得UEN后还要设置企业办事权限、账户和开业所需记录。注册成功，只完成了其中一项手续。[ACRA：注册要求](https://www.acra.gov.sg/register/business/requirements-eligibility/)、[注册后的开业事项](https://www.acra.gov.sg/register/business/after-registering/local-company/)

## 哪些活动需要登记

以营利为目的、经常进行的活动，通常须登记，除非符合豁免。店铺、在家以品牌接单、网店、代发货及社交媒体销售都可能适用。只用本人完整NRIC姓名经营，或合伙人全部使用各自完整NRIC姓名，ACRA列有名称登记豁免；姓名之外再加店名、行业词等，就不能直接套这一项。[ACRA：登记与豁免](https://www.acra.gov.sg/register/business/requirements-eligibility/)

名称登记豁免不等于免税或获准在住宅经营。自行接项目的收入，应另按[个人税务](/book/work/tax/personal-tax/)判断；外国人还须先查[本人准证允许的工作](/book/life/documents/work-passes/)。把“尚未注册”“客户在海外”或“金额不大”当作全面豁免，容易漏掉不同机关各自管理的事项。

## 先核本人可以担任什么角色

持股、在ACRA登记职务、人在新加坡实际工作或经营，是不同的问题。先列清本人准备做的事：只出资，还是负责销售、接单、履约、招聘和管理，再对照准证；婚姻关系、家属身份和拥有Singpass都不能代替这一步。

| 本人情况 | 注册及经营前要核的条件 |
| --- | --- |
| 公民、PR | 一般个人登记须年满18岁，并符合有关职务、破产限制及自雇MediSave要求；专业活动另查执业条件。 |
| EP | 可以持有新加坡注册公司的股份；在另一家公司任董事须按MOM取得适用LOC。股东身份不直接扩大现有EP的工作范围。 |
| S Pass、Work Permit，包括家政移工准证 | MOM不允许持证人经营或管理新加坡业务，不能登记为独资经营者、合伙人、董事或公司秘书。先解决准证资格，不能先登记再补批准。 |
| PEP | 不能用PEP自由接单或创业；独资、合伙及同时持股的董事等有明确限制。 |
| ONE Pass | 可按该准证条件同时创办、经营和为多家公司工作；仍须履行ACRA及行业要求。 |
| EntrePass | 对企业、持股、融资或创新条件有专门要求，见下文；一般店铺注册不自动取得EntrePass。 |
| DP家属 | 核经营者LOC；ONE Pass持有人的配偶另有专门LOC入口，不能把配偶规则套给其他家属。 |
| ICA LTVP／LTVP+ | PLOC明确不允许自雇。拟经营者应先向MOM核适用工作许可，不能把可受雇直接理解为可创业。 |
| Student’s Pass | ICA条款对经营和工作有限制；学生打工豁免须按MOM具体条件判断，不能据此推定可自行经营企业。 |
| 访客、居住海外的外国人 | 不居住新加坡者登记为董事有专门规则，但STVP不能用于在新实际经营；须分别核注册安排、入境目的和工作许可。 |

来源：[ACRA：个人与本地负责人条件](https://www.acra.gov.sg/register/business/choosing-business-structure/)、[MOM：EP持股](https://www.mom.gov.sg/faq/employment-pass/can-an-ep-holder-be-a-shareholder-of-a-singapore-registered-company)、[S Pass／WP职务限制](https://www.mom.gov.sg/faq/work-pass-general/can-s-pass-or-work-permit-holders-be-registered-as-company-directors)、[PEP条件](https://www.mom.gov.sg/passes-and-permits/personalised-employment-pass/eligibility)、[ONE Pass经营范围](https://www.mom.gov.sg/faq/one-pass/do-onepass-holders-require-a-letter-of-consent-to-hold-secondary-directorship)、[PLOC不含自雇](https://www.mom.gov.sg/passes-and-permits/pre-approved-letter-of-consent/key-facts)、[ICA学生准证第12条](https://www.ica.gov.sg/docs/default-source/ica/files/docs/terms_-_conditions_stp.pdf?sfvrsn=964f6531_38)、[STVP限制](https://www.ica.gov.sg/enter-transit-depart/extend-stay)、[MOM：非本地居住董事](https://www.mom.gov.sg/faq/employment-pass/is-a-foreigner-required-to-apply-for-an-ep-if-he-is-registered-as-a-director-of-a-company-in-singapore-but-not-a-resident-of-singapore)。

EP的第二董事职务由拟聘任公司申请LOC，须先取得现雇主不反对，并通常与现雇主有ACRA记录可见的股权关联及本职需要；批准后才登记。无股权关联公司的申请，MOM另按主管行业机构支持等条件评估，不能仅凭个人兼任意愿推定会批。[MOM：第二董事职务程序](https://www.mom.gov.sg/passes-and-permits/employment-pass/taking-up-secondary-directorship)、[无关联公司分支](https://www.mom.gov.sg/faq/employment-pass/can-ep-holders-be-registered-as-directors-in-another-company)

EntrePass现行详页要求设立或拟设立ACRA注册私人有限公司、本人至少持股30%、企业有创投支持或创新技术，并符合至少一项指定条件。公司在申请时已注册超过 **12个月** ，按续期标准评估；ACRA概述仍写六个月，应以MOM这项现行详页核申请。咖啡店、小贩中心、酒吧、按摩、中医及职业介绍所等列为不适用业务，应在支付注册及租赁费用前先检查。[MOM：EntrePass完整资格与排除](https://www.mom.gov.sg/passes-and-permits/entrepass/eligibility)、[ACRA概述](https://www.acra.gov.sg/register/business/requirements-eligibility/)

## DP经营者怎样申请LOC

一般DP经营者LOC面向ACRA已登记业务的独资经营者、合伙人、至少持股30%的公司董事，或担保有限公司成员。申请时DP须至少还有3个月有效期； **收到LOC后才可开始经营** 。先提交MOM网上请求，获准进入申请步骤后，通过myMOM的EP eService或聘请就业中介提交，并确保企业营业额资料已更新。[MOM：经营者资格](https://www.mom.gov.sg/passes-and-permits/loc-for-dependants-pass-business-owners/eligibility)、[请求与正式申请](https://www.mom.gov.sg/passes-and-permits/loc-for-dependants-pass-business-owners/apply-for-a-letter-of-consent)

申请免费，多数在4周内处理；网上初步请求的结果通常在1周内，正式申请3周后查状态及补件通知。首次LOC最长1年，并受DP到期日限制；续期须至少聘用一名公民或PR，达到当时LQS，且申请前连续3个月已有CPF缴款，DP也须至少余3个月。业务不再活跃时仍要取消LOC，不能只停接单。[MOM：期限、续期与终止](https://www.mom.gov.sg/passes-and-permits/loc-for-dependants-pass-business-owners/eligibility)

ONE Pass持有人的 **配偶** 要经营业务，可由本人或就业中介申请专门LOC；要受雇则由雇主申请。DP须至少还有3个月有效期，LOC最长到DP到期日，申请免费，多数4周内处理。其他家属不走这个配偶分支，应按其工作准证条件申请。[MOM：ONE Pass配偶与其他家属](https://www.mom.gov.sg/passes-and-permits/overseas-networks-expertise-pass/passes-for-families/dependants-pass-for-overseas-networks-expertise-pass/working-in-singapore)

## 选择企业形式与承担责任的人

先讨论谁出资、谁管理、谁承担欠款，以及将来怎样加入新投资者或退出，再选择形式。

| 形式 | 关键责任与人数 |
| --- | --- |
| 独资 Sole proprietorship | 一名业主；业务与业主不是独立法律主体，业主对业务债务承担无限责任。 |
| 普通合伙 Partnership | 通常2—20名合伙人，指定专业合伙有例外；不是独立主体，合伙人可能须为其他合伙人造成的业务债务负责。 |
| 有限合伙 LP | 至少一名普通合伙人和一名有限合伙人。普通合伙人管理并承担无限责任；有限合伙人不应参与管理，否则可能按普通合伙人承担责任。 |
| 有限责任合伙 LLP | 至少两名合伙人及一名符合条件的本地经理；是独立主体，但本人自己的不当行为仍可能产生个人责任。 |
| 公司 Company，如Pte Ltd | 独立主体，股东与董事是不同角色；须安排合资格董事、秘书及持续申报，不能只比较注册费。 |

来源：[ACRA：各形式责任及要求](https://www.acra.gov.sg/register/business/choosing-business-structure/)。独资、普通合伙和LP须按登记期限续期；LLP与公司则有各自的持续申报及正式终止程序，暂时没有营业收入不会自动关闭主体。

公司须至少一名符合本地居住要求的董事。董事不能因被称为“挂名”或“不参与经营”而免去记录、申报和公司管理责任；唯一董事不能兼任公司秘书。接受职务前应看清授权、取阅账目的安排和服务合同。[ACRA：董事与秘书职责](https://www.acra.gov.sg/register/business/registering-different-business-structures/local-company/appointing-company-directors-other-key-officers/)

已有外国企业的读者，另比较代表处、本地子公司、外国公司分支及迁册。代表处用于市场研究等目的，不能赚取收入；分支与新设本地子公司的法律关系不同。外国企业须由CSP办理，不宜直接套个人独资流程。[ACRA：外国既有企业四种路径](https://www.acra.gov.sg/register/foreign-business/ways-to-set-up/)

## 谁提交，怎样选择服务提供者

有资格自行提交的人使用本人的Singpass；CSP以其企业身份办理。ACRA总则及疑难指南要求外国人、含外国职务持有人的登记由CSP处理；独资、LP及LLP步骤页另列有“外国人有Singpass”的情况。遇到这一差异，应把具体准证、是否本地居住及拟任角色交ACRA确认，不能只因能登录就承诺可以自己递交。[ACRA：外国人总则](https://www.acra.gov.sg/register/business/requirements-eligibility/)、[职务持有人与提交权限](https://www.acra.gov.sg/resources/guides-forms/troubleshooting-guide-name-application-business-registration/)、[独资步骤页](https://www.acra.gov.sg/register/business/registering-different-business-structures/sole-proprietorship-or-partnership/)

找CSP时，先在Bizfile的实体查询核其是否登记为CSP，再要求书面列出政府费用与服务费。尤其核清注册地址、秘书、本地董事、会计税务、年度申报是否分别收费，哪些只含第一年，停止服务时怎样交回记录和权限。ACRA把企业设立、地址、职务安排及代申报等列为CSP服务；一个代收邮件地址不能替代实际经营场所的许可。[ACRA：CSP范围及查询](https://www.acra.gov.sg/register/corporate-service-provider/checking-if-you-must-register/)

## 确定名称、活动与地址

在Bizfile申请名称时，选择企业形式，并按实际主要活动选择SSIC行业代码；有次要活动时也填明。名称申请费 **S$15** ，名称不可用或自行撤回也不退。获准后保存交易编号，并在 **120天内** 完成登记，逾期名称会释放。[ACRA：名称申请及期限](https://www.acra.gov.sg/register/business/choosing-reserving-a-business-name/reserving-bizfile/)

ACRA登记名称不产生商标专有权，也不自动取得同名网站域名。打算长期使用的品牌，应同时检查商标及域名，再决定印刷、装修或宣传投入；需要专有商标权时走IPOS申请。[ACRA：名称、商标和域名](https://www.acra.gov.sg/register/business/choosing-reserving-a-business-name/reserving-bizfile/)

独资、普通合伙和LP须填实际业务地址，不可填邮政信箱。公司及LLP的注册地址须为新加坡地址，用于收法律文件和保存记录，未必与实际营业地点相同；公司注册所填办公时间须每个营业日至少开放3小时。[ACRA：独资地址](https://www.acra.gov.sg/register/business/registering-different-business-structures/sole-proprietorship-or-partnership/)、[公司地址与办公时间](https://www.acra.gov.sg/register/business/registering-different-business-structures/local-company/registering-via-bizfile/)、[LLP注册地址](https://www.acra.gov.sg/register/business/registering-different-business-structures/limited-liability-partnership/)

职务持有人还须提供住址和公开联系地址。公开联系地址可以与住址相同，须在住址所在国家或司法管辖区、能收到联系，且不能是邮政信箱。决定是否公开住宅地址前，先核自己所用形式的资料要求。[ACRA：公司个人及联系地址](https://www.acra.gov.sg/register/business/registering-different-business-structures/local-company/registering-via-bizfile/)

## 从家里经营，先分清两项计划

**Home Office Scheme** 用于住宅内的小规模办公行政活动；私人住宅向URA、HDB住宅向HDB办理。不是屋主的申请人须先取得屋主书面同意。私人住宅按URA详页允许最多两名不住在该住宅的人参与，包括雇员、合伙人和董事；这里的non-resident指不住在该单位的人，不是在说外国人配额。[URA：Home Office登记与条件](https://www.ura.gov.sg/guidelines/property-and-business-owners/business-owners/home-business/home-office-scheme/)

按URA的Home Office条件，住宅须继续用于居住，客户不能来访，不能在屋内外销售实物或展示招牌；营业活动须保持为行政性质，其他活动在别处进行。还须安装规定的灭火器与独立烟雾探测器，并满足其他机关要求。一次性许可持续至该家庭办公业务结束，但违反条件可被撤销。[URA：允许活动、消防及限制](https://www.ura.gov.sg/guidelines/property-and-business-owners/business-owners/home-business/home-office-scheme/)

私人住宅的 **Home-Based Business Scheme** 则允许符合条件的小规模活动无须URA事先批准，例如小量烘焙、部分美容或同时不超过三名学生的私人补习。须由住户经营、租客取得屋主同意，不可让外来人员在住宅经营，也不可有不住在该住宅的雇员在内工作；重型设备、大量储货、频繁装卸及扰邻都受限制，食品与消防规则仍适用。HDB住户应另核HDB的住宅条件，不能把URA私人住宅的允许清单直接当作自己的批准。[URA：Home-Based Business详规](https://www.ura.gov.sg/guidelines/property-and-business-owners/business-owners/home-business/home-based-businesses/)

## 准备材料与注册费用

共同材料包括已批准名称及交易编号、准确的企业形式与业务活动、地址、业务电邮，以及每名业主、合伙人、董事或经理的身份与联系资料。独资、合伙及LP还须核开业日期与登记期限；独资或普通合伙的全体业主居住海外时，须核本地授权代表；LP的全体普通合伙人为外国人时，须核本地经理。[ACRA：独资／普通合伙](https://www.acra.gov.sg/register/business/registering-different-business-structures/sole-proprietorship-or-partnership/)、[LP材料](https://www.acra.gov.sg/register/business/registering-different-business-structures/limited-partnership/)

公司另备财务年度截止日FYE、股东及股份分配、已发行与实缴股本、章程、代名人与实际控制人资料；LLP也须判断RORC实际控制人登记要求及豁免，无法识别控制人时按规定填实际执行控制者。[ACRA：公司材料与控制人](https://www.acra.gov.sg/register/business/registering-different-business-structures/local-company/registering-via-bizfile/)、[LLP控制人](https://www.acra.gov.sg/register/business/registering-different-business-structures/limited-liability-partnership/)

需要股本的公司，ACRA列的起始股本最低为S$1；实缴股本是股东实际支付的部分。这个登记最低额不能说明企业有足够租金、工资或周转金。股份数量、金额和各股东权利应先谈妥，经营预算另按实际支出准备。[ACRA：股本与实缴](https://www.acra.gov.sg/register/business/registering-different-business-structures/local-company/deciding-on-share-capital-share-types/)

公司可以上传自订章程或采用范本。范本可选择以后随法规更新，或固定采用设立时版本；选择前要理解对股权转让、会议和任职的影响。全体初始认购股东须在设立时签署留存版本，保存于注册地址。[ACRA：章程准备与两种范本选择](https://www.acra.gov.sg/register/business/registering-different-business-structures/local-company/company-constitution/)

| 形式 | ACRA注册费，不含另付S$15名称费 |
| --- | --- |
| 独资、普通合伙 | 一年S$100；三年S$160，三年须满足CPF Board条件。 |
| LP | 一年S$100；三年S$160，三年须满足CPF Board条件。 |
| LLP | S$100。 |
| 本地公司 | S$300。 |

来源：[独资费表](https://www.acra.gov.sg/register/business/registering-different-business-structures/sole-proprietorship-or-partnership/)、[LP费表](https://www.acra.gov.sg/register/business/registering-different-business-structures/limited-partnership/)、[LLP费表](https://www.acra.gov.sg/register/business/registering-different-business-structures/limited-liability-partnership/)、[公司费表](https://www.acra.gov.sg/register/business/registering-different-business-structures/local-company/registering-via-bizfile/)。CSP服务、场地、行业牌照及后续会计申报费用另算；拟登记或续期独资、普通合伙及LP的自雇者，还应核MediSave是否已付清或有有效GIRO安排。[ACRA：MediSave条件](https://www.acra.gov.sg/register/business/choosing-business-structure/)

## 在Bizfile提交，直到拿到注册结果

由符合提交资格的人从Bizfile选择“Register → Register new entity → Register new business entity”，用名称申请编号带入资料。按所选形式补地址、人员及其他材料，逐项检查姓名、角色、股份和电邮，再作声明。名称阶段所选企业形式须与登记一致，不能在最后一步随意换类型。[ACRA：公司逐步流程](https://www.acra.gov.sg/register/business/registering-different-business-structures/local-company/registering-via-bizfile/)、[独资逐步流程](https://www.acra.gov.sg/register/business/registering-different-business-structures/sole-proprietorship-or-partnership/)

公司、LP与LLP自行提交时，其他职务持有人须在 **60天内** 完成endorsement；CSP代办时不要求这一系统确认。全部确认完成后，提交人在Bizfile收件箱取得付款通知。没有付款入口时，先核所有需要确认的人是否已完成，再用原提交账户进入“Pending actions”查看付款。[ACRA：LP确认](https://www.acra.gov.sg/register/business/registering-different-business-structures/limited-partnership/)、[LLP确认](https://www.acra.gov.sg/register/business/registering-different-business-structures/limited-liability-partnership/)、[付款受阻处理](https://www.acra.gov.sg/resources/guides-forms/troubleshooting-guide-name-application-business-registration/)

多数登记付款后很快获准，复杂申请可能需15个工作日，须其他机关批准的可能需14—60天。不能只凭已扣款就宣布注册成功；到Bizfile收件箱取得成功通知、UEN及Business Profile下载链接，并核资料。公司免费Business Profile须在注册后60天内下载保存。[ACRA：结果与处理期](https://www.acra.gov.sg/register/business/registering-different-business-structures/local-company/registering-via-bizfile/)、[公司资料下载期限](https://www.acra.gov.sg/register/business/after-registering/local-company/)

## 取得UEN后，完成开业准备

公司取得UEN一天后可申请Corppass。先由登记在企业名下的Registered Officer安排管理员；管理员注册账户、建立用户并分配各机关数字服务的权限，实际办事人用自己的Singpass验证身份。企业可以把税务、CPF或其他事务分给不同人员处理，应同时记清谁能查看、准备和提交。[ACRA：申请时间](https://www.acra.gov.sg/register/business/after-registering/local-company/)、[GovTech：Corppass角色与设置](https://www.tech.gov.sg/products-and-services/for-businesses/corporate-transactions/corppass/)

再把以下事项安排到具体负责人和日期：

- **账户与账目。** 向银行确认该企业形式、股东与签字人的开户材料，把业务收支单独记录；不要假设个人账户的开户流程可原样用于公司。
- **公司人员与名册。** 公司秘书须在设立后6个月内任命；未获审计豁免的公司须在3个月内任命审计师。按适用条件从设立日维护控制人、代名董事和代名股东等名册。
- **牌照与场地。** 从GoBusiness的牌照指引按实际活动核要求，完成所需批准再开业。涉及进出口货物，另须安排Customs账户及贸易许可；普通ACRA登记不能替代它们。
- **雇人及资料处理。** 开始聘人前安排CPF Submission Number和适用雇主义务；处理个人资料的组织须安排DPO责任。姓名、电邮、客户名单等资料应由谁管理，也要在开业前说清。
- **税务。** 公司以公司名义纳税，独资或合伙按相应取得人判断；检查GST登记义务和适用开票要求，保留交易、费用、资本及库存记录。

这些开业事项来自[ACRA公司注册后清单](https://www.acra.gov.sg/register/business/after-registering/local-company/)；CPF个人与雇主的区别见[CPF基础](/book/work/finance/cpf-basics/)，家庭资金与经营投入应分别安排，可先用[预算方法](/book/work/finance/household-budget/)列出可承受的现金支出。日后停止接单、换股东、换地址或负责人时，还要处理登记和权限更新；公司及LLP须按正式程序终止，不能把不营业当成已注销。[ACRA：持续经营及关闭分流](https://www.acra.gov.sg/register/business/choosing-business-structure/)
