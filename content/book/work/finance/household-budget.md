做家庭预算，可以先拿出最近三个月的工资单、银行流水和账单，回答三个问题：每月实际进来多少钱，哪些钱已经有用途，下次发薪前会不会不够用。把数字记在纸上或表格里即可；夫妻、伴侣、合租者之间还要写清谁付、何时结算，以及哪些支出各自承担。

## 先认清每月可用的钱

固定工资用扣款后的实际到手金额；奖金、尚未落实的加班费或佣金，等收到后再安排。靠接单、自雇或季节性收入生活的人，可以先用较保守的收入水平做基本预算，收入较好的月份补充储备。MoneySense 的预算指引同样建议先列可靠收入，随后检查税款、债务、日常开销及受供养家人的费用。[MoneySense：管理日常收支](https://www.moneysense.gov.sg/managing-your-money/)

有 CPF 缴款的雇员，应从工资单读到手现金，避免先按税前工资安排支出、又遗漏雇员扣款。CPF 里的储蓄按住房、医疗、退休等条件使用，不能把账户总余额当成今天可支付房租和饭钱的存款。[CPF：账户与用途](https://www.cpf.gov.sg/member/cpf-overview) 具体身份、年龄、新 PR 阶段和自雇安排见 [CPF 基础](/book/work/finance/cpf-basics/)。

学生获得的家庭汇款、退休者的固定月领款，也可以按预计实际到账的日期登记。跨境家庭要同时记下汇款币种、费用及收款人实际需要的金额；如果收入和支出使用不同货币，给汇率变化留一点余量。尚未获批的补助、等待审核的理赔、朋友答应归还的借款，可以另列一栏跟进，先不用于承诺新的固定支出。

## 把账单按时间摆出来

每笔费用记金额、到期日、付款人和扣款账户。建议分成下面四组：

| 一组钱 | 常见项目 | 怎样放进预算 |
| --- | --- | --- |
| 每月固定或必须支付 | 房租、贷款、学费、照护费、家人生活费 | 先按合同或实际账单登记，到期前确认账户有钱 |
| 每月会变化 | 食物、交通、水电、就医、休闲 | 看几个月的真实记录，再给出可调整的金额 |
| 每年或隔一段时间支付 | 税款、保险费、回乡旅费、设备更换 | 计算距离付款还有几个月，逐月预留 |
| 一次发生 | 租房押金、搬家、添置家具、课程报名 | 在决定前另算现金需求，确认支付后还剩多少 |

年度费用除以 12，适合从完整年度开始积累。若账单已经近在眼前，要按剩余时间计算。 **教学虚构：** 六个月后须付 S$2,400，已经留有 S$600，余下 S$1,800 应分六个月准备，即每月 S$300。此时每月存 S$200，到期仍会短缺。

押金也要占用现金。即使预计退租后能收回，入住时仍须先付，退回时间和金额要看合同及实际结算。租房前可把首期租金、押金、适用税费和搬家支出列成一张表，再看 [租房与签约](/book/life/housing/renting/)。医疗支出则按自己的身份、补贴资格和保险条款估计，可从 [医疗费用怎样支付](/book/people/healthcare/healthcare-payments/) 查起。

个人所得税也单独预留。用自己的评税及缴款安排登记金额和日期，相关步骤见 [个人税务](/book/work/tax/personal-tax/)；需要离职税务清算的人，再核对 [IR21 与暂扣款项](/book/work/tax/leaving-singapore/)，把可能暂时收不到的尾薪计入离职期间现金安排。

## 一张可以改成自己数字的表

以下是 **教学虚构** ：一个家庭每月可靠到手收入合计 S$6,000，金额全部为演算设定，不代表新加坡平均开销、市场报价或最低生活费。税款与年度保费在“年度费用预留”中计算，不再重复放入其他行。

| 项目 | 每月安排（S$） |
| --- | ---: |
| 住房与固定家庭账单 | 2,200 |
| 食物和日用品 | 1,000 |
| 交通 | 250 |
| 给父母的生活费 | 400 |
| 日常医疗现金预留 | 150 |
| 现有债务还款 | 300 |
| 年度费用预留 | 600 |
| 新增应急储备 | 500 |
| 休闲和个人消费 | 300 |
| 尚未分配的余量 | 300 |
| 合计 | 6,000 |

第一遍先换成自己真实的数字。若合计超过收入，把差额写出来，并逐项决定能否改期、降低、取消，或需要增加哪些支持。抚养、照护和必要医疗未必有压缩空间；预算表能帮助说明困难。

第二遍看时间。假设工资每月 25 日到账、房租次月 1 日支付，那么 25 日看到的余额里，已有一部分属于下一次房租。自动扣款可以减轻记日期的负担，但仍要检查余额及扣款结果。信用卡记账可以在消费时计入相应类别，再把还款记为付款动作，避免同一笔购物被算成两次开销；原有未清债务和利息则另列。

## 应急储备要能及时使用

MoneySense 的基本财务规划指引把 **三至六个月开销** 作为应急储备的经验起点；FAQ 说明，收入不稳定的人可能需要更多，应按个人处境调整。计算时想一想失去收入后哪些费用仍须支付、另一位家庭成员能否继续承担，以及找到新收入可能要多久。[MoneySense：基本财务规划](https://www.moneysense.gov.sg/planning-your-finances-well/)、[消费者 FAQ：应急储备](https://isomer-user-content.by.gov.sg/309/3521b80b-3319-45e0-b8b5-a293c39604be/FAQs_for_consumers_on_Basic_Financial_Planning__finalised_.pdf)

先确定一个能持续存下的小额目标，逐步积累。已经预留给年度保险费的钱有明确用途，做应急资金清单时应把它扣除。储备还要容易取用；MoneySense FAQ 不建议把这笔钱放进股票市场，也提醒 CPF 有专门使用条件。检视任何存放方式时，都要核对何时可取、需要哪些手续及会不会亏损或产生费用。[MoneySense FAQ，第 2 页](https://isomer-user-content.by.gov.sg/309/3521b80b-3319-45e0-b8b5-a293c39604be/FAQs_for_consumers_on_Basic_Financial_Planning__finalised_.pdf)

使用储备之后，把补回计划写进下一次预算。若失业同时影响居留、家属准证或雇主保险，现金计划应与手续一起安排，参见 [离职后的工资、准证与家属安排](/book/work/employment/leaving-job/)。

## 钱已经不够时，先把缺口讲清楚

把现有现金、下一笔可靠收入、近一个月必要开销和债务到期日整理在同一页。若贷款或信用卡将无法按期偿还，尽早联系原金融机构，说明变化并询问可行的付款安排。MoneySense 建议遇到还款困难及时与金融机构沟通；追加借款前应比较全部利息和费用。[MoneySense：债务困难怎么办](https://www.moneysense.gov.sg/managing-debt-what-can-you-do/)

也可以从 **Credit Counselling Singapore（CCS，新加坡信贷辅导机构）** 的免费债务说明会开始了解选项。按其当前流程，参加说明会后取得辅导申请表，填写并连同所需证明交回，再安排个别辅导。可用方案及后续安排需要评估，不应把登记参加说明会视为债务已经重组。[CCS：消费者债务与辅导流程](https://ccs.org.sg/consumer/debt-management/)

基本生活费不足时，可在 [SupportGoWhere](https://supportgowhere.life.gov.sg/) 的“Financial support and benefits”及相关分类查找支持，进入具体项目再核对国籍、居留、收入及家庭条件。网站列出项目不代表每位居民均符合资格；尚待评估的援助先记为“申请中”。

每月选一个固定时间对账，看看预留的钱是否仍在、有没有漏掉的年度账单，以及下一月是否将换工作、搬家、添孩子或增加照护。完成预算的标志是下一笔账单知道由谁、用哪笔钱支付；遇到缺口时，也知道要提前找谁商量。
