被裁员、公司停业或因其他非自愿原因失去工作后，符合条件的公民和PR可以申请SkillsFuture Jobseeker Support，在继续求职并完成活动目标期间取得临时现金支持，六个月合计最高S$6,000。先核身份、过去收入和就业记录、住宅年值，再提交申请；获批后按个人活动周期完成和申报求职活动，达到积分目标才进入付款程序。[主管：资格](https://ask.gov.sg/jobseekersupport/questions/cm98bmi2800zb9t9j1cv7cnh6)、[怎样取得付款](https://ask.gov.sg/jobseekersupport/questions/cm98bp1a500l93lrkf6mcs65t?from=topics)

## 先核六项申请条件

从申请日判断，须同时符合下表条件。过去平均月收入用 **总收入 gross income** ，排除雇主CPF供款，只计过去十二个月里实际受雇并取得收入的月份。[主管完整资格表](https://ask.gov.sg/jobseekersupport/questions/cm98bmi2800zb9t9j1cv7cnh6)

| 条件 | 核什么材料或记录 |
| --- | --- |
| 新加坡公民或PR，年满21岁 | 身份记录和年龄；持工作、学生、家属或访客准证本身不满足此项 |
| 过去十二个月平均总月收入不超过S$5,000 | 工资、加班、津贴、佣金和奖金；不用净到手工资代替 |
| 过去十二个月在新加坡受雇至少六个月 | 就业日期、雇主记录和CPF供款 |
| 非自愿失业 | 裁员、企业停止经营、被解雇，或疾病、受伤、事故导致终止雇用等证明 |
| 居住的新加坡住宅年值AV不超过S$31,000 | 所居住宅的Annual Value；AV含义见[房产税](/book/work/tax/property-tax/) |
| 过去三年没有收到本计划付款 | 过去参与和收款记录 |

住宅年值看自己 **居住的住宅** ，不是把每月租金拿来与S$31,000比较。平均工资的计算也不是一律除以十二：主管把过去十二个月里的总就业收入，除以实际受雇且取得收入的月份数。[资格](https://ask.gov.sg/jobseekersupport/questions/cm98bmi2800zb9t9j1cv7cnh6)、[总收入与除数](https://ask.gov.sg/jobseekersupport/questions/cm986u1eo00s6gqf4r8vu2wul?from=topics)

“非自愿”包括裁员、关业、解雇及因疾病、受伤或事故不能继续原职位的终止雇用。主动辞职时，要向主管说明实际情况，不能只因暂时没有收入就按非自愿失业申报；保留终止通知与雇主往来记录。[非自愿失业定义](https://ask.gov.sg/jobseekersupport/questions/cm98b6py700kl3lrkk5kpm57h?from=topics)

## 不同工作关系怎样判断

| 情形 | 当前主管答复与下一步 |
| --- | --- |
| 原为兼职雇员，遭裁员 | 可以申请，但仍须符合所有其他条件 |
| 原为自雇或平台工作者，不能继续经营或接单 | 这项计划面向失去雇佣工作的雇员；该自雇或平台工作中断不符合计划，另找职业服务及生活支持 |
| 实习到期结束 | 主管不视为非自愿失业，不能仅以实习结束申请 |
| 居住海外，或最后一份工作在海外 | 不符合须在新加坡居住、最后在新加坡工作的要求 |
| 外籍准证持有人 | 不满足公民或PR条件；先核准证停留、转雇、欠薪与本人的求助渠道 |
| 公民或PR同时在读书、照顾家人 | 不能从“学生”或“家属”标签推定获批；逐项核实际雇佣、非自愿失业和继续求职条件 |

以上分支分别见[原兼职雇员](https://ask.gov.sg/jobseekersupport/questions/cm98ayvuk00jimx0i532uv2qh?from=topics)、[自雇与平台工作者](https://ask.gov.sg/jobseekersupport/questions/cm98avcwc00yi9t9jfqxh9q5h)、[实习结束](https://ask.gov.sg/jobseekersupport/questions/cm98azlpq00yn9t9jhikxb0xy?from=topics)、[海外居住或就业](https://ask.gov.sg/jobseekersupport/questions/cm98ai2pp00ocraro2jnajliy?from=relatedquestions)与[身份条件](https://ask.gov.sg/jobseekersupport/questions/cm98bmi2800zb9t9j1cv7cnh6)。外籍离职的动作见[离职与换工作](/book/work/employment/leaving-job/)；工资争议另查[劳动权益](/book/work/employment/employment-rights/)。

## 准备材料并提交申请

使用主管申请FAQ给出的[官方申请入口](https://ask.gov.sg/jobseekersupport/questions/cm98a9ax600irmx0inbjg2uec?from=topics)。提交前准备过去就业详情、前雇主邮箱或手机、雇主正式终止或解雇通知，以及过去 **十五个月** 的CPF Transaction History，筛选为雇主供款；因医疗原因终止雇用，还须医疗证明或医生、医疗机构的正式信。主管会联络前雇主核实所报就业信息。[申请材料与核实](https://ask.gov.sg/jobseekersupport/questions/cm98a73oe00o1rarot3kgoifk)

保留所交文件、提交确认、申请号和结果通知，确认联络邮箱可用。缺终止证明或雇主已停业，把现有工资、CPF和终止往来材料整理好，向主管说明缺哪份材料，请其确认补件方法；不用自己的说明替代主管核实。

没有电脑、手机或网络，可到Careers Connect的Lifelong Learning Institute寻求申请操作协助，当前FAQ列工作日9:00—17:00。带上就业材料，并准备本人Singpass登录；只由本人完成密码与验证。未能使用Singpass或需要语言、读写协助，先打计划热线 **6883 5885** 说明需要哪类帮助，确认办理安排。[设备与申请协助](https://ask.gov.sg/jobseekersupport/questions/cm989w5db00nrraro4ecx30h9?from=topics)、[求助地点与热线](https://ask.gov.sg/jobseekersupport/questions/cm96zfz1h00jzraroadz1iwfm?from=topics)

## 按自己的活动周期积点

活动周期与自然月不同。现行FAQ说明，首个周期从提交申请日开始，延续至批准后三十天；之后每个周期为三十天，最多六个。获批后在平台Dashboard记录自己的起止日，分别安排活动、材料上传和积分检查。[活动周期](https://ask.gov.sg/jobseekersupport/questions/cm987i4za00xb9t9jg8s6eavt)

正常按期达标时，前三个周期每期须达到 **10分** ，后三个每期 **5分** ；有未达标顺延时，按平台当期目标和下文的顺延规则核。下面列出几种活动；次数上限按活动周期计算，完整活动与材料要求从主管清单和平台Activities核。[每期目标](https://ask.gov.sg/jobseekersupport/questions/cm987ox6r00stgqf4il2kfjze?from=relatedquestions)、[当前官方活动清单PDF](https://go.gov.sg/jobseekersupportactivities)

| 活动 | 每次积分 | 每周期计分次数上限 |
| --- | --- | --- |
| 提交职位申请 | 1 | 5 |
| 在招聘平台更新简历 | 2 | 1 |
| 完成CareersFinder职业测评 | 2 | 1 |
| 职业咨询或辅导 | 4 | 1 |
| 浏览或订阅职业相关内容 | 1 | 2 |
| 开始参加认可培训课程 | 2 | 1 |
| 参加职位面试 | 4 | 官方清单此项未列次数上限 |

清单还列招聘机构登记、职业活动、行业交流、工作见习计划申请和就业相关志愿服务，选择能帮助自己找工作的项目。需要培训时，先核课程实际费用及[成人学习](/book/people/learning/adult-learning/)的资助条件，再决定是否报名。[主管：可参加的活动](https://ask.gov.sg/jobseekersupport/questions/cm987j5gw00t310xz63giij3q?from=topics)

在MyCareersFuture提交的职位申请自动记录，按主管说明于下个工作日计分，每周期最多五次；在其他招聘平台申请，则上传能显示本人姓名、平台、职位及公司的成功申请证明。其他活动各有材料要求，先在Activities看需要什么，再保存通知、完成或出席记录并上传。[职位申请计分](https://ask.gov.sg/jobseekersupport/questions/cm9877dhf00asmx0ies7lo3kn?from=topics)、[申请证明](https://ask.gov.sg/jobseekersupport/questions/cml68uf1q006hcsd0i0jhnmzr?from=topics)、[各类活动材料](https://ask.gov.sg/jobseekersupport/questions/cm987fojf00skgqf46lujhz7i?from=topics)

达到目标后的多余积分会带到下一周期。某期未达标，已得积分连同该档付款顺延，下一期继续达到同一个目标；最长仍只有六个月，因此会少领一笔，不能靠顺延把整个计划无限延长。[多余积分](https://ask.gov.sg/jobseekersupport/questions/cm9878e5t00ss10xzkkx9ff2h?from=topics)、[未达标的后果](https://ask.gov.sg/jobseekersupport/questions/cm8o43s2z00l5ee0adj7fumkc?from=topics)

## 领款金额、到账与重新就业

在符合付款资格且达到目标时，六档付款上限如下。每档实领还受本人过去平均总月收入限制，按当档金额与该平均收入 **取较低者** ；六个月S$6,000是最高合计，不是每人固定领取额。[付款金额](https://ask.gov.sg/jobseekersupport/questions/cm986u1eo00s6gqf4r8vu2wul?from=topics)、[工资封顶](https://ask.gov.sg/jobseekersupport/questions/cm986t61c00s1gqf4br2hi1i2?from=relatedquestions)

| 付款档次 | 最高金额 |
| --- | --- |
| 第1档 | S$1,500 |
| 第2档 | S$1,250 |
| 第3档 | S$1,000 |
| 第4、5、6档 | 每档S$750 |

**教学虚构例子** ：某人的过去平均总月收入为S$1,200，所有资格和各期积分均满足，又没有中途重新就业。六档最高分别为S$1,200、S$1,200、S$1,000、S$750、S$750、S$750，合计S$5,650。实际审批仍会核就业、活动和付款条件；这个算例只是说明工资封顶怎样影响金额。

申请时同时向主管核首笔付款是否须从最后就业日起失业至少一个月，并按批准与付款通知确认预计到账日。达标后一般再等 **三至六周** 付款，经本人PayNow-NRIC、GIRO或GovCash收取；没有PayNow-NRIC而用GIRO或GovCash，主管列还可能多一至两周。收到发放邮件后查看平台Payout状态及实际到账；达标超过六周仍未收，或平台显示已付而银行或GovCash没有通知，通过主管服务入口查询，并交申请号、达标日和付款状态。[到账时间](https://ask.gov.sg/jobseekersupport/questions/cm986g89o00rjgqf4zqtjw0us?from=topics)、[超时查询](https://ask.gov.sg/jobseekersupport/questions/cmaxmklhd0070ep722fkh3pr2?from=topics)、[已付却未收到](https://ask.gov.sg/jobseekersupport/questions/cm986bibb00ih3lrkti97qm1j?from=topics)

每个活动周期开始要申报就业状态。找到新工作，立即在平台更新并注明预计开工日；新工作开始后不再符合继续付款条件。裁员后先找到临时兼职，临时收入每月 **S$1,500或以下** 且仍寻找长期工作者，主管FAQ容许在满足其他条件时继续符合计划；超过S$1,500则不符合。把临时工作的收入和期限如实申报，并请主管核该份工作的适用安排。[重新就业申报](https://ask.gov.sg/jobseekersupport/questions/cm986f42o00regqf4hafjtaqc?from=topics)、[临时兼职](https://ask.gov.sg/jobseekersupport/questions/cm98ar4jh00f4uy0m5xk460be?from=topics)

## 拒绝、活动不计分或还有其他生活困难

申请被拒和活动材料被拒，先读通知中的具体理由，分别补身份、就业或活动证明；两种情况均可按各自主管FAQ从服务入口提出申诉，由机构按个案和及时提供的材料考虑。申诉FAQ列处理期十五个工作日，保留提交确认并按通知追踪；提出申诉本身不等于已获批或守住活动目标。[申请申诉](https://ask.gov.sg/jobseekersupport/questions/cm9867qlw00wg9t9jibj75bho?from=topics)、[活动申诉](https://ask.gov.sg/jobseekersupport/questions/cm986511800s710xzukftulmy?from=topics)、[处理时间](https://ask.gov.sg/jobseekersupport/questions/cm9863t8w00a9mx0i1nn950u9?from=topics)

不符合这项现金计划但仍须找工作，可另向Skills and Workforce Development Agency（SWDA）及e2i询问职业服务，或从SupportGoWhere按需要找其他支持。每项职业服务和现金计划的身份、收入及用途分别判断。[不符条件时的支持](https://ask.gov.sg/jobseekersupport/questions/cm98aqi4k00ul10xzpqotb9uv?from=topics)

本计划不提供托儿、照护或HDB贷款延期；有需要时另向对应主管申请。正在断粮、无力付必要账单或等首笔付款，先整理[家庭预算](/book/work/finance/household-budget/)，向合适的社会服务渠道说明当下缺口；照护需要见[照护支持](/book/people/accessibility/caregiver-support/)，债务压力见[债务与争议](/book/work/finance/debt-disputes/)。[MOM：JS与其他生活支持的分工](https://www.mom.gov.sg/newsroom/parliament-questions-and-replies/2026/0908-written-answer-to-pq-on-js-scheme-wraparound-support)
