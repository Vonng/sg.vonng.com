给孩子安排学位，先查孩子自己的公民、PR或外国人身份、完整出生日期、目标学年和年级。公民与PR的小一报名由教育部（Ministry of Education，MOE）分阶段办理；外国孩子的小一须先表达意向，较高年级主要通过国际学生入学考试；国际及私立学校则向学校申请。拿到学校通知后，还要按孩子持有的有效证件完成居留及报到手续。[MOE：小一报名问答](https://www.moe.gov.sg/faq?categoryid=76037F9F568F46A7AA80EFDCE9AB23CD)、[SEAB：AEIS](https://www.seab.gov.sg/aeis/about-aeis/)、[ICA：学生准证](https://www.ica.gov.sg/reside/STP)

## 先按孩子的身份选路

父母是公民或PR，孩子也可能仍是外国人。MOE明确说明，PR家长的外国孩子，以及持Dependant’s Pass（家属准证，DP）的外国孩子，申请主流学校小二至小五、中一至中三仍须参加AEIS；父母的身份不能替代孩子的入学身份。[MOE：国际学生及DP孩子](https://www.moe.gov.sg/faq?categoryid=D1FDE07370F74F04B63B4592E161CBA1)

| 孩子的情况 | 先处理的事项 |
| --- | --- |
| 公民或PR，首次读小一 | 核出生日期，在P1 Registration Portal查合资格阶段、学校和报名期。 |
| 既非公民也非PR，首次读小一 | 在当届窗口向MOE提交Indication of Interest（入学意向），等候是否获学校安排。 |
| 外国孩子，申请较高小学或中学年级 | 核AEIS或S-AEIS当届年级、出生日期范围及适用的英语成绩要求。 |
| 公民或PR，从海外回流 | 有保留学籍先找原校；其余核Returning Singaporeans安置服务或相应中学考试。 |
| 已在主流学校就读，拟因搬家或其他原因转校 | 先找现校；公民与PR的小学搬家转校有特定服务。 |
| 拟读外国学制、国际或私立学校 | 向学校核年级、课程、评估、学额、合同与所需准证，再查注册及认证。 |

来源：[MOE：小一报名](https://www.moe.gov.sg/faq?categoryid=76037F9F568F46A7AA80EFDCE9AB23CD)、[国际学生](https://www.moe.gov.sg/faq?categoryid=D1FDE07370F74F04B63B4592E161CBA1)、[回流学生](https://www.moe.gov.sg/faq?categoryid=F8ACA3ABB7DD42799138FD6D8D34D9AA)、[小学转校](https://www.moe.gov.sg/faq?categoryid=FFCA2C16536A4CC1AE64080BA2917D31)。

家长持工作准证、Student’s Pass（学生准证，STP）、DP、Long-Term Visit Pass（长期探访准证，LTVP）或短期访客证件时，分别列出家长和孩子的证件、签发机构与到期日。孩子已持有效DP或LTVP的学习例外见后文；家长自己的学生或访客证件不能直接作为孩子全日制就学的居留依据。相关准证安排见[入境与ICA证件]({{< relref "/book/life/documents/arrival-renewal.md" >}})及[MOM家属准证]({{< relref "/book/life/documents/work-passes.md" >}})。[ICA：全日制学习条件](https://www.ica.gov.sg/reside/STP)

## 公民与PR读小一：先核出生日期和报名年度

 **2026年小一报名对应2027年入学** ，常规出生日期为2020年1月2日至2021年1月1日，首尾两天均包括。MOE按入学当年1月1日已满六岁处理小一入学：2021年1月2日出生的孩子不能在2027年入小一，应参加2027年报名、2028年入学。截至2026年10月14日，2026年的公民与PR报名期已经结束；合龄却还没有学位，应联系MOE协助安排有余位的学校。[MOE：出生日期、漏报与安排](https://www.moe.gov.sg/faq?categoryid=2662B55F532E40368F35394CD97CD2E5)、[SC与PR漏报及一月一日出生的分支](https://www.moe.gov.sg/faq?categoryid=17EF23F543444142955C9817E6C53B25)

| 特殊情况 | MOE问答所列处理 |
| --- | --- |
| 公民孩子合龄，家长想延后一年 | 须向Compulsory Education Unit（义务教育事务单位，CEU）申请延期；不能自行漏报后改参加下一年。 |
| PR孩子合龄却漏报 | 联系MOE安排有余位的学校，通常不能直接改参加下一年的小一报名。 |
| 2021年1月1日出生的公民孩子，拟2028年入学 | 经CEU申请延期或延后入学。 |
| 同日出生的PR孩子，拟2028年入学 | MOE问答允许参加2027年小一报名。 |
| 已获CEU延期批准且已取得学校位置 | 告知学校并按其手续衔接延后入学；不能再参加下一年的小一报名。 |
| 已获CEU延期批准但还没有学校位置 | 参加下一年的小一报名。 |

来源：[MOE：延期与已有学位](https://www.moe.gov.sg/faq?categoryid=99F9F9282C3049E38838F410F292357B)、[公民与PR的不同分支](https://www.moe.gov.sg/faq?categoryid=17EF23F543444142955C9817E6C53B25)。

居住在新加坡、1996年1月1日之后出生的公民儿童受义务教育要求约束；私立或海外课程的安排应先核MOE批准及适用豁免。PR及外国孩子的申请条件按各自路径处理。[MOE：义务教育与小一报名](https://www.moe.gov.sg/faq?categoryid=17EF23F543444142955C9817E6C53B25)

### 阶段资格、名额与结果

2026年报名使用Phase 1、2A、2B、2C及2C Supplementary等阶段。Phase 1面向有兄姐正在该小学就读的公民或PR孩子；仅住在学校一公里内，不能取得Phase 1资格。家长是该校旧生，可在Phase 2A报名，仍可能因超额而抽签。义工、获认可的社区领袖及其他优先资格，要在当届阶段检查器和学校核认可条件与所需证明；学校的义工招募要求各有不同。[MOE：阶段资格](https://www.moe.gov.sg/faq?categoryid=65AF36CE05034FB99C2705FDFAB78E5E)、[外国孩子不适用Phase 1](https://www.moe.gov.sg/faq?categoryid=A7B0B51A79FC4652A9EE81E77A17C09E)、[阶段及日期入口](https://www.moe.gov.sg/primary/p1-registration/registration-phases-key-dates)

Phase 2C对家长有无学校关联均开放；仍有余位的学校才会开放Phase 2C Supplementary。每个阶段只能为孩子申请一所学校，录取不按先到先得。没有录取，就在下一个合资格阶段选有余位学校；2C Supplementary仍不成功的孩子，MOE会安排有余位学校，结果通过报名门户和短信通知。[MOE：阶段安排](https://www.moe.gov.sg/faq?categoryid=65AF36CE05034FB99C2705FDFAB78E5E)、[报名事项](https://www.moe.gov.sg/faq?categoryid=2662B55F532E40368F35394CD97CD2E5)、[名额分配](https://www.moe.gov.sg/faq?categoryid=2F9980DC0E2D4217ACA58B28672A4D04)、[未录取的下一步](https://www.moe.gov.sg/faq?categoryid=1139BF5BD5BE498ABBF8082B3467901A)

学校超额时，公民优先于PR；再按适用的住家与学校距离类别处理，同一类别超额会由MOE集中电脑抽签。部分学校在Phase 2C及2C Supplementary有PR名额上限，学校名单及各阶段可供PR的余位须查当届公布资料；这个上限不套到PR兄弟姐妹的Phase 1报名。[MOE：抽签](https://www.moe.gov.sg/faq?categoryid=1139BF5BD5BE498ABBF8082B3467901A)、[PR名额限制](https://www.moe.gov.sg/faq?categoryid=71DE17DF588D46E6A86204485C67CF9B)

准备2027年报名、2028年入学的家庭，应核该届正式阶段、保留名额、适用学校与抽签安排，再安排义工、住房和搬家。这里的2026年日期及条件须与下一届公告逐项对照。[MOE：小一当届入口](https://www.moe.gov.sg/primary/p1-registration)

### 住址、距离及30个月居住要求

先在当年[OneMap School Query](https://www.onemap.gov.sg/school)核住家与学校距离类别。MOE按学校地界至住所楼宇轮廓的最短距离计算，通勤路程或手机地图的步行距离不能直接替代。学校迁址、地界或住宅楼宇资料改变，可能使类别变化；报名前须查报名当年的资料。[MOE：距离与住址问答](https://www.moe.gov.sg/faq?categoryid=E3E39C0FD0F04504A444B1F600CC8430)

普通住址按报名家长身份证（National Registration Identity Card，NRIC）所列、家长与孩子实际居住的地址处理。父母NRIC地址不同，可用其中一方的地址，但须是报名家长与孩子居住处。因距离类别获得优先录取的孩子，有至少30个月的居住要求；2026年普通住址规则的起算日为报名开始的 **2026年6月30日** 。租客要安排足以满足要求的租期。经认可的活跃社区领袖资格录取也涉及30个月居住要求。[MOE：30个月起点、租房、父母不同地址及社区领袖](https://www.moe.gov.sg/faq?categoryid=E3E39C0FD0F04504A444B1F600CC8430)

搬家后仍在原来同一住家至学校距离类别，可按MOE问答从新地址继续履行居住要求；如果新地址超出原类别，且不能满足要求，MOE可决定转到另一所学校，家长无权指定接收学校。无法提供MOE满意的居住证明，也可能触发转校。[MOE：搬家与证明要求](https://www.moe.gov.sg/faq?categoryid=E3E39C0FD0F04504A444B1F600CC8430)

以下替代地址要在注册前核条件和批准：

| 拟用地址 | 需核的条件 |
| --- | --- |
| 孩子的祖父母，或家长的兄弟姐妹地址 | 申请替代照护声明时父母双方均全职工作，孩子由所列亲属照顾，并在上学后继续有相应平日放学照护安排。须先收到MOE批准邮件；只有作声明的家长可用该地址报名。 |
| 已批准的照护亲属地址距校不超过2km | 与同一身份、居住在1km至2km类别的孩子一起抽签，即使照护地址本身在1km内也如此。超过2km则归同身份的超过2km类别。 |
| 已买但尚未竣工的住宅 | 核正式Vacant Possession Date／Delivery Possession Date（VPD／DPD，房屋交付日期），不能用预计竣工日代替；2026报名对应的VPD／DPD须不晚于2028年12月31日。另核实际迁入及30个月居住要求的适用起点。 |
| 正在办理购入的转售住宅 | 须能提供主管认可的购房承诺及交易尚在完成的证明，并核居住要求。 |
| 已与照护亲属同住，NRIC地址相同 | 可按本人的NRIC地址报名，无须另作替代照护声明；若获距离优先，仍须履行适用居住要求。 |

来源：[MOE：替代照护声明、批准与距离类别](https://www.moe.gov.sg/faq?categoryid=FC5BB3094F074536AEBBCA4303234A4D)、[新房、转售及实际住址](https://www.moe.gov.sg/faq?categoryid=E3E39C0FD0F04504A444B1F600CC8430)。照护声明有早于相关报名阶段的截止期，不应等到Phase 2C开放才开始办。

### 在线报名、监护与系统受阻

家长须用本人的Singpass及双重验证进入P1 Registration Portal；一名合资格家长提交即可。门户地址资料以报名当年5月31日父母NRIC记录为基准，当前地址或替代地址不同，须使用门户内的在线表格。看不到孩子、阶段或学校资料时，先让另一名有权访问的家长登录；仍看不到，可按门户指引用在线表格报名。[MOE：报名门户与资料纠错](https://www.moe.gov.sg/faq?categoryid=F61369DB2D624A40ACA9C73104E3F213)

同一阶段要改申请，由原提交家长在截止前删除旧申请并重新提交，MOE取最后提交的一份。已在上一阶段获得学位、拟改报下一阶段学校，须先由原家长成功撤回已获位置，否则后续申请不处理。多名孩子在同一申请内时，删除会同时影响其中全部孩子。[MOE：修改、撤回与多子女申请](https://www.moe.gov.sg/faq?categoryid=F61369DB2D624A40ACA9C73104E3F213)

共同监护的家长对选校无法达成一致，可通过Family Justice Courts（家事法院）或适用的Syariah Court（回教法院）申请教育决定所需命令；MOE建议尽量提前至少三个月处理。另一方失联与另一方明确不同意的手续不同，已有单独监护或选校决定权限，也须按法院文件及门户表格办理。不能只凭日常照顾孩子便认定可以单方决定。[MOE：共同监护、失联与法院命令](https://www.moe.gov.sg/faq?categoryid=2662B55F532E40368F35394CD97CD2E5)、[门户访问与单独决定权限](https://www.moe.gov.sg/faq?categoryid=F61369DB2D624A40ACA9C73104E3F213)。需要法律帮助，见[法律援助与委托律师]({{< relref "/book/rights/legal/getting-help.md" >}})。

没有可用Singpass、无法设置双重验证，或门户持续报错，应在孩子所属报名阶段的注册日 **上午9时至下午4时30分** 通过拟报名学校的官方电话或电邮求助，保留提交时间、错误截图及往来邮件。小一注册全部在线，联系学校是请求协助完成适用手续；不能假定普通到校询问已算报名。[MOE：在线注册受阻的协助](https://www.moe.gov.sg/faq?categoryid=2662B55F532E40368F35394CD97CD2E5)

## 外国孩子读小一：意向、学校安排与身份变化

外国孩子须在MOE公布的Indication of Interest窗口提交意向；错过指定日期和时间，就不能参加当届Phase 3。意向不是注册，也没有学校选择。MOE会在公民与PR已经分配学位后，按剩余名额等因素安排外国孩子，不能保证有学位。[MOE：意向及分配](https://www.moe.gov.sg/faq?categoryid=A7B0B51A79FC4652A9EE81E77A17C09E)

提交后应看到成功确认页，并收到表格副本邮件；保存确认页，核孩子身份、出生日期和联系方式。意向期内修改资料须重新交表，只取最后一份；窗口后按MOE指定的修改表处理，可能须上传证明。撤回意向后，孩子不能再参加当届Phase 3。[MOE：确认、修改与撤回](https://www.moe.gov.sg/faq?categoryid=A7B0B51A79FC4652A9EE81E77A17C09E)

2026年已表达意向、正在等待2027年小一安排的家庭，按MOE问答应在10月底前收到是否获学位的邮件。查看登记邮箱与垃圾邮件夹；有位置时，只能向邮件指定学校注册，再按该校通知交证明和报到。未获位置，或想改换获安排学校，Phase 3分配结果不接受上诉，学校也不收临时到校申请入学或转校；可考虑私立学校，或在合龄条件下申请下一轮AEIS的小二入学。[MOE：结果、指定学校与未录取](https://www.moe.gov.sg/faq?categoryid=A7B0B51A79FC4652A9EE81E77A17C09E)

正在为孩子申请公民或PR身份，也应在意向窗口先提交。孩子在公民与PR的报名活动期间取得新身份，须撤回外国学生意向，并在合资格阶段报名；若活动结束后才取得身份，按MOE问答先等意向结果邮件，再提交结果邮件、孩子出生与护照资料、新身份或入境／再入境许可证明及父母证件。不要仅凭申请回执就改孩子的报名身份。[MOE：申请中的身份及获批后处理](https://www.moe.gov.sg/faq?categoryid=A7B0B51A79FC4652A9EE81E77A17C09E)

## AEIS与S-AEIS：先核当届年级、出生日期和英语成绩

Singapore Examinations and Assessment Board（SEAB，考试主管机构）受MOE委托办理这些考试的注册与考试管理。

| 考试 | 提供的入学年级 | 学年关系 |
| --- | --- | --- |
| Admissions Exercise for International Students（国际学生入学考试，AEIS） | 小二至小五、中一至中三 | 考试的下一学年入学。 |
| Supplementary Admissions Exercise for International Students（补充入学考试，S-AEIS） | 小二至小四、中一至中二 | 考试的同一学年入学。 |

来源：[SEAB：AEIS](https://www.seab.gov.sg/aeis/about-aeis/)、[S-AEIS](https://www.seab.gov.sg/s-aeis/about-s-aeis/)。因此，AEIS 2026对应2027入学，S-AEIS 2027对应2027入学；AEIS 2027则对应2028入学。

申请前应在MOE的[AEIS资格页](https://www.moe.gov.sg/international-students/aeis/eligibility-criteria)及[国际学生当届公告](https://www.moe.gov.sg/international-students)核完整出生日期、所准报考级别、入学年，以及小学要求的Cambridge English Qualifications（CEQ，剑桥英语考试）类型和剑桥英语量表（Cambridge English Scale，CES）最低分。孩子在海外读几年级、英语补习班说适合什么课程，均不能代替这项核对。无法查到适用分档时，把出生日期、目标入学年及已有成绩单交SEAB／MOE，请其明确对应条件，再决定付费报名。

小学须先取得合要求的CEQ成绩，再申请相应数学测试；中学考英语与数学。CEQ成绩须在申请期内交，不能报名后补交；成绩对应的考试须在申请月份之前12个月内。已经提交的一组CEQ成绩按该次申请处理，重新考到更高分不应假定可以替换。2026申请页所列“2025年7月起”或“2025年1月起”的考试日期，是对应2026 AEIS及S-AEIS的说明，不能用于推算2027全部窗口。[SEAB：CEQ提交与12个月](https://ask.gov.sg/seab/questions/cmcvbp7tf002d13wyb0mcqpvn)、[AEIS材料](https://www.seab.gov.sg/aeis/application-procedures/)、[S-AEIS材料](https://www.seab.gov.sg/s-aeis/application-procedures/)、[MOE：CEQ成绩及录取问答](https://www.moe.gov.sg/faq?categoryid=D1FDE07370F74F04B63B4592E161CBA1)

上轮AEIS申请小五未成功者，S-AEIS没有小五入学，只能在符合允许年龄等条件下再申小四；SEAB小学流程也列出相应B1 Preliminary for Schools成绩承接说明，应把考试日期和成绩交主管核。曾获学位但没有接受者，MOE允许在符合年龄条件下再申请，原学位可能作废；SEAB当前S-AEIS流程同时说明，曾获学校位置者不能再直接网上报名，应先找SEAB处理原记录。[MOE：重报及小五转小四的条件](https://www.moe.gov.sg/faq?categoryid=D1FDE07370F74F04B63B4592E161CBA1)、[SEAB：S-AEIS小学流程第1页](https://file.go.gov.sg/s-aeis-pri-key-activities-and-milestones.pdf#page=1)

各轮报名只能在正式公布的窗口办理，逾期不受理，考试位置满额也可能提前关闭。2027的具体报名与考试日、出生日期分档和小学最低CES分数，须查该轮原表；安排培训、机票或离开现有学校前，先取得适用条件及日期。[SEAB：逾期规则](https://ask.gov.sg/seab/questions/cm5f0cx4v008f13bz7wxujhsm)、[S-AEIS报名流程](https://file.go.gov.sg/s-aeis-sec-key-activities-and-milestones.pdf#page=1)、[MOE：当届考试入口](https://www.moe.gov.sg/international-students)

### 申请、应考与结果

1. 核当届资格、报名日期和CEQ成绩；按ICA入境条件确认孩子能到新加坡应考。
2. 在开放期依SEAB指引建立孩子的Candidates Portal（考生门户，CP）账户，准备出生证及必要英文译本、至少还有六个月有效期的护照资料页、小学CEQ成绩单，以及主管要求的补充家庭文件。CEQ成绩单须交，Cambridge证书本身无须提交。
3. 通过CP交材料并付款。SEAB列信用／借记卡和PayNow；已支付费用不退。申请显示Pending时仍待审核，要检查Remarks及登记邮箱。
4. 材料齐全且被判定合资格时，SEAB说明至少四周才可把状态更新为Registered，缺件会更久；获准后依邮件从CP取Entry Proof（准考文件）。
5. 按准考文件查考场和时间，至少提前45分钟到场、提前15分钟就座；带护照资料页与准考文件复印件。
6. 到公布期在相应的AEIS Internet System或S-AEIS Internet System查学校安排，按学校通知注册、交证明与报到。

来源：[SEAB：AEIS申请全文](https://www.seab.gov.sg/aeis/application-procedures/)、[S-AEIS申请全文](https://www.seab.gov.sg/s-aeis/application-procedures/)、[应考材料与时间](https://www.seab.gov.sg/aeis/test-details/)、[AEIS结果系统](https://www.seab.gov.sg/aeis/release-of-school-offers/)、[S-AEIS结果系统](https://www.seab.gov.sg/s-aeis/release-of-school-offers/)。

备考按拟入学年级的前一级内容，例如申小三要熟悉小二数学，申中二要熟悉中一英语与数学；数学测试不允许计算器，须按要求写解题步骤。需要残障或考试便利安排，报名之前向SEAB说明具体需要并核本项入学测试的手续，不把其他全国考试的截止日套用到AEIS。[SEAB：准备内容](https://ask.gov.sg/seab/questions/cm79ro0nx00dgzvz0byxy4xvu)、[AEIS测试](https://www.seab.gov.sg/aeis/test-details/)、[S-AEIS测试](https://www.seab.gov.sg/s-aeis/test-details/)

准考文件不提供入境许可。学校录取结果也不在CP发布；学校安排取决于测试表现、所报拟居区域与余位，没有指定学校选择，CEQ达标也不保证录取。[SEAB：赴新应考](https://www.seab.gov.sg/aeis/about-aeis/)、[MOE：分配、CEQ及准证条件](https://www.moe.gov.sg/faq?categoryid=D1FDE07370F74F04B63B4592E161CBA1)。结果未成功时，核下一轮合龄年级、已有英语成绩是否仍有效，并安排孩子继续接受教育。

CP登录、建户、上传或字段错误，可从SEAB联络页选择“Tests for Admissions or Placement Exercises”的技术协助表；其他问题用一般查询表。不能使用网上入口，可拨 **6970 6255** ：通常周一至周五上午9时至下午5时，公共假期及所列半日关闭安排另看官网。到访协助仅限特定服务并须预约，官方要求至少提前两个工作日提出；不能直接到访当作补报名。[SEAB：联系、电话与预约](https://www.seab.gov.sg/contact-us/)

## 回流、转校和特殊教育需要

MOE的Returning Singaporeans包括在海外生活学习的公民及PR孩子。已有Leave of Absence（LOA，保留学籍安排）先联系原校；没有保留位置者，符合Assured School Placement（学位保证安置服务）条件可获靠近住所、适合孩子且有余位的学校，不能保证指定学校。没有当地住所可申报拟居区域。小学通常无须先考入学试，但学校入学后可评估适合年级；中学可有评估或面谈。[MOE：回流安置及LOA](https://www.moe.gov.sg/faq?categoryid=F8ACA3ABB7DD42799138FD6D8D34D9AA)

主流学校的公民或PR孩子在小一至小五、因搬家转校，可核Primary School Transfer Service；其他原因或中学转校先找现校。外国孩子过去在新加坡主流学校读过、拟申请重新入学，应先结清尚欠MOE学校账款并交指定在线表，MOE可能建议参加AEIS、准许回原校或拒绝，按个案处理。[MOE：小学转校](https://www.moe.gov.sg/faq?categoryid=FFCA2C16536A4CC1AE64080BA2917D31)、[外国学生重新入学](https://www.moe.gov.sg/faq?categoryid=D1FDE07370F74F04B63B4592E161CBA1)。具体转学、监护文件和离境续期见[学校生活与转校]({{< relref "/book/people/school/school-life.md" >}})。

轻度特殊教育需要、认知能力可接国家课程并能在较大班级学习的孩子，可循主流学校小一报名；中重度需要或支持需求较高者，应准备合适的Special Education（特殊教育，SPED）学校申请。已向SPED学校提交申请的家长，无须再参加小一报名。以具体学习及适应需要讨论学校选择，带完整评估与现有支持资料，另核目标学校的年龄、申请窗口、身份与学额条件。[MOE：特殊需要与小一安排](https://www.moe.gov.sg/faq?categoryid=17EF23F543444142955C9817E6C53B25)、[学习支持及SPED申请]({{< relref "/book/people/school/learning.md" >}})。

## 国际及私立学校：先核课程、注册和合同

向学校索取拟入读年级的课程、语言及学习支持、评估、学额、完整报价和合同。核学费、申请／注册费、发展费、校车、膳食、设备和考试费是否含GST，何时付款，以及退学通知、退款与转校安排。课程与身份收费、经济帮助和母语申请见[学校课程与费用]({{< relref "/book/people/school/learning.md" >}})；付款与签字前可用[合同检查]({{< relref "/book/rights/contracts/before-signing.md" >}})。

Skills and Workforce Development Agency（SWDA，技能与劳动力发展主管机构）对适用的私立教育机构办理注册与相关许可。用TPGateway当前[私立教育机构（PEI）与课程名录](https://www.tpgateway.gov.sg/resources/information-for-private-education-institutions-(peis)/pei-listing)核机构、获准课程及EduTrust状态；注册本身不代表政府保证教学质量或未来院校必定接受学历。需要通过外国学制学校办理Student’s Pass时，ICA要求该校有EduTrust认证。[TPGateway：注册及认证问答](https://www.tpgateway.gov.sg/faq/private-education-institutions)、[ICA：外国学制学校](https://www.ica.gov.sg/reside/STP/apply/fss)

适用的费用保险保护学校无法继续营运时尚未使用的课程费。签前向学校或保险方核自己的保障与付款安排；普通退学退款仍须看合同，不能直接把停办保险当任意退学退全费的承诺。[TPGateway：课程费保护](https://www.tpgateway.gov.sg/resources/information-for-private-education-institutions-(peis)/protection-of-course-fees)

## 拿到学校通知后，核孩子自己的准证与报到

Immigration & Checkpoints Authority（ICA，移民与关卡主管机构）要求外国人参加获准全日制课程时办理STP，但孩子本人持有效DP、LTVP或Immigration Exemption Order（IEO，移民豁免令）时，可在现有证件有效期内读全日制、非宗教课程。现有证件在学习期间到期或被取消，须按当时STP资格申请，才能继续学习。读获准宗教学校时，持DP或LTVP也须办理STP；持有效IEO者仍可豁免。短访课程豁免仅限在准证有效期或30天内完成、独立完整且符合其他要求的短课，不适用于整段小学或中学课程。[ICA：学习准证及例外](https://www.ica.gov.sg/reside/STP)、[宗教学校例外](https://www.ica.gov.sg/reside/STP/apply/gov)

| 学校类别 | STP申请前需准备 |
| --- | --- |
| 政府、政府辅助或ICA所列独立学校 | 学校Registration Acknowledgement Letter（注册确认信）；本地担保人须公民或PR、年满21岁，不能用公司或组织担保。有SC／PR父母或继父母者，该父母／继父母须担任担保人。 |
| 外国学制或私人资助学校 | 该类别学校的注册确认信、适用注册与EduTrust资格；按ICA对应流程申请，不把前一类别的本地担保条件自行套入。 |

来源：[ICA：政府／政府辅助／独立学校](https://www.ica.gov.sg/reside/STP/apply/gov)、[外国学制及私人资助学校](https://www.ica.gov.sg/reside/STP/apply/fss)。

这两类STP的新申请及续期，应在课程开始前至少两个月、至多三个月提交。准备旅行证件、适用出生与家庭资料、住址、近三个月照片和所需官方英文翻译。外国出生、年龄12岁0天或以下的孩子，还须按ICA要求向Communicable Diseases Agency（CDA，传染病主管机构）提交疫苗资料。向ICA交非英文文件时，须用使领馆、合资格公证人翻译，或经所列使领馆认证／公证的私人译本。[ICA：时间、材料与翻译](https://www.ica.gov.sg/reside/STP/apply/gov)、[外国学制申请](https://www.ica.gov.sg/reside/STP/apply/fss)

STP处理中可留在境外；ICA建议先申请，再按批准安排来新完成签发，申请处理中不能据此延长在新的停留。学校录取不保证STP签发，现有证件的到期日仍须处理。签发、续期、转校及孩子入境手续见[ICA证件管理]({{< relref "/book/life/documents/arrival-renewal.md" >}})，疫苗衔接见[儿童预防保健]({{< relref "/book/people/healthcare/preventive-care.md" >}})。[ICA：申请期间与完成手续](https://www.ica.gov.sg/reside/STP/apply/gov)、[MOE：录取与STP](https://www.moe.gov.sg/faq?categoryid=D1FDE07370F74F04B63B4592E161CBA1)

向学校报到前，逐项核清注册是否完成、孩子的有效就学及居留证件、到校日期、尚待核验的文件和账单。需要语言、读写或听觉沟通帮助，就把要核的问题写下来，请学校说明可用协助及书面回复；教学虚构问句：“孩子持DP，出生日期是……，拟入学年是……；请确认应报哪一项考试、英语成绩要求，以及我们还欠什么材料。”入学后的通知、接送、课后照顾及保护安排见[学校生活]({{< relref "/book/people/school/school-life.md" >}})，办事表达见[电话、邮件与口译]({{< relref "/book/people/language/communication.md" >}})。
