雇用住家家政人员（migrant domestic worker，MDW），先确定谁作雇主、家里能否提供安全住宿，再把工资、外劳税、食宿、医疗和休息日的替补照护一起算进预算。雇主须获 MOM 批准并办理她的 Work Permit；委托中介申请后，家庭仍须履行日常雇主责任。[MOM：雇主条件](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/eligibility-and-requirements/employer-requirements)、[申请手续](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/apply-for-work-permit)

## 先安排照护需要和住宿

把一周的工作写出来：家务、接送孩子、照顾长者、夜间协助分别需要多长时间，家人在什么时间接手。面谈时说明家里的人数、宠物、房间与睡眠安排，让应聘者讲清自己做过哪些工作、用什么语言沟通、哪些任务需要培训。家人轮班和后备照顾者也应先排好，便于她休息、看病或回国探亲。

如果只需要定期清洁或临时家务，可以从 MOM 的 [Household Services Scheme（HSS）公司名单](https://www.mom.gov.sg/faq/work-permit-for-foreign-worker/what-is-household-services-scheme)找服务。部分参与公司提供基本长者看护；需要护理或医疗操作时，应另找相应专业服务，并核执行人员的经验和训练。HSS 基本儿童看护试点的人力优惠已从 **2026年3月** 停止；不要凭旧试点介绍假定仍有同样安排。

住家 MDW 需要有通风、安全、能保护隐私的睡眠空间及基本寝具。MOM 建议提供独立房间；若确实无法提供，也须保证足够空间和隐私，不能安排她与成年或青少年男性同房。签约前就应让她知道实际住宿条件。[MOM：住宿、隐私与生活需要](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/employers-guide/rest-days-and-well-being)

## 谁来申请，能否成为雇主

雇主须年满21岁、不是未解除破产者，并具备理解和承担雇主责任的心智能力。MOM 会评估家庭照护需要、支付雇用开支的能力和住宿安排。单身人士也可按实际需要和经济能力申请。MOM **不公开统一最低收入门槛** ；已婚申请人可合并配偶收入，没有收入者可提交存款等证明，由 MOM 评估。[雇主条件](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/eligibility-and-requirements/employer-requirements)、[单身申请](https://www.mom.gov.sg/faq/work-permit-for-fdw/can-any-single-person-employ-an-fdw)、[收入评估](https://www.mom.gov.sg/faq/work-permit-for-fdw/what-is-the-minimum-income-needed-to-employ-an-fdw)、[没有收入时](https://www.mom.gov.sg/faq/work-permit-for-fdw/can-i-employ-an-fdw-if-i-dont-have-any-income)

| 申请人的身份或情况 | 申请前核对 |
| --- | --- |
| 新加坡公民、PR | 按一般雇主条件申请；若需亲属共同承担经济责任，另核下方特别计划 |
| Employment Pass、S Pass、PEP 持有人 | MOM 明确允许申请；准备护照、准证及家庭和收入证明 |
| LTVP 持有人 | 申请时须持有效 LTVP，并符合其他雇主条件；提交自己实际准证和家庭情况 |
| ONE Pass、EntrePass、DP、Student's Pass、其他 Work Permit，或短期访客 | 不能用 EP、S Pass 或 LTVP 的答复替这些类别确认资格；付款前向 MOM 提交具体准证名称、签发机构、有效期、住所与收入资料，确认由谁申请 |

前三类的依据分别见 [一般及特别计划](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/apply-under-a-special-scheme)、[EP／S Pass](https://www.mom.gov.sg/faq/work-permit-for-fdw/can-an-employment-pass-or-s-pass-holder-employ-an-fdw)、[PEP](https://www.mom.gov.sg/faq/work-permit-for-fdw/can-a-personalised-employment-pass-holder-employ-an-fdw)及 [LTVP](https://www.mom.gov.sg/faq/work-permit-for-fdw/can-i-hire-an-fdw-if-i-am-holding-a-long-term-visit-pass)。其他类别的逐项资格未由这些答复解决，可经 [MOM 查询入口](https://www.mom.gov.sg/contact-us)取得个案答复。

EP、S Pass、PEP 家庭通常须提交本人及配偶当期或上一评税年的所得税评税通知书，或同意 MOM 向 IRAS 核实收入。刚到新加坡、没有本地评税通知书时，写明原因，并提供载有入职日和月薪的雇主信；无法提供指定材料时，可按官方说明补其他收入证明、海外税单或本地定期存款证明。[MOM：外籍雇主的材料及替代证明](https://www.mom.gov.sg/faq/work-permit-for-fdw/can-an-employment-pass-or-s-pass-holder-employ-an-fdw)

首次雇用者须参加 Employers' Orientation Programme（EOP），至少在提交申请前两个工作日完成。课程有课堂与线上形式；因健康、行动或特定孕产情况不能亲自参加者，须按 MOM 条件申请代表安排。[MOM：EOP、课程及代表条件](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/eligibility-and-requirements/employers-orientation-programme-eop)

### 需要亲属帮忙承担开支

MOM 有两类特别计划，雇主、共同申请人及担保者均须为公民或 PR，共同申请人和担保者须年满21岁；各人须符合相应条件，不能只借用亲属姓名递交：

- **Joint Income Scheme** ：公民或 PR 雇主可与同住、非配偶的合资格家庭成员合并收入；雇主须21岁或以上、未处于未解除破产状态，收入较高者作雇主。
- **Sponsorship Scheme** ：供60岁或以上、没有收入、家中没有同住在职成年人的公民或 PR 雇主申请，可由最多两名合资格亲属担保；雇主仍须有能力理解和承担责任。

共同申请人和担保者也承担相关生活照顾及外劳税责任。网页与 **2026年6月15日版申请表** 对可参与的亲属列举并不完全一致；申请表还列有担保者年龄、不同住及已有雇用／担保关系等限制。用子女、父母、兄弟姐妹以外的亲属，或担保者自己已有 MDW 时，先向 MOM 核实能否参加，再签署和付款。[MOM：特别计划](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/apply-under-a-special-scheme)、[申请表第3页的参与条件](https://www.mom.gov.sg/-/media/mom/documents/services-forms/passes/fdw-appln-form.pdf)

需要第二名 MDW 时，也须单独获准。MOM 列出的情况包括本人或配偶60岁以上、同住有两名18岁以下孩子、同住父母／岳父母／公婆60岁以上，或同住有经 AIC 确认符合相关外劳税优惠条件的残障者；仍要证明经济能力及足够住宿、隐私空间。[MOM：第二名 MDW](https://www.mom.gov.sg/faq/work-permit-for-fdw/can-i-hire-a-second-fdw)

## 先列完整预算，再看外劳税优惠

以下金额为新元。工资、中介服务费、保险保费和机票会随实际合同变化，先拿分项报价，再看家庭预算能否长期承担。

| 开支 | 核对方法 |
| --- | --- |
| 工资 | 与员工议定，并按向 MOM 申报的工资支付；MOM 没有为 MDW 规定统一最低工资。来源国的合同、出境及使馆要求另核 |
| 外劳税（levy） | 一般第一名每月300元，后续每名450元；合资格优惠为每月60元。不足整月按 MOM 账单处理；MDW 不缴 CPF |
| Work Permit 手续 | 申请35元，签发35元；中介代办费另列，不把中介报价当政府收费 |
| 食宿及生活用品 | 由雇主提供足够食物、合适住宿和基本生活需要，预留实际新增开支 |
| 医疗和保险 | 包括看病、定期检查、强制医疗及人身意外保险；保额与保费是不同数字 |
| 其他 | EOP、首次来新者的 SIP、初次体检、交通、替补照护、返程机票及合同约定费用 |

工资及费用依据：[MOM：工资要求](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/employers-guide/salary-guidelines)、[MDW 最低工资答复](https://www.mom.gov.sg/faq/work-permit-for-fdw/do-i-need-to-pay-a-minimum-wage-to-my-fdw)、[外劳税](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/foreign-domestic-worker-levy/paying-levy)、[政府申请费与入境准备](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/apply-for-work-permit)。可把报价放入 [家庭预算]({{< relref "/book/work/finance/household-budget" >}})，同时预留保险不赔或医疗费超出保额时的支出。

非马来西亚籍 MDW 通常还须有 **5,000元保证金安排（security bond）** ，一般向银行或保险公司购买保证；这是雇主对政府的保证责任，不能把5,000元当成一笔一律缴清的政府申请费，也不能转嫁给员工。保证须在她入境前生效。按规定取消准证、送她回国并履行保证条件后，MOM 才解除保证责任；欠薪、未履行遣返等违约可能导致没收。[MOM：保证金形式、生效及解除](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/eligibility-and-requirements/security-bond)

### 每月60元优惠看受照顾者的条件

外劳税优惠须有合资格人士住在同一家庭。每名合资格人士对应一名 MDW，每户最多两名享优惠；第二名也要有第二位合资格人士。[MOM：外劳税优惠](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/foreign-domestic-worker-levy/levy-concession)

| 合资格人士 | 主要条件及登记 |
| --- | --- |
| 未满16岁的公民儿童 | 父母作为雇主时，优惠从孩子出生起自动计算；其他雇主须把孩子加入 FDW eService 家庭成员记录 |
| 67岁或以上公民 | 本人或配偶达到年龄时自动处理；其他同住公民须与雇主 NRIC 地址相同，并列入家庭成员 |
| 67岁或以上 PR | PR 雇主须有公民配偶；PR 配偶须有公民雇主；雇主或配偶的 PR 父母／祖父母，则须雇主或配偶为公民，并符合地址与家庭成员记录条件 |
| 残障者 | 新加坡注册医生确认至少一项日常生活活动需要协助；须为公民，或有公民父母、配偶或子女的 PR，并符合相同 NRIC 地址及家庭成员登记条件，向 AIC 申请并取得推荐 |

这里的长者优惠年龄是 **67岁** ；特别计划或申请第二名 MDW 所用的60岁条件不能用来替代。完成条件与登记后，优惠及追溯调整应在之后两张账单内反映；没有出现时，使用同页儿童或长者／残障者查询表核查。家有 PR 或外国儿童，不会仅因孩子年幼就取得公民儿童这项优惠。[MOM：各类别及账单核查](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/foreign-domestic-worker-levy/levy-concession)

外劳税通常须在下个月17日缴纳，遇周末或公假顺延至下一工作日，可用 GIRO 或 PayNow；留意扣款结果。员工海外休假连续至少七天，可申请相应期间豁免，一历年最多60天；本地医疗机构的新加坡注册医生签发的住院病假也有独立条件及年度上限。按账单发生后的申请窗口和所需证明办理，勿自行少缴。[MOM：缴税](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/foreign-domestic-worker-levy/paying-levy)、[豁免条件与申请](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/foreign-domestic-worker-levy/apply-for-levy-waiver)

## 核中介、面谈与三种文件

选中介前，在 [MOM EA Directory](https://www.mom.gov.sg/eservices/services/employment-agencies-and-personnel-search)核公司和经办人员；查看牌照、MDW 安置及留任记录，并检查撤销、暂停或监察名单。面谈时用实际工作场景问经验，不凭国籍、外貌或广告口号判断照护能力。请中介说明语言沟通、培训、到岗时间、不合适时的安排及每笔收费。[MOM：怎样看中介记录](https://www.mom.gov.sg/faq/work-permit-for-fdw/how-do-i-check-an-employment-agencys-track-record-for-fdws)

新申请 MDW 须为女性，申请时23岁至未满50岁，来自 MOM 批准的来源地，并有至少八年正规教育及认可证明；50岁或以上现有员工可续期至60岁。来源地目前包括孟加拉国、柬埔寨、香港、印度、印度尼西亚、澳门、马来西亚、缅甸、菲律宾、韩国、斯里兰卡、台湾和泰国。她不能是雇主亲属，须在申报住址居住；在本地转雇者按转雇手续办理。[MOM：员工资格](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/eligibility-and-requirements/fdw-eligibility)

以下文件要分别阅读、保存：

| 文件 | 应写清什么 |
| --- | --- |
| 雇主与 EA 的书面服务协议 | 中介服务范围、费用、替换安排、退款、安置贷款处理及争议解决；EA 必须与 MDW 雇主签书面服务协议 |
| 雇主与 MDW 的雇用合同 | MOM 鼓励书面订立；双方商定工资、工作、休息日、休息日补偿、休假、贷款记录、终止通知及代通知金 |
| Safety agreement | 雇主和员工须签安全协议；中介负责安排时，三方各留一份，用员工母语解释擦窗等安全条件 |

[MOM：中介服务协议](https://www.mom.gov.sg/faq/employment-agencies/what-must-be-included-in-an-eas-service-agreement-with-an-fdw-employer)、[雇用合同及安全协议](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/employers-guide/contracts-and-safety-agreement)

MDW 不适用 Employment Act 的一般雇员工时和假日制度，休假等安排需要在合同中谈清，同时遵守 MDW 的专门休息、安全和照顾要求。首次来新者在 SIP 后、到家工作前签安全协议；其他新雇用者在派到雇主家前签，原员工续约除外。[MOM：合同适用范围和签署时间](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/employers-guide/contracts-and-safety-agreement)

从2026年10月1日生效的中介牌照条件明确要求：EA 应以客户理解的语言清楚解释文件，填妥表格，并留足时间让客户阅读、问清后再签。不要签空白表，也不要接受“中介叫我这样做”作为扣证件或违反雇用条件的依据。[MOM：2026年牌照条件修订，第1—2页](https://www.mom.gov.sg/-/media/mom/documents/employment-agencies/ea-alerts/2026/ea-alert-280926-amendments-to-ealc-to-take-effect-from-1-oct-2026.pdf)

### 安置贷款、代理费与退款

把雇主付给中介的服务费、替员工垫付的 placement loan 和员工本人的代理费分开列账。新加坡 EA 向员工收取的代理费，以每年服务期一个月固定月薪、总额最多两个月固定月薪为上限；固定月薪包括基本工资及固定津贴。员工可核对自己 IPA 上的工资与本地代理费，收费超限时向 MOM 求助。[MOM：员工代理费及 IPA](https://www.mom.gov.sg/faq/employment-agencies/how-will-foreign-workers-know-the-amount-that-they-are-expected-to-pay-the-singapore-ea)、[计算工资组成](https://www.mom.gov.sg/faq/employment-agencies/what-component-of-a-worker-s-salary-does-mom-base-the-fee-cap-on)

雇主签 EA 服务协议时就要看清：员工提前离职，未还安置贷款能退多少、何时退、由谁承担。MOM 要求中介在合同中列明此类退款安排；也有不要求雇主垫安置贷款的服务可供选择。[MOM：未还清安置贷款时提前离职](https://www.mom.gov.sg/faq/work-permit-for-fdw/what-can-i-do-if-my-fdw-wants-to-end-her-employment-contract-early-but-has-not-repaid-her-placement-loan)

对2022年6月1日起签订的相关 EA 服务合同，若 MDW 雇用在首六个月内终止，符合条件的雇主可获 **至少50%的中介服务费退款** 。应在终止前及时通知 EA，不能先取消准证、遣返或转雇再通知。退款排除情形包括：EA 只做行政手续而未配对；雇主违反雇用法例或对员工犯罪；已更换最多两名员工且其中一人工作超过六个月，或已提供第三名替换者；服务协议明确为照顾特定家人而雇用，但该家人去世或移至其他照护、已不住在该地址。EA 不能自行追加退款资格条件。[MOM：退款条件](https://www.mom.gov.sg/employment-agencies/refund-of-ea-service-fee)

首六个月从开始雇用算到准证取消或书面请求 EA 终止雇用的较早日期。申请、SIP、体检等指定程序费用、来源国政府要求费用、雇主要求的第三方培训及安置贷款等排除项目不算可退服务费。逐项核账后书面请求退款；EA 须在书面请求或准证取消两者较迟日起14个工作日内退款。[MOM：六个月怎样计算](https://www.mom.gov.sg/faq/employment-agencies/how-is-the-first-six-months-of-the-mdw-employment-calculated)、[费用项目及退款时限](https://www.mom.gov.sg/employment-agencies/refund-of-ea-service-fee)

## 从申请到可以开始工作

境外新雇用者，应先取得员工书面同意，备齐家庭、收入和个人材料，再由雇主、担保人或 EA 申请。一般非马来西亚籍员工不应在申请期间先入境等批准；应核实 IPA、入境所需保证与保险，并按来源国要求办好出境手续。没有 Singpass 的雇主可走 MOM 指定表格途径：下载电子表填写后按入口提交材料，不要打印空表代替规定格式。[MOM：申请方式、材料及入境前要求](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/apply-for-work-permit)

家中有未满7岁、尚未完成麻疹疫苗接种的儿童时，雇主须确保 MDW 对麻疹有免疫力；应在申请和入境准备时向中介及医生核对所需证明。[MOM：有幼儿家庭的麻疹免疫要求](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/apply-for-work-permit)

安排抵达和开始照护时，把以下几件事排进日历：

1. 首次来新工作的 MDW 须在抵达后七天内参加一天的 SIP，计算时不含星期日及公假，也不能安排在抵达当天；费用由雇主承担，完成后才可开始工作。
2. 抵达后两周内做所需体检，并按 MOM 要求在期限内签发 Work Permit；IPA 是原则批准，不能用来跳过正式签发手续。
3. 给员工完整的批准／准证文件，按通知办理指纹、照片及领卡；记录实际开始工作日，并保存政府缴费和保险凭据。

[MOM：SIP 时间与费用责任](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/eligibility-and-requirements/settling-in-programme-sip)、[签发与领卡步骤](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/apply-for-work-permit)

新申请是否批准、可入境日期和签发期限，以具体申请结果为准。电子服务申请通常约一周，表格途径通常约三周；补件会影响安排。拒批或资料不全时，先按结果说明补证或处理上诉，尚未解决前另排照护。续期、地址及准证管理见 [领取、续期与管理准证]({{< relref "/book/life/documents/pass-management" >}})。

## 工资、每周休息与日常相处

工资周期不得超过一个月，须在周期结束后七天内付清，至少达到向 MOM 申报的月薪。若员工要求通过个人银行账户收薪，雇主须照办；账户不能与雇主联名。现金支付要有双方签署的工资记录。雇主不能替她保管工资、银行卡或存折，即使她提出代管也不行。[MOM：工资支付、记录及保管限制](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/employers-guide/salary-guidelines)

帮她了解转账记录和汇款费用，让她自己掌握账户和验证方式；开户材料与账户选择可看 [银行与支付]({{< relref "/book/work/finance/banking" >}})。贷款、代垫费用和工资分别留凭据，双方看得懂每月实际收入与余额，遇到分歧及时请中介或 MOM 协助。

MDW 每周有一天休息日，星期几由双方约定；双方同意在部分休息日工作时，每一天须在基本月薪之外至少加付一天工资，按 **月薪÷26** 计算。每个月至少有一天不能用钱补掉；可以休整天或分为两个半天，员工可选择留在家休息。该月确有无法休到的情况，按 MOM 规则最迟延至下个月月底前休完。[MOM：休息日安排](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/employers-guide/rest-days-and-well-being)、[休息日工资公式](https://www.mom.gov.sg/faq/work-permit-for-fdw/how-do-i-calculate-my-fdws-pay-in-lieu-of-a-weekly-rest-day)

家庭排班时，应写明员工日常睡眠、吃饭和休息时段；若夜间常需照顾婴儿或长者，由家人轮班或增加其他照护。用她理解的语言逐项示范器具和工作，定期谈哪些任务做不完、哪里需要帮助。沟通可以用简单文字或翻译工具，但要请对方复述确认，尤其药物、过敏和紧急联系资料。

每日要提供足够饭食，MOM 要求三餐，并顾及她的宗教与饮食需要。家中装有摄像头，要事先告知位置，不得在睡觉、更衣、洗浴等会侵犯员工隐私的位置安装。护照及 Work Permit 应由她随时自由取用；“防止弄丢”或员工同意代存，都不能成为雇主扣留证件的理由，可提供她自己使用的抽屉或柜子。[MOM：饮食、摄像头与生活需要](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/employers-guide/rest-days-and-well-being)、[护照和准证不得代管](https://www.mom.gov.sg/-/media/mom/documents/employment-agencies/ea-alerts/2023/ea-alert-012023-employers-are-not-allowed-to-retain-their-migrant-domestic-workers-passports-and-wor.pdf)

## 照顾家人、工作地点与安全

MDW 只能为自己的雇主、在申报的住宅地址做家务工作，不能派去商店、摊位或公司，也不能替别人兼职，即使在休息日也一样。[MOM：可做的工作及地点](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/employers-guide/employment-rules)

若家里孩子或父母白天在亲属家，需要她在那里协助照顾，须 **事前通知 MOM** 、取得员工书面同意，并确保她不需要同时承担两家的整套家务。若在那里过夜，也要有适当住宿；原雇主仍承担工资、食宿和医疗等责任。[MOM：在亲属家照顾孩子或父母的条件](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/employers-guide/employment-rules)

照顾婴幼儿、卧床或行动不便的家人时，可把面试和入职培训落到具体任务：接送时谁交接，跌倒或发烧时联系谁，移位、进食和用药由谁指导，员工离开时谁接手。需要护理判断或专业操作，先让照护团队评估、安排训练，并确保有人可联系。不能把“有照顾老人经验”直接当成能独自处理所有护理需要。

擦窗尤其要按安全协议做。除了位于地面层或面向公共走廊的窗口，清洁窗外侧须有已锁紧的防护窗花，并由雇主或能履行监督责任的成年人全程在场。员工须留在房内，除手臂外不得把身体伸出窗沿。家中没有这些条件，就不要安排她做该项工作。[MOM：安全协议及附件 A 的擦窗条件](https://www.mom.gov.sg/-/media/mom/documents/employment-agencies/fdw/safety-agreement-between-mdw-and-employer-bahasa-indonesia-apr-2026.pdf)

## 看病、保险和独立面谈

雇主负责员工必要的医疗费用，包括超过保险赔付额的部分，不能要求她分摊。入境前须买医疗保险与人身意外保险，保费由雇主承担：[MOM：医疗费用责任](https://www.mom.gov.sg/faq/work-permit-for-fdw/can-i-get-my-fdw-to-co-pay-her-medical-expenses-that-exceed-the-insurance-benefit-limit)、[保险要求](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/eligibility-and-requirements/insurance-requirements)

- 医疗保险涵盖住院及日间手术，年度最低赔付限额60,000元。2023年7月1日起生效的增强要求，对超过15,000元的索赔部分由保险公司承担75%、雇主承担25%；这25%由雇主付。2025年7月1日起生效的新保单、续保或延保另有统一排除条款及符合索赔条件后直接向医院付款等要求。
- 人身意外保险每年保额至少60,000元，保障突发意外导致的永久残障或死亡，赔偿给员工或其受益人。MDW 不在 Work Injury Compensation Act 的保障范围内，不能省掉这项保险。[MOM：MDW 与工伤赔偿法](https://www.mom.gov.sg/faq/work-permit-for-fdw/are-fdws-covered-under-the-work-injury-compensation-act)

买保险时请保险公司列明门诊、既往疾病、除外责任、索赔文件和先行付款安排；实际保单条件会影响可赔金额。员工生病先安排合适诊疗，不能等索赔结果才看病。就医分流见 [在新加坡看病]({{< relref "/book/people/healthcare/getting-care" >}})。

按 MOM 通知安排六个月体检（6ME），雇主付费，由新加坡注册医生在诊所完成，雇主及代表不得进入诊室陪同。检查包括规定的妊娠、传染病筛查及身体状况；各项目频率不同，按收到的表格办理。50岁及以上员工无需例行6ME，但续期时仍须体检。境外休假或临近结束雇用时，按条件申请延期／豁免；检查未通过时应依 MOM 规定处理准证和返国，不能自行忽略结果。[MOM：6ME 项目、频率、例外与结果](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/eligibility-and-requirements/six-monthly-medical-examination)

首次来新的 MDW 第一工作年须参加两次由 CDE 代 MOM 进行的独立面谈，收到通知后安排时间。雇主可协助交通和到场，但不要进入面谈室；被选中的家庭也须配合 MOM 家访，让员工单独回答。如果通过 EA 雇用，中介须在到户后三个月内至少做一次安置后检查。准备替补照护，保证她有实际机会参加。[MOM：独立面谈、家访及中介检查](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/publications-and-resources/employment-rules/three-mandatory-measures-to-check-if-your-mdw-is-fitting-into-her-job-well)

## 回国休假、转雇或结束雇用

### 回国探亲后继续工作

先书面约定休假日期、工资与机票安排。海外休假期间是否付薪及由谁负担假期机票，按合同约定；未约定时双方先商量清楚。雇主仍要核护照、准证有效期及来源国回程手续，并按条件申请外劳税豁免。[MOM：海外休假](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/employers-guide/overseas-leave-for-fdw)、[休假工资](https://www.mom.gov.sg/faq/work-permit-for-fdw/must-the-employer-pay-the-salary-of-their-fdw-when-she-is-on-overseas-leave)、[休假机票](https://www.mom.gov.sg/faq/work-permit-for-fdw/who-should-pay-for-an-fdws-air-ticket-if-she-goes-on-overseas-leave)

如果她不再回来工作，应按规定取消准证，并留存离境和取消记录；取消后再回来工作须重新申请。[MOM：休假后不返回的处理](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/employers-guide/overseas-leave-for-fdw)

### 想换雇主

员工、现雇主及新雇主先确认意愿和交接日。直接转雇时，新雇主先向现雇主确认员工已完成6ME，再通过电子服务取得现雇主同意，随后提交新 Work Permit 申请；核对6ME和提交申请这两步均须在现准证到期前至少30天完成，时间不足时由现雇主先申请延期。收到 IPA 后，新雇主准备自己的保险、所需保证及双方签署的声明。新准证须按 IPA 指定期限、在双方约定的交接日签发，员工才开始为新雇主工作；原准证届时自动取消。[MOM：直接转雇流程与期限](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/transfer-to-a-new-employer)

如果需要 EA 接手寻找新雇主，应取得员工同意，确认中介愿意并有资格接手，签清交接安排，再由 EA 按专门程序取消准证作转雇用途。接手中介须承担过渡期住宿、生活、医疗保险等责任；若 Special Pass 到期前找不到新雇主，由 EA 承担返国费用。仅把员工送到中介处，并不等于法定责任已转移。[MOM：经 EA 转雇](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/transfer-to-new-employer-through-ea)、[2026年10月起牌照条件15A](https://www.mom.gov.sg/-/media/mom/documents/employment-agencies/ea-alerts/2026/ea-alert-280926-amendments-to-ealc-to-take-effect-from-1-oct-2026.pdf)

### 结束合同并返国

雇主或员工都可按合同通知期终止，未能给足通知者按合同付代通知金，双方也可同意缩短或免除。员工确实无法付代通知金时，MOM 鼓励商量可行安排；未还清安置贷款则依 EA 服务合同处理退款和争议。[MOM：终止合同](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/employers-guide/contracts-and-safety-agreement)、[无法支付代通知金](https://www.mom.gov.sg/faq/work-permit-for-fdw/my-fdw-wants-to-end-her-employment-contract-without-serving-notice)

准备返国时，按顺序完成：

1. 确认最后工作日，结清工资及员工提出的其他雇用事项；有未解决争议时及时找 MOM 或中介处理。
2. 核护照和目的地、过境要求，与员工书面商定航班衔接、转机等候及途中生活费。
3. 雇主购买含托运行李的返程机票，并承担到其本国、接近家乡的国际入境口岸所需衔接交通费用。即使员工提前辞职，结束雇用的返国费用仍由雇主承担。
4. 一般须在最后工作日后一周内取消 Work Permit，离境日期须在取消后两周内。员工仍在新加坡时，取得并交给她 Special Pass，核实际有效期并确保按时离境；准证已到期也要处理合法停留。

[MOM：取消、结清、机票及 Special Pass](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/cancel-a-work-permit)、[提前终止时谁付返国费用](https://www.mom.gov.sg/faq/work-permit-for-fdw/who-pays-for-sending-an-fdw-home-if-the-contract-is-terminated-early-either-by-the-employer-of-the-fdw)

取消后就不能再工作，外劳税计至取消前一天。她已离境且不再回来工作时，须在离境后一周内取消；最后保存取消、出境及保证责任解除的记录。[MOM：取消后的工作、税费与离境](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/cancel-a-work-permit)

### 家庭或雇主身份发生变化

雇主去世后，家属须在去世日起一个月内安排取消并送员工回国，或转雇给另一名家属／雇主；亲属接手也须申请新准证及购买保险，原长者外劳税优惠可能终止。[MOM：雇主去世](https://www.mom.gov.sg/faq/work-permit-for-fdw/what-should-the-family-do-if-an-fdws-employer-passes-away)

若外籍雇主自己的 MOM 准证失效，MOM 区分“已申请新的 MOM 准证或 PR、正在等结果”和“未申请或申请失败”。前者可在等待期间继续雇用；后者须按官方规定安排转雇或返国，网页列有自雇主准证取消起14天的转雇期限。接近取消日或收到拒批结果时，立即向 MOM 核具体办理日期，并安排照护衔接；不能靠员工的准证尚未到期就继续原安排。[MOM：雇主准证失效后的处理](https://www.mom.gov.sg/faq/work-pass-general/i-am-an-mdw-employer-but-my-mom-issued-pass-is-no-longer-valid-can-i-continue-to-hire-my-mdw)

## 双方怎样求助

工作节奏、语言或家规有分歧，可以先把具体问题、双方意见及可试行的安排写下来，请 EA 或 CDE 协助沟通。与 EA 的服务费或退款争议，先按服务协议的争议解决机制提出，保留合同、收据及往来记录；未解决时可考虑调解或适用的小额索偿途径。[MOM：雇用与中介争议](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/employers-guide/resolving-disputes)

欠薪、不给足食物、过劳或虐待，可以直接求助，不必等中介愿意介入。员工本人或知情者准备姓名／FIN、雇主或中介资料、工资记录、消息及就医资料，说明目前是否安全；拿不到全部证据也可先联系。MOM 对受困 MDW 有专门渠道：[欠薪求助](https://www.mom.gov.sg/faq/work-permit-for-fdw/how-can-an-fdw-report-that-her-salary-has-not-been-paid)、[过劳或食物不足的报告方法](https://www.mom.gov.sg/faq/work-permit-for-fdw/what-should-i-do-if-an-fdw-has-not-been-paid-is-overworked-or-not-given-enough-food)。
