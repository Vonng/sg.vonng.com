在新加坡赴约或收件，准备好完整地址、单位号和六位邮编，再确认实际入口。出门前也看一下目的地附近的天气：全年湿热，短距离步行可能遇到强烈日照或骤雨，有遮蔽、能休息的路线往往更实用。

## 地址从街道读到门口

新加坡的地址由门牌、街道、单位号（如有）和六位邮编组成。单位号中的 `#` 后先写楼层，连字符后是该单位的编号。例如 `#08-123` 表示第八层的 123 号单位；`#B1-02` 则在地下一层。正式编号以获批的楼层和单位为准，按门牌与电梯标识找路。[IRAS 门牌与单位号手册，第 1、6 页](https://www.iras.gov.sg/media/docs/default-source/uploadedfiles/pdf/hn-handbook.pdf?sfvrsn=aa992812_11)

以下是 **教学虚构地址，不能用于投递或导航** ：

```text
Chen Mei
123 Example Grove
#08-123 Example Court
Singapore 000000
```

| 部分 | 怎样理解 |
| --- | --- |
| `Chen Mei` | 收件人或到访联系人 |
| `123 Example Grove` | 楼栋或门牌号，加街道名；门牌中的字母也要保留 |
| `#08-123` | 第八层、123 号单位；楼层与单位号分开填写时照表格拆开 |
| `Example Court` | 示例中的建筑名称，便于现场辨认 |
| `Singapore 000000` | 国家名称与六位邮编的位置；这里的数字只是占位示范 |

组屋地址中常见的 `Blk` 是 Block 的缩写，用来提示楼栋。填写表格时，把街道中的 `Road`、`Street`、`Avenue` 及数字照原地址保留；不要仅凭相似的地名补全。IRAS 也允许特定门牌带字母后缀，例如 `12A` 与 `12B`，因此少一个字母可能就指向另一处。[IRAS 门牌编号说明，第 3—5 页](https://www.iras.gov.sg/media/docs/default-source/uploadedfiles/pdf/hn-handbook.pdf?sfvrsn=aa992812_11)

先用 [OneMap](https://www.sla.gov.sg/geospatial/onemap/) 核对街道、建筑与附近路线，再请联系人确认入口。医院、校园、大型公寓或商场可以有多个出入口；需要接送时，另存下大堂、落客点或指定门的名称。没有单位号的地址，不要自己补一个；收到不完整地址时，向收件人核实后再寄送。

## 全年湿热，季候风改变降雨节奏

新加坡靠近赤道，全年温度变化相对小。MSS 用 1991—2020 年作气候参考期，其说明中的典型夜间低温约为 23—25°C、日间高温约为 31—33°C，年平均相对湿度约 82%。这是长期气候特征，某一天仍可能更热、更凉或更湿。接近赤道也使白昼长度全年较稳定，实际日照时数则很受云量影响。[MSS 新加坡气候](https://www.weather.gov.sg/climate-climate-of-singapore/)

| 大致时期 | 常见天气节奏 |
| --- | --- |
| 12 月至 3 月初：东北季候风 | 前段较湿，可出现持续降雨；后段通常较干、风较明显 |
| 3 月下旬至 5 月：季候转换 | 午后与傍晚雷雨较常见，也有炎热午后 |
| 6 至 9 月：西南季候风 | 仍有阵雨雷雨；苏门答腊飑可在黎明前至中午带来强风和降雨 |
| 10 至 11 月：季候转换 | 午后与傍晚雷雨较常见，通常比上一次转换期更湿 |

季候风时间有大致范围，不能把某个月当成保证晴天的“旱季”。午后局地雷雨与持续数天的季候风降雨，也会给行程带来不同影响。[MSS 季候与降雨表](https://www.weather.gov.sg/climate-climate-of-singapore/)、[天气系统说明](https://www.weather.gov.sg/learn_weather_systems/)

日常通勤可以随身带伞，并给步行和换乘留一些余量。看房则把天气带进观察：窗户能否在下雨时安全关闭、晾衣空间是否可用、从楼下到车站的遮蔽是否连续。若需要在家长时间工作或照护家人，也试着在通常在家的时段感受房间通风和日晒，别只看夜间灯光下的照片。

## 出门前看预报，户外活动再看热压力

先在 [MSS 天气网站](https://www.weather.gov.sg/) 或 myENV 查看预报、雨区和闪电信息。局地天气变化快，要看目的地和路线周边，而不只看全岛一个图标。已有雷雨时，优先找建筑物内避雷，停止骑行或水上活动；不要站在高处、大树下或金属围栏旁。SCDF 的雷电指引列有这些避险方法。[SCDF 2026 应急手册，第 54 页](https://www.scdf.gov.sg/docs/default-source/comm.---volunteers-%28docs%29/2026-scdf-emergency-handbook%28eng%29_final.pdf?sfvrsn=52538979_3)

如果路面已积水，改走安全路线，避开水渠和排水口；持续关注 PUB 的积水警报。myENV 可开启大雨、水渠水位和突发积水通知。遇到生命危险或需要紧急救援，按[紧急求助说明]({{< relref "/book/rights/safety/emergencies" >}})联系救援，并报出完整位置。[SCDF 洪水指引，第 55 页](https://www.scdf.gov.sg/docs/default-source/comm.---volunteers-%28docs%29/2026-scdf-emergency-handbook%28eng%29_final.pdf?sfvrsn=52538979_3)

长时间在户外运动或步行，再查看 **热压力（Heat Stress）** 。MSS 采用湿球黑球温度 WBGT，综合温度、湿度、风和日照，不能拿天气预报的气温直接套用。一般公众指引的中等等级建议减少户外活动、规律到阴凉或室内休息；高等级建议尽量减少户外活动，增加休息频率或时长。[MSS 热压力解释](https://www.weather.gov.sg/learn-heat-stress/)、[2026 年热压力活动指引](https://www.weather.gov.sg/wp-content/uploads/2026/04/Manage-HeatStress-Eng-2026.pdf)

这一指引主要帮助一般公众安排较长时间的户外活动。儿童、老人、孕妇、患病或刚从较凉气候地区来的人，应更谨慎地调整强度和休息；户外工作者、学生等按各自部门或学校的指引执行。夜间仍可能湿热，天黑也不代表高强度运动没有热风险。[MSS 指引对象与夜间热风险](https://www.weather.gov.sg/learn-heat-stress/)

日照还涉及紫外线。MSS 提醒，通常上午 11 时至下午 3 时的紫外线最强；其 UVI 读数来自樟宜测站，不同地点和云雨条件可有差异。安排户外时段时，同时考虑遮阴、遮阳衣物和防晒。网页若提示传感器维护或数据缺失，不要把空白或旧读数理解为安全信号。[MSS 紫外线指数说明](https://www.weather.gov.sg/weather-uv/)
