在新加坡，“本地人”“新移民”“外籍人士”常出现在同一场讨论里，却可能分别指国籍、出生地、到来时间或工作身份。要理解一个人的生活处境，先弄清这些词在当时指什么，再看他与家庭如何居住、工作、照护和建立联系。

## 出生地、国籍与居留身份分别看

统计局的“居民人口”包括公民和永久居民（PR）；“非居民人口”包括在新加坡工作、求学或生活、但未取得 PR 的外籍人士，不包括游客和短期访客。这是人口统计口径，不能用来判断个人所得税上的税务居民。[SingStat：人口定义](https://www.singstat.gov.sg/find-data/explore-data-themes/population/population-and-population-structure/our-data-explained)

| 常用说法 | 还要补问的信息 |
| --- | --- |
| 本地出生 | 现在是什么国籍、在哪里成长；出生地点不能代替当前身份 |
| 新移民 | 指最近来居住、最近成为 PR，还是最近入籍；讨论采用什么时间范围 |
| 新公民 | 已取得新加坡公民身份；文化适应、语言和原有家庭联系则因人而异 |
| PR | 是永久居民但并非新加坡公民；在新生活多年的人也可能仍是 PR |
| 外籍工作者 | 是哪类工作准证、做什么工作、雇主及家庭安排怎样 |
| 跨国家庭 | 家庭成员各自的国籍、居留、工作与就学条件，以及谁住在哪个国家 |

例如，刚成为公民的人可能已在这里生活多年；在新加坡出生的孩子，也需要按自己的公民或居留身份办理事务。学校、医疗、住房和工作资格，应回到[身份与资格]({{< relref "/book/life/documents/status-and-eligibility.md" >}})逐人确认，不能仅凭全家都在新加坡居住作判断。

## 定居也包含关系和归属

迁徙史不只发生在过去的港口和劳工招募中。今天一个家庭可能同时与新加坡的学校、邻里及海外父母保持紧密联系。到来较早、刚来、本地出生的人，都可能经历换学校、换语言环境、建立朋友关系和重新安排照护。

新公民的表达也有不同重点。NPTD 在 2012 年公民仪式报道中记录 Suksri Lumprasert 的话：她的配偶和两个孩子都是新加坡公民，入籍表达了自己对家庭与未来的承诺；她也把社区活动视为建立归属的一条途径。这是当年一位受访者的经历，说明定居可以包含家庭与参与的意义，不能代表所有新公民的理由。[NPTD：2012 年公民仪式与受访者表达](https://www.population.gov.sg/media-centre/national-citizenship-ceremony-2012-coming-together-to-build-a-brighter-future-for-all/)

建立联系，可以从共同做一件小事开始：固定参加兴趣活动、与家长或同事约一次交流、参加有明确安排的志愿项目。先问活动用什么语言、费用多少、是否需要报名，以及自己能稳定投入多少时间。对邀请者而言，也要考虑轮班、照护、交通和参加费用；一个人没有出席，未必是不愿与邻里来往。

## 外籍工作者有多种生活条件

MOM 公布的 2026 年 6 月外籍劳动力共有约 165.59 万人，包含下面这些类别。这是工作人口统计，不能拿来代替所有非居民人口；没有工作的家属与学生也在城市生活。[MOM：Foreign workforce numbers](https://www.mom.gov.sg/foreign-workforce-numbers)

| 2026 年 6 月类别 | 人数 | 阅读时的边界 |
| --- | ---: | --- |
| Employment Pass（EP） | 204,300 | 不代表每个人都是长期定居或收入与家庭安排相同 |
| S Pass | 177,300 | 不与 EP 或 WP 的条件互换 |
| Work Permit 总数 | 1,243,600 | 已包括下列家政及建筑、海事船厂、加工业群体，不能再次相加 |
| 其中：移工家政人员（MDW） | 323,800 | 属于家庭雇用的专门准证安排 |
| 其中：建筑、海事船厂、加工业（CMP）WP | 490,700 | 是 WP 的行业子集，未覆盖所有 WP 工作者 |
| 其他工作权限类别 | 30,700 | MOM 表注包括 LOC、PLOC、培训工作准证和培训就业准证等 |

专业人士、技能岗位雇员、建筑或服务业工人、家政人员，会面对不同的雇用、居住和家属安排。“Expat”或“外劳”等日常称呼不能代替准证类别，也不适合用来推断一个人的教育、收入、语言或对新加坡的感情。具体职业、雇主、家属与换工作条件见[工作准证]({{< relref "/book/life/documents/work-passes.md" >}})。

学生与家属另有各自的工作条件。Student’s Pass、MOM DP、ICA 与 MOM LTVP，以及 LOC、PLOC 等分支的工作条件不同。准备就业时，应先核实本人权限和雇主需要完成的手续，不能把无偿帮忙、兼职或远程工作一概视为不受规则影响。

## 听工作者怎样描述自己的生活

TWC2 的 Discover Singapore 项目介绍中，参加者 Madhavra 提到长工时、外出费用，以及家人在印度带来的孤独感；组织提供的外出活动让他有机会接触平日较难负担的城市空间。项目也记录移工参加龙舟训练等活动。这里看到的是具体参加者与项目的经历，不是所有外籍工作者的生活调查。[TWC2：Discover Singapore](https://twc2.org.sg/helping-workers-in-need/discover-singapore/)

家政人员的工作场所又常与雇主的家庭空间重叠。HOME 在 2025 年发表其庇护服务使用者 Sara 的写作：她描述为了支持家人来新工作，面对反复辱骂和互相矛盾的工作指令，逐渐失去自信。这是组织工作坊记录的一名求助者陈述，不能换算成整个家政行业的发生率；但它提醒雇主和读者，工作指令、休息空间与日常称呼会直接影响一个人的生活。[HOME：Sara 的陈述](https://www.home.org.sg/my-voice/2025/4/4/you-are-just-a-helperstay-as-a-helper)

与工作者交往时，可以使用其姓名，直接听取需要，并先征得同意再拍照或分享经历。雇用关系涉及合同和工作条件时，应使用相应的正式沟通与申诉渠道；一句“当作家人”不能替代清楚的工作安排。

## 跨国家庭要把每个人的条件写清

同一个家庭可能包括新加坡公民、PR、持 ICA LTVP 的配偶、持工作准证的另一位成年人，以及不同身份的子女。婚姻、亲属关系和同住本身，不能替全家取得同一种居留或工作权限。第一步是制作一张家庭记录：

- 每人的国籍、准证签发机构、有效期及续期负责人。
- 本人能否工作、孩子的学校或入学安排、医疗保障和实际费用。
- 房屋合同上的承租人与同住者，及任何申请所采用的家庭成员范围。
- 海外照护、汇款、证件保管，以及工作或关系变化时需要联系的机构。

关系良好时先把这些事情说清，可以减少其中一人独自掌握所有资料造成的不确定。工作变动时，核对本人和家属准证是否联动；婚姻或照护发生变化时，也应逐项确认，不能自行延用旧资格。

研究能够帮助看见家庭困难的具体来源。AWARE 在 2020 年发布的《Migrant Wives in Distress》分析其 2016—2018 年求助热线、法律诊所记录及已有研究；热线资料辨认出至少 137 名曾与新加坡男性公民结婚的非居民女性，所述问题涉及居留、家暴、离婚和住房。该组资料来自主动求助者，部分身份资料也未完整取得；不能把它当作所有跨国婚姻的代表性样本，更不能拿报告中的旧政策说明代替今天的准证规则。[AWARE：原始报告，第 3—7 页](https://www.aware.org.sg/wp-content/uploads/AWARE-Report-1-June-2020-Migrant-Wives-in-Distress.pdf)

## 按问题找到支持

| 当前需要 | 可以先联系什么渠道 |
| --- | --- |
| 准证、家属工作权限或雇主变化 | ICA／MOM 相应服务；先整理准证、关系、日期和具体问题，入口见身份与工作准证主文 |
| 跨国婚姻准备、适应与沟通支持 | MSF 的跨国伴侣婚姻准备／支持项目及其列出的服务机构，询问语言、资格、安排与所需文件 |
| 跨国家庭的居留、住房、医疗、教育或离婚问题交织 | Pro Bono SG 与 South Central 的 Transnational Family Care Centre，先申请评估 |
| 移工或家政人员遇到困难 | HOME 的移工／家政求助热线，说明语言、工作身份与紧迫事项；正式劳动申索仍须另按主管程序和期限处理 |
| 正面临人身危险、急病或暴力 | 按[紧急求助]({{< relref "/book/rights/safety/emergencies.md" >}})使用相应紧急渠道 |

MSF 说明鼓励新加坡人与其拟结婚的非居民伴侣参加婚姻准备和支持项目。 **如果 ICA 的 LTVP 原则批准要求完成指定项目** ，应在 IPA 到期前完成并上传结业证明；未按要求完成会被视为撤回申请，需要重新申请。这一条件针对收到相应要求的申请人，不能写成所有跨国夫妻都必须按同一期限上课。[MSF：项目目的、完成要求与服务机构](https://ask.gov.sg/msf/questions/cls1lenlt026hjzsgq7gzpw1p)

Transnational Family Care Centre 的公开说明针对家庭中至少有一名新加坡公民或 PR、遇到其所列困难的外籍家庭成员。社工与社区律师可协助评估教育费用、医疗、居留、住房、离婚及就业培训等问题，援助和法律代理都须经过评估。可通过 **help@probono.sg** 登记，先说明家庭成员身份、问题和已有期限；不要把发出邮件当成律师已受托或申请期限已经暂停。[Pro Bono SG：跨国家庭服务](https://www.probono.sg/get-legal-help/legal-guidance/a-transnation-family/)

HOME 当前提供电话或 WhatsApp 求助：一般移工 **+65 6341 5535** ，家政人员 **+65 9787 3122** 。联系时提供可安全回覆的方式，并询问是否需要携带合同、薪资或准证记录。该组织的服务与 MOM、警方或法庭的正式程序各有作用，不能以等候回复代替必须及时完成的步骤。[HOME：求助入口](https://www.home.org.sg/)
