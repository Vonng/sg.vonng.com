买到有问题的东西，先保存 **收据、商品描述、交付日期和故障证据** ，向实际卖家写明希望怎样解决。单纯不喜欢或买错，先看商家退换政策；商品交付时已有缺陷，则要考虑柠檬法下的修理、更换、减价或退款。协商受阻后，可向 CASE 求助，或按争议类型、金额及时限考虑小额索偿庭。

## 付款前，把退换、保修和总价问清

买衣物先看尺寸和洗护要求，买家具先量门、电梯和摆放空间；购买电器则核对型号、电压、插头、安装条件及本地售后。下单时保存页面和书面报价，把下列事项放在同一处：

| 要确认的事 | 留下什么记录 |
| --- | --- |
| 谁卖给你 | 商家正式名称、地址、订单号；平台购物另记实际卖家 |
| 总共付多少 | 商品、GST、运费、安装、搬楼和拆旧等收费；分期及续订另读条款 |
| 何时交货 | 交付日期、缺货替换和延迟处理办法 |
| 改变主意能否退换 | 时限、包装和使用条件、退货运费、退现金还是购物额度 |
| 谁负责保修 | 厂商／商家／第三方、期限、零件人工及上门费、送修地点 |

不要只听口头说“全保”“随时可退”；请对方把承诺写进订单。延长保修要看实际承保项目，二手和展示品应先记录已告知的缺陷。[CASE：投诉需要的合同与购买凭证](https://www.case.org.sg/submit-a-complaint/)

属于受管制类别的家用电器、电子及燃气产品，在新加坡销售须有 **SAFETY Mark** 。可用型号或标记上的八位注册号查询，核对结果是否与实物一致；没有匹配结果，按 CPSO 页面入口反馈。这一步用于核实产品安全注册。[消费者产品安全办公室：SAFETY Mark 查询方法](https://www.consumerproductsafety.gov.sg/suppliers/cpsr/overview-of-cpsr/)

## 先判断自己属于哪一种问题

| 发生了什么 | 先走的处理路径 |
| --- | --- |
| 颜色不喜欢、买错尺寸、后来不想要 | 按商家或平台公开的退换政策申请，并满足其条件 |
| 商品与约定不符，或交付时已有缺陷 | 保存商品及证据，向卖家提出柠檬法补救 |
| 保修期内发生故障 | 按保修条款报修，同时保留与卖家的交易记录 |
| 未送货、服务没做、报价与实际收费不符 | 写明合同未履行之处，要求商家说明、履行或退款；受阻时向 CASE 咨询 |
| 怀疑诈骗或付款资料被盗用 | 尽快联系银行、平台及警方；处理方法见 [紧急求助与安全](/book/rights/safety/emergencies/) |

柠檬法适用于在新加坡购买的一般消费商品，二手商品也可适用，但合理质量预期会考虑货龄和价格。它不适用于服务、房屋土地、租赁物品、企业对企业或个人对个人的交易；消费者自己损坏、误用、已知缺陷或正常磨损，也不能直接据此要求补救。 **单纯改变主意** 同样不属于柠檬法退款理由。[CASE：柠檬法范围及例外](https://www.case.org.sg/cpfta-lemon-law/)

私人二手交易先核对卖家身份、实物和约定；不要把平台上的每个卖家都当成经营商家。网购发生争议时，先在平台保护期内开启争议程序，同时确认卖家是否在新加坡，以便判断后续可执行的途径。

## 商品有缺陷时，怎样要求补救

通常先向卖家提出 **修理或更换** 。商家须在合理时间内处理，且不应给消费者造成重大不便；一种办法不可能或费用明显不成比例时，可以考虑另一种。无法合理修换，或商家未能按上述要求完成，才进一步要求减价或退货退款。已使用商品的退款可能考虑使用所得的价值。[METI：柠檬法补救次序说明](https://www.meti.gov.sg/resources/laws-and-regulations/general-advisory-on-amendments-to-the-consumer-protection-fair-trading-act-and-hire-purchase-act/)

交付后 **6 个月内** 发现不符合约定，一般推定问题交付时已存在，由卖家提出反证；与商品性质不相容时有例外，例如不能据此要求易腐食品维持半年。超过 6 个月仍可寻求补救，但消费者要证明交付时已有问题。这是举证规则，保修期限须另看保修条款。[METI：柠檬法 FAQ，第 1 问](https://isomer-user-content.by.gov.sg/1004/1553753e-2d89-4541-a109-1fce1bf7454d/Lemon%20Law%20FAQs.pdf)

可以这样组织一次有效的报修：

1. 写清购买和交付日期、型号、故障首次出现日期，附照片、视频或错误信息。
2. 向卖家提出希望修理或更换，要求确认接收、检修方式及预计日期；适用柠檬法的修理所需人工、材料和邮寄运输等必要费用由卖家承担。
3. 交机时取得工单，列出序列号、附件、外观状态和已描述的故障；有个人资料的设备先备份。
4. 取回后尽快测试原故障，保留每次修理结果。反复失败时，把完整记录交给卖家，提出下一步补救请求。

法律并无适用于所有商品的统一“修满几次才能换货”数字，合理时间和不便程度要结合商品用途判断。卖家承担销售合同责任，厂商另给的保修也可按其条款使用。[METI：柠檬法 FAQ，第 7、10、13 问](https://isomer-user-content.by.gov.sg/1004/1553753e-2d89-4541-a109-1fce1bf7454d/Lemon%20Law%20FAQs.pdf)

超过保修或自行找维修商时，先要检查费、零件费、人工费及修后保修的书面报价；追加工作要先同意。涉及住宅线路或管道，人员资格按 [住宅维修](/book/life/household/home-maintenance/) 核对。尚在与卖家处理原缺陷时，避免自行拆修造成进一步损坏并影响证据。

## 向 CASE 求助，需要什么

CASE 一般处理个人为自己或家庭用途，向新加坡注册公司购买商品或服务的争议；海外商家另看 CASE 的跨境合作范围。先通过 [投诉表](https://complaints.case.org.sg/) 提交合同、收据、支付记录、交货或维修单、往来消息和具体请求，等工作人员评估。身份文件可包括身份证或工作、学生、家属准证；按表格要求填写，不要在上传材料中附整张 NRIC 复印件。[CASE：受理范围、提交投诉和材料](https://www.case.org.sg/submit-a-complaint/)

不便网上办理，可拨 **6277 5100** ，周一至周五 9:00—17:00，公共假日除外。面谈须预约，地址为 **170 Ghim Moh Road，#05-01，Ulu Pandan Community Club，Singapore 279621** 。访客也可先向 CASE 或新加坡旅游局反映零售争议。[CASE：预约与联系](https://www.case.org.sg/contact-us/)、[CCS：本地消费者及旅客求助入口](https://www.ccs.gov.sg/resources/faqs/consumer-protection/)

CASE 提供咨询；需要其代拟信件或代为跟进时，先确认选择哪项服务。代拟信件的 Assisted Scheme 须预约到访，由消费者送信并自行协商；正式代为跟进通常须入会并缴行政费。当前普通年费为 **S$27.25** ，行政费按索赔额另计，符合相关团体条件者可能获豁免，申请时出示证明并请 CASE 确认。[CASE：处理方式](https://www.case.org.sg/submit-a-complaint/)、[会员及行政费用](https://complaints.case.org.sg/)

僵持后可考虑调解，需按 CASE 安排参加并确认费用。调解员帮助双方商谈，不替双方裁决；达成和解时把金额、履行日期及其他条件写清。若未解决，再评估小额索偿或其他法律途径。[CASE：调解流程](https://www.case.org.sg/mediation/)

竞争与消费者委员会 CCS 负责对持续不公平经营行为采取执法行动，个人退款求助仍应走商家、CASE 或法院的适当路径。[CCS：执法与个人补救的分工](https://www.ccs.gov.sg/resources/faqs/consumer-protection/)

## 要提小额索偿，先检查四项条件

小额索偿庭（SCT）可处理特定商品、服务等争议。通常索赔额不超过 **S$20,000** ，双方签署同意备忘录可提高至 **S$30,000** ；须在产生诉因的事件起 **2 年内** 提出，并且可在新加坡向被申请人送达。不能只为限额而把同一索赔拆成几件。住宅租约另有限于不超过两年的条件，雇佣争议不走此庭。[新加坡法院：SCT 可受理案件](https://www.judiciary.gov.sg/civil/cases-eligible-small-claim)

满足条件后，在 CJTS 做提交前评估，保存评估编号；整理当事人姓名地址、争议经过、金额及 PDF 证据。向企业索赔须备提交前一个月内取得的 ACRA 商业资料，非英文文件附英文译文。个人提交费目前为：索赔 S$5,000 及以下 **S$10** ，超过 S$5,000 至 S$10,000 为 **S$20** ，超过 S$10,000 至适用限额为索赔额的 **1%** 。[法院：提交资料与费用](https://www.judiciary.gov.sg/civil/how-to-file-serve-small-claim)

提交并付款后选咨询日期；在提交起 **7 日内** 向对方送达索赔及咨询通知，并在首次咨询前于 CJTS 提交送达声明及证明。无法送达时仍按时出席咨询，请登记官指示后续方式。SCT 程序不允许律师代表当事人出庭。[法院：送达与后续步骤](https://www.judiciary.gov.sg/civil/how-to-file-serve-small-claim)

个人通常用 Singpass 登录；不具备申请 Singpass 资格者可申请 CJTS Pass。没有电脑可使用国家法院二楼 Business Centre；系统受阻可拨 **6587 8423** 询问，出发前查开放安排。国家法院地址为 **1 Havelock Square，Singapore 059724** 。[法院：CJTS 登录及支援](https://www.judiciary.gov.sg/services/cjts)、[到访地址](https://www.judiciary.gov.sg/visit-us/state-courts)
