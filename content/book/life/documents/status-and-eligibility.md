判断自己能否在新加坡工作、读书或申请某项服务，先拿出当前有效的证件，确认 **国籍、居留身份、准证名称、签发机构和到期日** 。接着再看这件事要求的年龄、收入、家庭关系和申请时间。一个家庭可以同时有公民、PR、工作准证和家属准证成员，办事时要逐人填写。

## 先确认自己属于哪一条路

| 当前情况 | 先确认什么 | 从哪里查 |
| --- | --- | --- |
| 新加坡公民（Singapore Citizen，SC） | 公民身份，以及具体事务的年龄、家庭和收入条件 | 对应服务的公民资格条款；男性另查国民服役义务 |
| 永久居民（Permanent Resident，PR） | PR 身份及取得途径；出境安排还要看 Re-Entry Permit（REP） | ICA 的 PR 与 REP 服务 |
| EP、S Pass、Work Permit 等工作准证 | 准证类别、雇主、职业、有效性；附带的家庭准证 | MOM 的准证状态查询及该类别规定 |
| Student’s Pass 学生准证 | ICA 准证有效性、学校与课程；工作时再查 MOM 的学生豁免 | ICA 学生准证、MOM 学生工作条件 |
| Dependant’s Pass（DP）家属准证 | 主准证持有人的类别、双方关系；本人有没有另外取得工作权限 | MOM 的 DP 工作规定 |
| Long-Term Visit Pass（LTVP）长期探访准证 | **先看由 ICA 还是 MOM 签发** ，再看担保关系 | 各签发机构的 LTVP 服务 |
| 短期访客 | 入境时实际获准的停留期限、访问目的 | ICA 的电子 Visit Pass（e-Pass）与有效期查询 |

PR 可以在新加坡工作，无需另办工作准证；医生、律师等须注册的职业仍要取得相应执业资格。[ICA：PR 就业说明](https://ask.gov.sg/ica/questions/clxwhkiyj00fkdsotb37zlufh)

对于短期访客，签证负责让持有人赴新并申请入境，实际获准停留多久以入境签发的 Visit Pass 为准。SG Arrival Card 是入境申报；填写它不会取得工作或长期居留权限。需要签证的人也不能仅凭签证有效期计算最后离境日。[ICA：入境签证与停留期限](https://www.ica.gov.sg/enter-transit-depart/entering-singapore/visa_requirements)

## 家属想工作，必须看清签发机构和关系

“我是家属”“我拿 LTVP”还不足以判断能否入职。先把下面的分支核对到自己，再与雇主确定申请方式。

| 你持有的身份 | 本地就业的主要路径 |
| --- | --- |
| 普通 MOM DP 持有人 | 雇主申请 EP、S Pass 或 DP-Work Permit（DP-WP）；取得 EP/S Pass 后，居留依托本人的工作准证；DP-WP 的有效期仍依托 DP |
| 普通 MOM LTVP 持有人 | 取得本地 offer 后，由雇主申请符合条件的 EP、S Pass 或 Work Permit |
| ICA LTVP/LTVP+，且是公民或 PR 的配偶、未满 21 岁未婚子女 | 可以走 Letter of Consent（LOC，同意书）或符合资格的 Pre-approved Letter of Consent（PLOC，预先批准同意书）路径 |
| ICA LTVP，作为公民或 PR 的父母 | 可由雇主申请 Work Permit；不要套用配偶的 LOC 路径 |
| ICA LTVP，作为陪读家长 | 在新第一年不得工作；满一年后可由雇主申请 Work Permit，仍须满足该路径的要求 |
| ONE Pass 持有人的合法配偶持 DP，或获承认事实婚姻伴侣持 MOM LTVP | 有专门的 LOC 工作路径 |

普通 DP 就业规则见 [MOM：DP 持有人工作](https://www.mom.gov.sg/passes-and-permits/dependants-pass/working-in-singapore)；MOM LTVP 规则见 [LTVP 持有人工作](https://www.mom.gov.sg/passes-and-permits/long-term-visit-pass/working-in-singapore-for-ltvp-holders)。ICA 家属与陪读家长的分支见 [ICA LTVP 持有人的工作权限](https://www.mom.gov.sg/passes-and-permits/work-passes-for-holders-of-long-term-visit-passes-issued-by-ica)；ONE Pass 的配偶分支见 [ONE Pass 家属](https://www.mom.gov.sg/passes-and-permits/overseas-networks-expertise-pass/passes-for-families)。

ICA 家属 LOC 要有本地 offer，LTVP/LTVP+ 至少还有三个月有效期，由雇主或受委托中介申请，收到 LOC 后才能开工。LOC 会随居留准证到期、取消或该雇用关系结束而失效。[MOM：ICA 家属 LOC 条件](https://www.mom.gov.sg/passes-and-permits/loc-for-ica-issued-ltvp-holders/eligibility)

符合条件者可在申请或续期 ICA LTVP/LTVP+ 时选择申请 PLOC，取得 PLOC 时可以尚未找到工作。入职前向雇主出示 PLOC 和有效 LTVP/LTVP+，雇主须通知 MOM；离职后，雇主须在最后工作日起 7 日内通知。新闻编辑、记者、制片与宗教等受限制职业须按相应 LOC 路径办理。[MOM：PLOC 资格](https://www.mom.gov.sg/passes-and-permits/pre-approved-letter-of-consent/eligibility)、[入职及离职通知](https://www.mom.gov.sg/passes-and-permits/pre-approved-letter-of-consent/taking-up-employment)、[职业限制](https://www.mom.gov.sg/passes-and-permits/work-passes-for-holders-of-long-term-visit-passes-issued-by-ica)

DP 持有人经营企业另有符合条件的 LOC 路径。远程为境外机构服务、自由职业、陪读祖父母等情况还需要具体核对工作内容与身份；不要从上表某一亲属关系推导出另一关系的工作权限。

## 学生的居留和工作条件怎样衔接

外国人获全日制课程录取后，通常须向 ICA 申请 Student’s Pass。持有效 DP、LTVP 或 Immigration Exemption Order 者可在现有身份有效期间参加全日制、非宗教课程；原准证中途到期或被取消，要申请符合条件的 Student’s Pass 才能继续读书。学校录取与学生准证申请需要分别完成。[ICA：学生准证及豁免](https://www.ica.gov.sg/reside/STP/apply)

学生准证持有人工作时，先查看 MOM 的 **学校名单和学期状态** 。学期内的豁免要求包括在名单内院校全日制就读、持有效 Student’s Pass，并且每周工作不超过 16 小时，或参加由学校安排、计入毕业要求的实习。假期的学校名单和条件另列，要求年满 14 岁；交换生不能使用该学生工作豁免。毕业后学生准证到期，要取得相应工作准证再工作。[MOM：外国学生工作豁免](https://www.mom.gov.sg/passes-and-permits/work-pass-exemption-for-foreign-students)

## 公共服务资格还需要补哪些事实

查住房、医疗、教育、CPF 或补贴时，建议把所需信息整理成一张自己的办事记录：

- 谁申请、谁受益：本人、配偶、子女或父母，各自什么身份；是否属于政策认可的家庭关系。
- 年龄与日期：生日、PR 取得日、申请日、准证到期日、计划入学或入职日。
- 工作与收入：雇员、自雇、平台工作者或未就业；政策要求的是个人收入、家庭总收入还是人均收入。
- 居住与家庭：实际住址、房屋类别、同住成员、照护或无障碍需要。
- 所申请的具体项目：同一个机构的不同计划，可能采用不同资格和收入定义。

税务还会单独判断税务居民。IRAS 会按通常居住、在新停留或工作期间、跨年度安排等规则确定某个课税年度的身份；外籍人士也可能是税务居民。报税时应使用自己的工作和出入境记录，按 [IRAS 税务居民规则](https://www.iras.gov.sg/taxes/individual-income-tax/basics-of-individual-income-tax/tax-residency-and-tax-rates/working-out-my-tax-residency) 判断。

## 身份有变化时，先处理哪几件事

**离职或换雇主：** 核实新工作权限、旧准证注销日期、本人及家属的获准停留日期。以 EP 为例，注销会连带取消关联家属准证；注销后不能继续工作，获发短期停留准证时则按该准证安排离境或转换身份。[MOM：EP 注销](https://www.mom.gov.sg/passes-and-permits/employment-pass/cancel-a-pass)

**成为 PR 或申请公民：** 阅读批准文件中要求完成的手续，并核对男性本人及子女的 [国民服役条件](/book/life/documents/national-service/)。ICA 的 PR 申请入口列出配偶、子女、EP/S Pass 持有人、符合要求的学生等申请类别，同时会综合家庭联系、经济贡献等因素评估；符合申请类别不能保证批准。[ICA：申请 PR](https://www.ica.gov.sg/reside/PR/apply)

**PR 准备离境：** 提前检查 REP 是否有效。自 2025 年 12 月 1 日起，离境时无有效 REP，或人在境外时 REP 失效，须从相应日期起 180 日内申请 REP；未及时申请，或窗口内申请遭拒，会按上述情形丧失 PR。即使已经返回新加坡，并在 REP 被拒时人在新加坡，仍会失去 PR 身份。出行前从 [ICA REP 查询与现行规则](https://www.ica.gov.sg/enter-depart/for-PR/check-REP-validity) 核实自己的日期。

**家庭关系或学校变化：** 记录变化日期、现有准证的担保人和签发机构，再从该准证的更新、续期或取消服务办理。若不能确定变化是否影响身份，向签发机构说明现准证、关系变化和到期日，要求确认下一步；在取得结果前持续留意有效期。

## 怎样确认自己现在仍有有效身份

MOM 的 [准证与申请状态查询](https://www.mom.gov.sg/eservices/services/check-work-pass-and-application-status) 不要求登录，可用出生日期及 FIN 或护照号码查询 MOM 签发的准证。查询结果可保存为带查询时间的 PDF；SGWorkPass 应用也可显示最新工作准证信息。其中，网页上的薪资信息查询仅供 Work Permit 持有人使用。把查询结果及 IPA 与 offer 对照，若雇主、职位或薪资与约定不符，先向雇主或中介核实并要求更正，也可从该页联系 MOM。

ICA 的 PR、LTVP 与学生准证事项按各服务入口查状态；短期访客从 [延长停留说明](https://www.ica.gov.sg/enter-transit-depart/extend-stay) 找到 e-Pass 和有效期查询。记录应至少能确认当前准证类别、有效期限，以及所需的工作或学习权限。查询显示的信息与批准信冲突时，把两份记录及查询时间一并交给签发机构处理。
