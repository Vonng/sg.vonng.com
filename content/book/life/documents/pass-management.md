收到 MOM 的原则批准信后，先确认谁负责签发、本人何时抵达及准证必须办完的日期，再准备体检、保险、住址和领卡资料。准证签发后保存通知信，按要求登记生物特征；以后用实际准证到期日安排续期，搬家或换护照也要及时更新。

准证资格及工作权限见[工作准证与家属工作条件]({{< relref "/book/life/documents/work-passes.md" >}})；SGAC、实际入境停留和 ICA 签发的学生／长期探访准证，见[入境与 ICA 证件管理]({{< relref "/book/life/documents/arrival-renewal.md" >}})。本页的期限和费用按2026年10月查阅的 MOM 办理页说明。

## 从 IPA 到签发：先找负责的人和截止日

In-principle approval（IPA，原则批准）列出入境、体检及签发条件。本人抵达后仍须按实际获准停留期限安排手续，不能只看 IPA 的有效期。下表中的费用为签发费；适用 Multiple Journey Visa（MJV，多次入境签证）时，另有 S$30。申请、体检、保险和其他前置项目另按相应业务准备。

| 准证 | 谁办理签发 | 首次签发期限与费用 |
| --- | --- | --- |
| EP | 雇主或获委任的 employment agent（EA，职业介绍所／代理） | IPA通常给六个月进入新加坡并签发；本人须在新加坡，签发费S$225。[EP签发](https://www.mom.gov.sg/passes-and-permits/employment-pass/apply-for-a-pass) |
| S Pass | 雇主或EA | IPA通常给60天进入并签发；本人须在新加坡，S$100。[S Pass签发](https://www.mom.gov.sg/passes-and-permits/s-pass/apply-for-a-pass) |
| 产业 Work Permit（WP） | 雇主或EA | 新抵达的非马来西亚籍员工须在抵达后14天内签发；马来西亚籍员工按IPA所列日期，费用S$35。转雇主者还须在当前准证及IPA到期前完成。[WP签发](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-worker/apply-for-work-permit) |
| 移工家政人员的 Work Permit（MDW） | 雇主或EA | 抵达后两周内完成签发，S$35；同时安排入境后的SIP及体检。[MDW签发](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/apply-for-work-permit) |
| PEP | 本人或EA | IPA给六个月进入并签发，S$225；有Singpass按该页个人服务，无Singpass预约EPSC。[PEP签发](https://www.mom.gov.sg/passes-and-permits/personalised-employment-pass/apply-for-a-pass) |
| ONE Pass | 本人 | IPA给六个月进入并签发，S$225；无Singpass者预约EPSC。[ONE Pass签发](https://www.mom.gov.sg/passes-and-permits/overseas-networks-expertise-pass/apply-for-a-pass) |
| EntrePass | 本人、公司代表或EA | IPA给六个月进入并签发，S$225；无Singpass者预约EPSC。[EntrePass签发](https://www.mom.gov.sg/passes-and-permits/entrepass/apply-for-a-pass) |
| 普通MOM DP／LTVP | EP／S Pass家属由主准证雇主或EA；PEP、EntrePass及EP(Sponsorship)家属由主准证持有人办理签发 | EP家属IPA通常六个月，S Pass家属两个月，PEP／EntrePass家属六个月；签发费S$225。[DP](https://www.mom.gov.sg/passes-and-permits/dependants-pass/apply-for-a-pass)、[LTVP](https://www.mom.gov.sg/passes-and-permits/long-term-visit-pass/apply-for-a-pass) |
| ONE Pass家属DP／LTVP | 家属本人预约EPSC验证文件并签发 | IPA给六个月完成，S$225；申请可由主准证持有人直接办理，或委任EA／雇主代办。[ONE DP](https://www.mom.gov.sg/passes-and-permits/overseas-networks-expertise-pass/passes-for-families/dependants-pass-for-overseas-networks-expertise-pass/apply-for-a-pass)、[ONE LTVP](https://www.mom.gov.sg/passes-and-permits/overseas-networks-expertise-pass/passes-for-families/long-term-visit-pass-for-overseas-networks-expertise-pass/apply-for-a-pass) |

办理前核对护照姓名与IPA一致，准备护照资料、当前入境／STVP资料、本地住址、电话和所需体检／声明。卡片配送需本地地址，并可登记最多三名获授权收件人及其联系方式、证件号码。普通EP／S Pass家属申请分别由主准证雇主或EA提交；PEP／EntrePass由主准证持有人提交；EP(Sponsorship)家属的申请由本地担保人提交，随后签发角色见上表。[EP材料与签发](https://www.mom.gov.sg/passes-and-permits/employment-pass/apply-for-a-pass)、[DP申请与签发主体](https://www.mom.gov.sg/passes-and-permits/dependants-pass/apply-for-a-pass)

### S Pass、产业 WP 与 MDW 的前置安排

S Pass 须按规定备妥医疗保险，适用时还须有工伤保险；住在七名或以上员工宿舍，或属于建筑、海事业、加工业（CMP）者，签发及续期前须购买 Primary Care Plan（PCP，基层医疗计划）并申报。S Pass签发时护照至少还有七个月有效期，准证会受护照有效期限制。[S Pass准备与PCP](https://www.mom.gov.sg/passes-and-permits/s-pass/apply-for-a-pass)、[续期条件](https://www.mom.gov.sg/passes-and-permits/s-pass/renew-a-pass)

产业 WP 的非马来西亚籍员工，需要在入境前让 security bond（保证金担保）生效，并完成医疗及适用工伤保险、住宿和PCP安排。新获批员工的FIN可能在批准后三个工作日内分配，雇主须按MOM指示重新下载带FIN的IPA，再安排担保。抵达后按适用路径完成体检及入职程序；建筑业新员工还须核对BCA技能测试及验证要求。[产业WP抵达与签发准备](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-worker/apply-for-work-permit)

**Onboard Centre适用于持WP IPA、来自非马来西亚地区的男性CMP员工。** 雇主先取得住宿批准，再至少提前四天预约Onboard时段，随后订机票；抵达后直接前往中心。自2025年8月起，距上一次工作准证取消不超过两年、再次来新工作者通常参加两天安排；首次来新或超过该间隔者参加三天安排。中心要求带可用智能手机并提供免费SIM卡；自2026年5月4日起，指定体检提供者直接向MOM提交结果，雇主仍须跟进报告并在抵达后14天内完成签发。[Onboard对象、住宿、时段与体检](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-worker/sector-specific-rules/onboard-centre)

女性CMP员工、制造业员工等其他适用群体，按WP申请页的SIP及体检分支办理。非马来西亚籍新员工若无法在抵达后14天内签发，由雇主在Work Permit服务申请Special Pass，IPA按该路径自动延长；马来西亚籍员工或转雇主者的IPA需延长时，在WP Online按页面指示提出。[WP不同抵达分支与延长期限](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-worker/apply-for-work-permit)

家政人员抵达前，雇主备妥适用的非马来西亚籍保证金担保、医疗及人身意外保险。首次来新工作的MDW，须在抵达后七天内完成Settling-In Programme（SIP，适应课程），星期日和公共假期不计；所有新抵达MDW均须在14天内完成体检，再在两周内签发。家中有未满七岁且未完成麻疹疫苗接种的孩子，还须按MOM条件确认家政人员具麻疹免疫力；该要求自2025年9月1日起适用于相关申请及续期。[MDW准备、SIP、体检与麻疹条件](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/apply-for-work-permit)

### 体检未出结果，不能让停留先到期

EP、S Pass和普通MOM DP／LTVP办理页，为等待体检结果的情况列有STVP延长请求：在实际STVP到期前 **7至14天** 提出，附医生说明结果领取日期的memo。ONE Pass家属的专门页面则要求在到期前 **一周内** 提出，按本人的准证页面进入指定请求。家属申请还在审批中时，MOM不会仅因申请未有结果替其延长Visit Pass。[EP体检延期](https://www.mom.gov.sg/passes-and-permits/employment-pass/apply-for-a-pass)、[普通家属](https://www.mom.gov.sg/passes-and-permits/dependants-pass/apply-for-a-pass)、[ONE家属](https://www.mom.gov.sg/passes-and-permits/overseas-networks-expertise-pass/passes-for-families/dependants-pass-for-overseas-networks-expertise-pass/apply-for-a-pass)

## 签发后：通知信、登记与领卡

签发完成会取得notification letter（通知信），通常有效一个月。工作准证的通知信说明可在等卡期间开始工作及出入境；DP／LTVP通知信提供等卡期间的出入境安排，工作还须另有相应准证或同意书。先读信上的生物特征登记要求和有效期，需要更多时间时从对应办理页申请延长通知信。[EP通知信](https://www.mom.gov.sg/passes-and-permits/employment-pass/apply-for-a-pass)、[DP通知信](https://www.mom.gov.sg/passes-and-permits/dependants-pass/apply-for-a-pass)

如果通知信要求拍照及登记指纹，按以下地点和期限预约；不要求登记者，仍须完成文件核验及数字准证设置。

| 本人准证或家属类别 | 生物特征登记安排 |
| --- | --- |
| EP；EP家属DP／LTVP | 签发后两周内到Employment Pass Services Centre（EPSC）。[EP](https://www.mom.gov.sg/passes-and-permits/employment-pass/apply-for-a-pass)、[DP](https://www.mom.gov.sg/passes-and-permits/dependants-pass/apply-for-a-pass)、[LTVP](https://www.mom.gov.sg/passes-and-permits/long-term-visit-pass/apply-for-a-pass) |
| S Pass；S Pass家属DP／LTVP | 签发后一周内到MOM Services Centre Hall C。[S Pass](https://www.mom.gov.sg/passes-and-permits/s-pass/apply-for-a-pass)、[家属](https://www.mom.gov.sg/passes-and-permits/dependants-pass/apply-for-a-pass) |
| 产业WP及MDW | 签发后一周内到MOM Services Centre Hall C。[产业WP](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-worker/apply-for-work-permit)、[MDW](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/apply-for-work-permit) |
| PEP、ONE Pass、EntrePass | 签发后两周内到EPSC。[PEP](https://www.mom.gov.sg/passes-and-permits/personalised-employment-pass/apply-for-a-pass)、[ONE](https://www.mom.gov.sg/passes-and-permits/overseas-networks-expertise-pass/apply-for-a-pass)、[EntrePass](https://www.mom.gov.sg/passes-and-permits/entrepass/apply-for-a-pass) |
| ONE Pass家属DP／LTVP | 签发后两周内到EPSC；PEP／EntrePass家属的具体登记要求按本人通知信办理。[ONE DP](https://www.mom.gov.sg/passes-and-permits/overseas-networks-expertise-pass/passes-for-families/dependants-pass-for-overseas-networks-expertise-pass/apply-for-a-pass)、[ONE LTVP](https://www.mom.gov.sg/passes-and-permits/overseas-networks-expertise-pass/passes-for-families/long-term-visit-pass-for-overseas-networks-expertise-pass/apply-for-a-pass) |

预约时带原护照、预约信、通知信及页面所需材料。按MOM指示准备本地手机号码、Singpass与SGWorkPass；需要登记Singpass时，工作人员在登记过程中协助。本人当前不能使用所需设备或App，提前告诉雇主、EA或MOM，确认怎样完成本人验证。[EP登记材料](https://www.mom.gov.sg/passes-and-permits/employment-pass/apply-for-a-pass)、[MOM联系](https://www.mom.gov.sg/contact-us)

完成生物特征登记或文件核验后，卡片通常在五个工作日内送到所填地址，获授权收件人会提前收到配送消息。本人可用自己的Singpass登入SGWorkPass查看数字准证、状态与到期日；收到实体卡后仍须核对当前有效状态。[EP领卡与数字准证](https://www.mom.gov.sg/passes-and-permits/employment-pass/apply-for-a-pass)

两次配送失败后，通常可在第二次配送尝试的三个工作日后到指定中心领取，无需为这项补领再预约。EP及其家属到EPSC；S Pass、产业WP、MDW及S Pass家属到Hall C；PEP、ONE、EntrePass及ONE家属到EPSC。本人带准证页要求的护照／数字准证及通知信；由别人代领，还需其身份证明和授权信。 **普通雇佣类别的授权信来自雇主；PEP、ONE、EntrePass及ONE家属由相应持有人授权。** 代领前从本人的办理页核对原护照等材料。[EP补领](https://www.mom.gov.sg/passes-and-permits/employment-pass/apply-for-a-pass)、[WP补领](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-worker/apply-for-work-permit)、[PEP补领](https://www.mom.gov.sg/passes-and-permits/personalised-employment-pass/apply-for-a-pass)、[ONE家属补领](https://www.mom.gov.sg/passes-and-permits/overseas-networks-expertise-pass/passes-for-families/dependants-pass-for-overseas-networks-expertise-pass/apply-for-a-pass)

## 续期：按类别启动，再把批准做完

雇主、担保人或持有人应先核对当前资格、护照、保险及家属关系，再按自己的窗口申请。EP、S Pass和家属续期会按当时资格重新评估，获批后须完成签发才能延长准证。

| 准证 | 续期申请时间、提交人及主要安排 |
| --- | --- |
| 普通EP | 雇主或EA可在到期前六个月／180天开始，须在到期前申请；myMOM Portal通常十个工作日内处理或给更新。EP(Sponsorship)为提前三个月，用专用续期表及线上提交，通常六周。[EP续期](https://www.mom.gov.sg/passes-and-permits/employment-pass/renew-a-pass) |
| S Pass | 雇主或EA提前六个月／180天开始，通常十个工作日内处理或给更新；重新满足资格、配额、保险和适用PCP，签发费S$100。[S Pass续期](https://www.mom.gov.sg/passes-and-permits/s-pass/renew-a-pass) |
| 产业WP | 雇主或EA通常在到期前七至十二周，按WP Online续期信办理；签发费S$35。须先在OFWAS登记住址与手机，至少等一小时再续期，并备妥配额、适用保证金担保、保险、PCP及通知要求的体检。[WP续期](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-worker/renew-a-work-permit) |
| MDW | 到期前约八周收到续期信，收到后由雇主、担保人或授权EA办理，须在到期前完成；S$35，备妥新的保险／保证金担保及通知所需体检。旅行接近准证到期时，应在出境前续期。[MDW续期](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/renew-a-work-permit) |
| 普通MOM DP／LTVP | 主准证雇主或EA一般提前六个月／180天开始，须在到期前申请；有效期受主准证及所请求期限限制，通常三周。EP(Sponsorship)和EntrePass家属提前三个月，用专用表及各自提交入口，通常八周。[DP续期](https://www.mom.gov.sg/passes-and-permits/dependants-pass/renew-a-pass)、[LTVP续期](https://www.mom.gov.sg/passes-and-permits/long-term-visit-pass/renew-a-pass) |
| EntrePass | 持有人到期前三个月提交电子续期表及支持文件，通常八周；第一次续期最长一年，之后通常最长两年，签发费S$225，适用时另付MJV费。[EntrePass续期](https://www.mom.gov.sg/passes-and-permits/entrepass/renew-a-pass) |
| PEP | 一次签发最长三年，不能续期。要继续在新加坡工作，应在PEP结束前安排符合资格的EP或S Pass；雇主申请新准证时不必先取消PEP。[PEP有效期与转准证](https://www.mom.gov.sg/passes-and-permits/personalised-employment-pass/key-facts) |
| ONE Pass | 可提前六个月申请续期；每次续期五年，须满足规定的过去五年平均固定月薪，或本人经营新加坡公司及本地雇员条件。[ONE续期资格与窗口](https://www.mom.gov.sg/passes-and-permits/overseas-networks-expertise-pass/eligibility) |

EP、S Pass及普通家属在续期获批后，还须完成 **签发** 。EP续期IPA通常有效三个月，S Pass续期IPA通常60天；EP家属的续期IPA通常三个月，S Pass家属两个月。按IPA要求办理，须在IPA或当前准证到期之前完成，以先到的日期为准。续期成功的新有效期从当前准证结束时起算；EP尚余有效期最多六个月按MOM安排加到续期，不必为保留天数拖到最后申请。[EP批准后签发](https://www.mom.gov.sg/passes-and-permits/employment-pass/renew-a-pass)、[S Pass](https://www.mom.gov.sg/passes-and-permits/s-pass/renew-a-pass)、[家属](https://www.mom.gov.sg/passes-and-permits/dependants-pass/renew-a-pass)

产业WP若希望获发完整两年，护照一般须至少还有25个月有效期；保证金担保不足26个月也会限制准证期限。MDW的续期则 **不再与护照有效期挂钩** ，护照已过期或不足两年仍可按MOM条件续期；实际出行另须有效护照。MDW仍须满足适用保险、年龄及家有未完全接种幼儿时的麻疹免疫条件。[产业WP护照及期限](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-worker/renew-a-work-permit)、[MDW续期条件](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/renew-a-work-permit)

EntrePass续期须证明仍符合实际经营条件，准备近期ACRA商业资料、财务报表、公司银行记录、Startup SG Network（SSN）资料等，并按本次续期轮次检查Total Business Spending（业务总开支）及Local Workforce（本地雇用）要求。第一次续期与后续轮次条件不同；业务改变时还须提交更新计划。获续期IPA通常有效三个月，仍须在IPA或原准证先到期前完成签发。[EntrePass材料、不同轮次与完成手续](https://www.mom.gov.sg/passes-and-permits/entrepass/renew-a-pass)

ONE续期的收入路径目前要求过去五年在新加坡的平均固定月薪至少S$30,000；经营路径要求公司实际运作，并雇用至少五名本地员工，每人的gross monthly salary（税前月薪）达到当期EP最低门槛。提前六个月准备记录，再通过MOM的[ONE服务目录](https://www.mom.gov.sg/passes-and-permits/overseas-networks-expertise-pass/eservices-and-forms)或[准证查询入口](https://www.mom.gov.sg/contact-us)取得当次提交表件及签发指示；公开资格页未列出独立的完整续期操作流程。ONE家属可续期，但以ONE主准证成功续期为条件，有效期仍受主准证限制。[ONE续期条件](https://www.mom.gov.sg/passes-and-permits/overseas-networks-expertise-pass/eligibility)、[ONE DP](https://www.mom.gov.sg/passes-and-permits/overseas-networks-expertise-pass/passes-for-families/dependants-pass-for-overseas-networks-expertise-pass/key-facts)、[ONE LTVP](https://www.mom.gov.sg/passes-and-permits/overseas-networks-expertise-pass/passes-for-families/long-term-visit-pass-for-overseas-networks-expertise-pass/key-facts)

PEP家属办理续期时，也应先让MOM确认具体提交主体和方式：普通家属续期页未单列PEP持有人直接办理的流程，不能把个人EP eService的地址更新功能当作续期权限。PEP本身到期不能续，家属安排还须衔接主准证转换。[普通DP续期页](https://www.mom.gov.sg/passes-and-permits/dependants-pass/renew-a-pass)、[个人EP eService功能](https://www.mom.gov.sg/eservices/services/employment-pass-eservice)、[MOM联系](https://www.mom.gov.sg/contact-us)

完成续期后读通知信：若要求继续用旧卡，由本人保留；若要发新卡，按指示剪毁旧卡。WP或MDW不能在原期限前续期时，按续期页的短期延期入口提出请求；EP、S Pass或家属错过续期截止，需重新申请，申请或查询本身不延长合法停留。[EP旧卡处理](https://www.mom.gov.sg/passes-and-permits/employment-pass/renew-a-pass)、[WP短期延期入口](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-worker/renew-a-work-permit)、[MDW](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/renew-a-work-permit)

## 就业、家庭与身份变化

EP及S Pass换雇主，应由新雇主申请新的准证；续期用于继续为原雇主工作。工资降低时，相关MOM页面要求至少提前一个月提出，变更可能影响本人及家属资格；产业WP工资改变须先取得员工书面同意，再由雇主申报。[EP就业资料变化](https://www.mom.gov.sg/passes-and-permits/employment-pass/notify-mom-of-changes)、[S Pass](https://www.mom.gov.sg/passes-and-permits/s-pass/notify-mom-of-changes)、[WP薪资申报](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-worker/notify-mom-of-changes)

PEP持有人开始、结束工作或换雇主，须在 **一周内** 按指定表格通知MOM；每年还须按安排申报年薪，通常截止为1月31日。2025年或以后获发PEP者，MOM当前通知说明首次年度薪资申报在2027年办理；按当次通知确认期间。ONE Pass的年度通知由MOM向需要提交者发个人邮件。[PEP就业及年度薪资](https://www.mom.gov.sg/passes-and-permits/personalised-employment-pass/notify-mom-of-changes)、[ONE年度通知](https://www.mom.gov.sg/passes-and-permits/overseas-networks-expertise-pass/notify-mom)

主准证取消、停止就业或家庭关系改变时，逐一核对本人、配偶和子女的有效文件、取消要求及下一步停留安排，见[离职后的准证与家属衔接]({{< relref "/book/work/employment/leaving-job.md" >}})。获PR或公民批准后，按ICA及MOM结果通知确认原准证与新证件衔接，领取IC的流程见[ICA证件管理]({{< relref "/book/life/documents/arrival-renewal.md" >}})；相关NS与REP条件另见[国民服役]({{< relref "/book/life/documents/national-service.md" >}})及[PR与公民]({{< relref "/book/life/documents/permanent-residence.md" >}})。

## 不会线上办理、没有 Singpass 或查询不一致

雇主／EA以已获授权的Corppass及EP eService账号办理公司事务，个人入口提供护照及联系方式更新。PEP、ONE、EntrePass签发没有Singpass时，各自办理页提供预约EPSC的方式；MDW雇主首次申请没有Singpass，可按官方页填写申请文件并走指定线上表，EA不能使用这个替代渠道。[EP eService权限](https://www.mom.gov.sg/eservices/services/employment-pass-eservice)、[PEP签发替代](https://www.mom.gov.sg/passes-and-permits/personalised-employment-pass/apply-for-a-pass)、[MDW申请替代](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/apply-for-work-permit)

不擅长处理MDW线上事务的雇主，可按MOM要求用同意表授权一名符合条件的亲属，由对方用自己的Singpass处理获准的续期、短期延期及征费等事项；授权范围按服务页列出的交易判断。需要EA协助时也通过正式委任处理，保留申请回执和结果。[MDW授权家属及办理范围](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-domestic-worker/notify-mom-of-changes)

不用SGWorkPass App，也可在网页的 [Check work pass and application status](https://www.mom.gov.sg/eservices/services/check-work-pass-and-application-status) 查有效状态，无需登录。输入生日和FIN或护照号码，可查询当前准证及最近六个月内的申请；网页提供中文等五种语言，结果可保存或打印，附查询时间。护照号码对应多个FIN时，改用IPA上的FIN或向雇主／EA取得正确号码。发现薪资、职业或雇主资料不符，出发前先请雇主／EA更正，仍有问题向MOM提出。[查询范围、错误与打印](https://www.mom.gov.sg/eservices/services/check-work-pass-and-application-status)

办理受阻时，把准证类别、FIN、IPA及实际停留到期日、申请编号、错误时间和截图交给负责者核查；需要MOM人工帮助，可用[官方查询入口](https://www.mom.gov.sg/contact-us)，或周一至周五8:30—17:30致电 **6438 5122** ，公共假期休息。涉及本人拍照、指纹或文件验证的事项，先按该业务预约指定中心，并确认设备或材料困难怎样处理。
