在新加坡自己开车，先确认本人驾照是否有效、适用车型和是否需要转换，再决定租车或买车。持车还要安排保险、路税、停车和 ERP 支付；租车也须核准驾驶人及事故责任。准备把驾驶作为工作时，另查工作准证和职业执照要求。

## 境外驾照：先按居留和身份判断

SPF 对外国居民、公民及 PR 有不同安排。记录境外驾照首次签发、首次准证、取得 PR／公民身份的日期，再按下表选路。[SPF：驾照与外国驾照转换](https://www.police.gov.sg/Knowledge-Hub/Traffic/Traffic-Matters/Singapore-Driving-Licence)

| 本人情况 | 驾照安排 |
|---|---|
| 在新居住少于12个月的外国人，包括短访者、学生、工作或家属准证持有人 | 持有效境外驾照，并按 SPF 要求准备 IDP；不能取得 IDP 时用正式英文翻译。来自 ASEAN 成员国者免 IDP，仍须有效驾照 |
| 在新居住超过12个月的外国人 | 驾驶须有有效新加坡驾照；已有境外驾照者办理转换 |
| 新取得公民或 PR 身份，持有效境外驾照 | 取得该身份后最多可用境外驾照驾驶3个月；想继续驾驶须完成转换 |
| 已用 FIN 取得新加坡驾照，后来成为公民或 PR | 申请换证，把驾照资料更新为 NRIC |
| WP／S Pass 持有人要为工作驾驶 | 须在工作准证签发后6个月内取得新加坡驾照，且车型和职业另须符合要求 |

IDP 须由原籍国授权机构签发，并与有效境外驾照一起使用。访客需要的英文翻译，可按 SPF 所列使馆／高级专员署或新加坡注册翻译公司路线取得；转换申请的翻译材料另按下面的清单准备。

### 办理转换

先在驾驶中心登记并通过新加坡 Basic Theory Test（BTT，基本理论测试），再做 [Foreign Licence Pre-assessment](https://www.police.gov.sg/E-Services/Book-Appointment-to-Convert-Foreign-Driving-Licence)。合资格者收到预约链接后选时间；有预约才到 Traffic Police Headquarters，地址 **10 Ubi Avenue 3** 。Class 3／3A 和 Class 2B 转换须至少18岁，外国驾照须有效，未过期、暂停或撤销。

准备原件与复印件：

- 本人 NRIC／准证、护照，以及清单要求的首次入境或准证历史材料。
- 有效境外驾照；若未显示首次签发日期，取得发证机关的驾照记录。
- 非英文驾照按转换清单取得新加坡注册翻译公司的正式英文翻译。
- 近期白底彩色证件照，以及发证国家对应的认可或证明文件。

例如马来西亚驾照另须 JPJ 所列驾照类别及签发日期的信件和付款收据；印度驾照另列使馆有效性认可文件。按 [SPF 驾照页的国家清单](https://www.police.gov.sg/Knowledge-Hub/Traffic/Traffic-Matters/Singapore-Driving-Licence)逐项准备，不用其他国家的文件清单替代。

境外居住证明也有条件：PR 或准证持有人如果在取得 PR 身份或首个准证后才取得境外驾照，须证明在发照国的12个月期间内实际居住至少6个月；公民以境外驾照申请转换也须这类证明。保留相关护照、工作、教育及税务记录，按预评估要求补交。[转换资格与居住证明分支](https://www.police.gov.sg/E-Services/Book-Appointment-to-Convert-Foreign-Driving-Licence)

转换申请费为 **S$50** ，柜台按所列 NETS、借记卡、信用卡或 SGQR 方式付款。保存交易号和预约资料；预评估未通过、材料不明或遗失交易号时，用该页 SPF Feedback 询问。预约成功和完成 BTT 都不等于已取得可驾驶的新加坡驾照。[转换办理及费用](https://www.police.gov.sg/E-Services/Book-Appointment-to-Convert-Foreign-Driving-Licence)

## 为工作驾驶：车型、准证和职业执照都要符合

WP／S Pass 转换境外驾照，通常取得 Class 3C；Class 3C／3CA 限所列小型汽车，不能直接用来驾驶工作用轻型货车、厢式货车、皮卡或小巴。需要 Class 3／3A 时，还要通过实际驾驶测试。Class 3A 限无离合踏板车辆，挑车型时核对自己的驾照类别。[SPF：Class 3、3A、3C及工作驾驶](https://www.police.gov.sg/Knowledge-Hub/Traffic/Traffic-Matters/Singapore-Driving-Licence)

在准证允许的工作范围内，MOM 还要求：[工作准证持有人驾驶条件](https://www.mom.gov.sg/faq/work-pass-general/are-work-pass-holders-allowed-to-drive-on-public-roads-for-work)

| 准证／行业 | 工作驾驶的额外条件 |
|---|---|
| 建造、海事船厂、Process 行业 WP | 须是准证允许的驾驶相关职业，如 Worker-cum-Driver、Lorry Driver 等 |
| 制造业 WP | 工作需要，且符合准证上所列职业 |
| 服务业 WP | 按 Job Flexibility Scheme 使用，并遵守本人准证的特定限制 |
| S Pass | 工作需要，且符合 S Pass 上所列职业 |
| EP、EntrePass、ONE Pass、PEP、Tech.Pass | MOM 此表没有额外驾驶职业限制，仍须有效且获认可的驾照 |

NTS Occupation List 是另一个具体分支：清单上的重型车辆驾驶人须在2025年9月1日已有 Class 4／5，不能驾驶 Class 3 汽车或轻型货车。不能把服务业一般 Job Flexibility 安排套到这类准证上。[MOM：NTS 职业及车辆限制](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-worker/sector-specific-rules/non-traditional-sources-occupation-list)

Class 3C／3CA 持有人要学 Class 4／4P，须有雇主支持，并先通过指定 road assessment。评估不合格会撤销原 Class 3C／3CA，且一年内不能取得任何类别驾照；开始前让雇主和 SSDC 确认本人路线。[SPF 2026年3月 road assessment 说明](https://www.police.gov.sg/Media-Hub/News/2026/03/20260313_revised_test_fees_and_mandatory_road_assessment_for_class_3c_3ca_license)

驾驶出租车或私召车载客还须职业执照。新申请 TDVL 或 PDVL 的条件包括至少30岁、新加坡公民、有效新加坡 Class 3／3A 超过一年，以及英文、记录、医疗、培训测试和适用 MediSave 条件。[LTA：出租车及私召车职业执照](https://onemotoring.lta.gov.sg/content/onemotoring/home/driving/vocational_licence/vocational_licence_application.html)

私召巴士、校车或游览巴士的 BDVL 新申请要求至少21岁，身份可为公民、PR 或职业为巴士驾驶人的 WP，另须满足所列驾照、驾龄、记录及医疗等条件。WP 的海外驾龄证明可交 LTA 审核；公交 ODVL 另查对应条款。[LTA：BDVL 与其他职业执照分支](https://onemotoring.lta.gov.sg/content/onemotoring/home/driving/vocational_licence/vocational_licence_application.html)

家属、学生或访客要收报酬驾驶，先按[本人工作权限](/book/life/documents/work-passes/)核准；有驾照不会改变准证允许的工作范围。

## 第一次学车：报名、练习、考试、领证

普通汽车可选 Class 3 手动挡或 Class 3A 自动挡。至少18岁，先让驾驶中心核对本人证件、视力及适驾情况，再报名。SPF 列出 BBDC、CDC、SSDC 三家中心；可选学校课程，也可按 private learner 路线安排教练及中心测试账户。[BBDC 课程及证件要求](https://info.bbdc.sg/course/class-3-3a-driving-course/)，[CDC 学校课程](https://www.cdc.com.sg/course/class-33a/)，[CDC private learner 账户](https://www.cdc.com.sg/course/theory-test-btt-ftt/)

常见办理次序是：

1. 登记、做视力检查，准备并通过 BTT。
2. 申请 Provisional Driving Licence（PDL，学习驾照）。普通新学员上实际驾驶课前须有有效 PDL，数字 PDL 有效2年。
3. 按课程练习并通过 Final Theory Test（FTT）。普通新学员完成至少5次实际驾驶课后，安排3个模拟器模块；完成模拟器后须在2年内参加实际驾驶测试。
4. 达到中心的课程及预约要求后，参加 Traffic Police Practical Driving Test。
5. 合格后申请 Qualified Driving Licence（QDL，正式驾照），核对申请和驾照状态再驾驶。

PDL、模拟器及 QDL 的条件分别见 [PDL 详页](https://www.police.gov.sg/Knowledge-Hub/Traffic/Traffic-Matters/Provisional-Driving-Licence)、[模拟器训练](https://www.police.gov.sg/Knowledge-Hub/Traffic/Traffic-Matters/Simulator-Training-for-Learner-Motorists)和 [QDL 申请](https://www.police.gov.sg/E-Services/Apply-for-Qualified-Driving-Licence)。持有效 MOM 工作准证或 ICA Student／Long-Term Visit Pass 的合格考生，QDL 页明确列有 Singpass 网上申请路线；首次报名时带本人 FIN／准证，遇到账户或材料问题让中心及 Traffic Police 核对。

以下是2026年10月查阅的政府申请／测试费用， **不等于全部学车费用** ：

| 项目 | 当前金额 |
|---|---|
| PDL 新申请／续期 | S$25 |
| BTT／FTT | 各次 S$7.20 |
| 实际驾驶测试 | 各次 S$40 |
| 新 QDL 申请 | S$50 |

中心另有登记、课时、模拟器、行政费、考试用车及热身等费用。理论测试四语和课程语言也须分别核对，例如 BBDC 所列理论测试可选英文、中文、马来文、淡米尔文。不要把中心的平均课数当作保证获证次数；排期、取消、缺席和账户续期按所选中心处理。[BBDC 当期费用及语言](https://info.bbdc.sg/course/class-3-3a-driving-course/)，[PDL 申请费](https://www.police.gov.sg/E-Services/Apply-for-Provisional-Driving-Licence)，[QDL 申请费](https://www.police.gov.sg/E-Services/Apply-for-Qualified-Driving-Licence)

警方已公布下一阶段测试费：2027年3月13日起预约的理论测试 S$8、实操 S$45；2028年3月13日起预约的实操 S$50。看 **预约日期** ，而不是自行按考试当天日期套价。[SPF 测试费生效规则](https://www.police.gov.sg/Media-Hub/News/2026/03/20260313_revised_test_fees_and_mandatory_road_assessment_for_class_3c_3ca_license)

第一次取得普通汽车驾照后，试用期为一年，驾驶时按要求在车前后显示 P 牌。2026年现行试用期撤证门槛为13分；警方已宣布2027年1月1日起改为12分，非试用驾驶人的首次停牌门槛也由24个月24分改为18分，并有过渡扣分安排。查看官方记录和通知，不凭旧攻略计算还能违反几次规则。[SPF 基本理论教材，第5页](https://www.police.gov.sg/-/media/SPF/Knowledge-Hub/Traffic/BT-ENG-24126.pdf)，[2027年记分制度变更](https://www.police.gov.sg/Media-Hub/News/2026/07/20260731_tightening_of_the_driver_improvement_points)

## 续证、适驾与数字证件

外国准证持有人查看自己驾照的到期日；QDL 网上续期须持有效 MOM 工作准证或 ICA Student／Long-Term Visit Pass，并在到期前一个月内办理。不要把公民／PR 的长期驾照安排推给外国居民。[QDL 续期资格](https://www.police.gov.sg/E-Services/Apply-for-Qualified-Driving-Licence)

65岁及以上须按 Traffic Police 医检通知，经新加坡注册医生评估适驾；普通 Class 3 系列获适驾确认后通常每3年再检查。任何年龄若有影响驾驶的病况或身体障碍，也须取得适驾医学证明，可能另做职业治疗师及驾驶教练的评估。先与医生处理所需评估或车辆调整。[SPF 适驾及残障驾驶分支](https://www.police.gov.sg/Knowledge-Hub/Traffic/Traffic-Matters/Singapore-Driving-Licence)

Singpass 中的 Digital Driving Licence 可在本地核验，核验时打开真实应用；截图或录屏不能替代它。数字驾照需要网络，没有合适设备时保管好实体驾照；到海外驾驶仍带实体驾照，并查目的地 IDP 等要求。[数字与实体驾照 FAQ](https://www.police.gov.sg/Knowledge-Hub/Traffic/Traffic-Matters/Singapore-Driving-Licence)

## 租车、共享或借车：把驾驶人和责任写清

租车前告诉营运者自己的身份、年龄、驾照类别及驾龄，让其确认可接受的材料。商家的租用标准可能比道路驾驶资格更严；预约页面接受输入，也不代表柜台一定会交车。没有 App，可使用营运者的电话服务，例如 Avis Singapore 所列预约电话 **6737 1668** 。[Avis Singapore：材料与联系入口](https://www.avis.com.sg/Rent-a-Car)

签约前逐项确认，并保存合同及交车照片：

- 哪些人获准驾驶，增加同行驾驶人要怎样登记及收费。
- 租金、付款／担保、里程、燃料或电量、迟还及取消安排。
- 保险保障、自付额、年轻或新驾驶人附加条件，以及损坏、拖车和停驶费用。
- 能否去马来西亚，是否须书面同意、追加保险及跨境设备；核准后才安排出行。
- 事故或故障应立即打哪个电话，送哪个地点，交还时怎样确认损坏及款项。

借朋友的车，也让车主向保险公司确认你和用途在保障内。车主把私人汽车出租取报酬，须先向保险方申请合适保障；普通私人保单通常不承保这种租用。车辆改作私召或其他用途，须更新保险安排。[GIA：租借与用途限制](https://gia.org.sg/motor-insurance/23-faq-on-motor-insurance-issues.html)，[LTA：保险及车辆用途](https://onemotoring.lta.gov.sg/content/onemotoring/home/owning/ongoing-car-costs/insurance.html)

## 买车预算：先分清 COE、税费和剩余期限

COE（拥车证）让对应车辆在新加坡登记并使用，通常首次为10年。新车按相应类别取得 COE；个人投标须至少18岁，用本人身份和银行账户，外国人使用 FIN。让车商把是否包 COE、竞价不成功怎么办、最终车价及交车期限写入合同。[OneMotoring：COE、类别与竞价](https://onemotoring.lta.gov.sg/content/onemotoring/home/buying/upfront-vehicle-costs/certificate-of-entitlement--coe-.html)

目前普通汽车分 A、B 类，另有适用的 E 类。2026年10月8日启动的 A／B 合并及新费用抵减方案仍为公众咨询，咨询至11月2日；不能按提案假定自己已适用合并后的类别或价格。[LTA 当期 COE 咨询说明](https://www.lta.gov.sg/content/ltagov/en/newsroom/2026/10/news-releases/launch-of-public-consultation-on-coe-categorisation-for-cars.html)

签约前把报价拆开，再估每月实际支出：

| 项目 | 要核对什么 |
|---|---|
| 车辆与注册 | OMV、车价、COE、RF、ARF、消费税、适用排放抵减／附加和报价所含税费 |
| 资金安排 | 首付款、借款利率、手续费、每期偿还及提前还款条款 |
| 每年／每月持车 | 保险、路税、验车、住宅及工作地点停车 |
| 每次出行与保养 | ERP、短时停车、油／电、维修、轮胎和故障拖车 |
| 停止持车 | 剩余 COE、PARF 资格、出售或注销处置及相应费用 |

普通汽车当前 RF 为 S$350；ARF 按 OMV 及适用批次分档，不是一个全车统一百分比。纯电车路税还有 Additional Flat Component；其 EEAI 在2026年末终止，不能把2026优惠直接用来预算2027登记的新车。按具体车型、登记日期与 COE 批次核报价。[OneMotoring：汽车税费结构](https://onemotoring.lta.gov.sg/content/onemotoring/home/buying/upfront-vehicle-costs/tax-structure.html)

PARF 是合资格汽车注销时按年龄和实际支付 ARF 计算的退还安排。2026年2月第二次 COE 竞价起的新批次，退还上限为 S$30,000，5年以内为实际 ARF 的30%，超过9年但不超过10年为5%；旧批次有不同百分比及上限。超过10年没有 PARF。买二手车先查这辆车的资格，不能把旧车的退还比例当作新车将来一定取得的金额。[PARF 三批次明细](https://onemotoring.lta.gov.sg/content/onemotoring/home/buying/upfront-vehicle-costs/tax-structure.html)

普通汽车 COE 到期可按条件注销或续5／10年，续期按当期 PQP；汽车选择5年续期只能一次，期满不能再续。买已有续期的二手车，把“还能用多久”和日后可否再续写进自己的持车计划。[COE 续期与5年限制](https://onemotoring.lta.gov.sg/content/onemotoring/home/owning/coe-renewal.html)

## 二手车交接：核车、付费、接受转移

核对实车车牌、车型、发动机及车架编号与 LTA 记录，查 COE 到期、PARF、路税和改装情况，必要时做独立车辆评估。请现车主按 OneMotoring 的 Access Code 方法提供可查资料，不要取得或借用其 Singpass。车价、订金、交付、保修、保险和融资承诺都写进协议；向私人车主或寄售卖方买车的保障与向车商买不同。[LTA 二手车检查与交易说明](https://onemotoring.lta.gov.sg/content/onemotoring/home/selling-deregistering/transfer-ownership.html)

车辆转移须在7日内完成，须解决未清融资、欠路税等事项。买方先取得本人名下、覆盖全部有效路税期间的保险；卖方本人发起、买方本人确认。成功后在 OneMotoring dashboard 核对已登记在自己名下，并保存双方收到的通知。A／B 类新登记车辆还有可转移时间及部分批次额外 levy，近期新车尤其要查。[车辆转移条件与确认](https://onemotoring.lta.gov.sg/content/onemotoring/home/selling-deregistering/transfer-ownership.html)

不符合 Singpass 资格的外国车主，按 LTA 所列路线预约到 Customer Service Centre；双方到场，带 M01、身份证明、新车主保险及适用检验证明。该分支转移费 S$25，按 NETS 或 SGQR PayNow 付款；额外 levy 另算。遇到网上不能确认的交易，先查是哪项条件未满足，未确认成功前不只凭交钥匙认定已经转移。[无 Singpass 资格的外国车主](https://onemotoring.lta.gov.sg/content/onemotoring/home/selling-deregistering/transfer-ownership.html)

## 路税、保险与验车

普通汽车路税可按6或12个月续。至少在付款前一个工作日办齐全期保险、到期所需验车及清罚款；新车或二手车交付时，先查报价有没有包含路税及实际到期日。路税过期后，续办并确认生效再上路。10年以上车辆的路税附加逐年增加，最高为原路税的50%。[路税条件、金额查询及车龄附加](https://onemotoring.lta.gov.sg/content/onemotoring/home/owning/ongoing-car-costs/road-tax.html)

可以经 OneMotoring、AXS、GIRO 或授权收款处付款；检验中心自2025年2月起不收现金、支票或 cashier's order 办路税。付款失败时保留记录，查保险／验车资料是否已更新及银行卡限额，再按对应渠道处理；保存收据并重新核对有效期。[路税付款与先决事项](https://onemotoring.lta.gov.sg/content/onemotoring/home/owning/ongoing-car-costs/road-tax.html)

车辆上路须有有效汽车保险，最低保障是第三者死亡及身体伤害责任；这不等于自己的车辆损坏、其他财物损失或所有租借用途都受保。比较保单时，核驾驶人、用途、地域、自付额、无索赔折扣、指定维修厂及事故报告要求。车辆用途或改装改变，及时告知保险方。[LTA 汽车保险](https://onemotoring.lta.gov.sg/content/onemotoring/home/owning/ongoing-car-costs/insurance.html)，[GIA 保障与索赔 FAQ](https://gia.org.sg/motor-insurance/23-faq-on-motor-insurance-issues.html)

## ERP 与停车：出发前确认支付

ERP 按车型、地点和进入时间收费，费用会调整。检查路线当期 ERP、车上的 IU／OBU、卡是否插妥及余额；自动充值或后台付款服务须先完成自己的安排。[当前 ERP 收费与付款](https://onemotoring.lta.gov.sg/content/onemotoring/home/driving/ERP/ERP.html)

OBU 使用合资格 CEPAS 卡，不能用旧款有芯片的普通 CashCard；不是所有停车场都支持后台付款，仍应备可用卡。没有 App，可以使用所装显示屏和卡；设备故障找授权安装或检查中心。需要协助可用 LTA 所列电话 **6377 2255** ，按其服务时间联系。[ERP 2.0 支付、设备与协助](https://onemotoring.lta.gov.sg/content/onemotoring/home/driving/ERP/erp-2-0.html)

漏付 ERP 时，经 OneMotoring 的 Pay LTA Fines and ERP Charges 或 AXS 查缴。当前已有从 LTA 短信发送日起5日宽限，期内补缴不加 S$10 行政费；过期会另发通知并加行政费。[当前漏付处理](https://onemotoring.lta.gov.sg/content/onemotoring/home/driving/ERP/ERP.html)

另一个未来日期是 **2027年1月1日** ：普通新加坡注册上路汽车须安装 OBU；特殊车辆豁免另列。按本人安装通知的免费窗口预约授权中心，过期会有费用。2027年起漏付由车主承担，超过通知宽限仍未清，会限制路税续期、车辆转移等 LTA 交易。安装 OBU 本身没有让现行收费变为按行驶里程收费。[ERP2 当期 FAQ](https://onemotoring.lta.gov.sg/content/onemotoring/home/driving/ERP/erp-2-0.html)，[2027年过渡公告](https://www.lta.gov.sg/content/ltagov/en/newsroom/2026/2/news-releases/amendments-rta-facilitate-erp2-transition-enhance-penalties.html)

停车先看入口牌示的收费、时间、车辆和预留车位限制。URA／HDB 的 coupon car park 可用 Parking.sg 或有效纸券；有些每半小时 S$0.60 或 S$1.20，允许夜停的所列夜券为 S$5、适用22:30至次日07:00。无手机者可按 URA 当前清单到所列 SPC 油站买纸券，按停放时间正确使用。[URA：票券、收费及购买地点](https://www.ura.gov.sg/car-parks/short-term-parking/parking-coupons/)

长期停车须按具体车场申请。URA 季票数量有限，部分只向特定楼宇住户／租户提供；无票时按候补或短时停车安排。住 HDB 可从 [HDB 季票申请入口](https://www.hdb.gov.sg/parking/applying-for-season-parking/apply-for-season-parking)核自己的住址、租住及车辆情况、月费与名额；公寓则向管理处确认停车权、车牌登记和收费。买车前先落实家和工作地点的停车安排。[URA 住宅季票条件](https://www.ura.gov.sg/eservices-info/carparks/residentialtnc/)

## 上路安全与事故报告

靠左行驶，按标志、路面和雨天视线调整速度；变线及转弯前看镜、盲点并打灯。前后乘客扣好安全带，低于1.35米者按要求使用认可约束装置。行车时不要手持操作通讯设备，需要操作先到安全地点停车。儿童、轮椅或行李安排也应在出发前处理好。[SPF 基本理论教材](https://www.police.gov.sg/-/media/SPF/Knowledge-Hub/Traffic/BT-ENG-24126.pdf)

发生事故先处理即时危险和伤者，按[紧急求助](/book/rights/safety/emergencies/)联系警方或救护。确保安全后记录时间地点、车牌、双方及证人资料，拍现场与损坏；对方不肯配合，也记车牌并把情况交保险方。联系自己的保险／租车事故热线，按指示拖车及送到认可报告中心，谨慎处理现场陌生拖车或维修人员要求签署的文件。[GIA 事故及维修安排](https://gia.org.sg/motor-insurance/22-premium-renewal-of-policy.html)

**所有事故都须按 Motor Claims Framework 向保险方报告** ，包括轻微、没有明显损坏、已私下和解及租车事故。通常须在24小时内或下一个工作日完成，并把车带到认可报告中心；租车不要等还车才告知公司。受伤或境外严重事故确实无法按时完成，立即联系保险方说明原因、保留证明。[GIA Motor Claims Framework](https://gia.org.sg/motor-insurance/22-premium-renewal-of-policy/348-motor-claims-framework.html)

警方报告是另一个程序。SPF 要求下列事故向警方报告：[须报 Traffic Police 的事故](https://www.police.gov.sg/Knowledge-Hub/Traffic/Traffic-Matters/Reporting-Traffic-Accidents-and-Offences)

- 有人死亡。
- 有人在现场由救护车送院，或受伤取得至少3天门诊病假。
- 损坏政府财产。
- 涉及外国车辆。
- 涉及行人或骑行者。
- 肇事逃逸。

有 Singpass 和邮箱可网上报；也可到警署，无 Singpass 的外国人带护照按警方所列自助机／警署路线办理。属于须报的情况就及时办理，警方报告和保险报告各存自己的编号及副本。[SPF 报告入口](https://www.police.gov.sg/E-Services/Lodge-Traffic-Accident-Report)

使用 GEARS Myinfo 网上先发事故通知，仍要让 Accident Reporting Centre 完成并提交最终报告；收到先行通知编号不等于已完成 MCF。保存最终报告、警方报告、照片、维修估价、发票和保险回复，后续询问附上相应编号。索赔意见不一致先找保险方按保单及证据说明，必要时按 GIA 所指的 FIDReC 入口处理。[GEARS 与完整报告的区别](https://gia.org.sg/motor-insurance/22-premium-renewal-of-policy.html)，[GIA 索赔争议入口](https://gia.org.sg/motor-insurance/23-faq-on-motor-insurance-issues.html)
