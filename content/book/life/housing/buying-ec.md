买 Executive Condominium（EC，执行共管公寓），先分清向开发商买新单位还是向业主买转售，再确认项目的土地招标截止日期。2026年5月和8月的两次调整分别改变居住年限、付款与首次购房优先安排，以及新售收入上限；买房日期、推出日期和项目取得临时入伙准证（TOP）的日期不能代替这两个政策分界。[EC制度调整](https://www.mnd.gov.sg/newsroom/press-releases/view/strengthening-the-executive-condominium-housing-scheme-and-supporting-first-time-home-buyers)、[收入调整](https://www.mnd.gov.sg/newsroom/press-releases/view/increase-in-income-ceilings-and-greater-support-for-families-with-children)

## 先认清交易类型与项目

EC 是私人开发商建设和销售的分层产权住宅，初期有收入、购买资格及持有条件，并非所有阶段都按一般私人公寓出售。看房时记下项目正式名称、地段、开发商、单位编号、土地招标截止日、推出日期、预计交付及已获批许可；要求对方把用于判断批次的文件和条件一并提供。[EC性质与原有限制](https://www.mnd.gov.sg/newsroom/press-releases/view/strengthening-the-executive-condominium-housing-scheme-and-supporting-first-time-home-buyers)

| 所看单位 | 付款前要取得的确认 |
| --- | --- |
| 开发商的新单位，包括未售余额 | 本家庭的新售计划与资格、适用收入门槛、首次／再次购房类别、付款表和已有住房处理条件 |
| 尚有国籍限制的转售单位 | 卖方已满足转售所需的最低居住期（MOP）、此项目只可售给哪些身份，以及本交易的买方条件 |
| 已达到向任何买家开放阶段的单位 | 该单位实际已到适用开放日期；产权、贷款、税、公积金（CPF）及本人的居留另核 |

请让承办律师按该单位的正式文件核限制，不能只听“已经私有化”“今年的新EC”或广告中的年份。EC 的新售审核与组屋购买资格信（HFE）是不同办理对象；手里的组屋资格或银行预批，不能代替开发商与主管对这次 EC 交易的确认。

## 六类身份怎样确认家庭资格

先列出所有拟列入申请的人：国籍、年龄、婚姻及亲属关系、所持准证、收入和就业、已有或曾有的本地／海外住宅、既往购买受补贴住房及领取补助的记录。请开发商说明各人的业主／必需居住成员角色、采用的家庭计划，以及哪些资料仍须送主管判断。

| 身份与家庭情况 | 具体要问的事 |
| --- | --- |
| 公民家庭 | 哪个家庭计划适用，成员国籍和年龄是否齐全，婚姻或未婚夫妇文件须何时提交；首次购房优先不等于全部资格已过 |
| 公民与永久居民（PR）家庭／全PR家庭 | 新售和限制期内转售各允许什么家庭组合；不要把转售可售给PR的规定当成全PR家庭可买开发商新单位的批准 |
| 持工作准证的成员 | 能否列入该计划、所需准证类别和剩余有效期、是否可作业主或必需成员；就业或缴税不代替购房条件 |
| 学生 | 单独或与家庭申请时适用什么计划、年龄及关系要求；学生准证与延后收入评估安排须分别确认 |
| 家属或非公民配偶 | 按实际签发机构、准证类型、关系和期限核，问清变动或续期对资格的影响；不能只报“家属准证” |
| 访客或居住海外者 | 核能否参与该家庭申请、签名与文件安排；作为外国买家看转售者另须确认单位已进入开放阶段 |

联合单身、丧偶、孤儿、离婚携子女、跨国婚姻或需变更申请成员者，应带实际关系和证明，要求写明适用计划、年龄及签署手续。EC 收入表列有合资格联合单身计划（JSS），但这张金额表不说明该计划的全部成员条件，不能据此推定一个单身申请人已经获准。[EC收入表与JSS标注，第1页](https://www.hdb.gov.sg/-/media/hdb-pulse/news/2026/increase-in-income-ceilings-and-greater-support-for-families-with-children/Annex-A.pdf#page=1)

## 两个土地招标日期分别管什么

2026年5月8日或以后截止招标的 EC 政府售地项目，适用加长 MOP、取消延后付款方案和提高首次购房者保留份额三项措施。2026年8月24日或以后截止招标的新 EC 单位，才适用提高后的S$18,000月家庭收入上限。后一变化不普遍覆盖旧项目未售余额，也不按买家何时预约来判断。[5月措施及批次](https://www.mnd.gov.sg/newsroom/press-releases/view/strengthening-the-executive-condominium-housing-scheme-and-supporting-first-time-home-buyers)、[8月措施及旧余额范围](https://www.mnd.gov.sg/newsroom/press-releases/view/increase-in-income-ceilings-and-greater-support-for-families-with-children)

| EC土地招标截止日期 | MOP及向任何买家出售的年限 | 开发商新售的月家庭收入门槛 |
| --- | --- | --- |
| 2026年5月8日前 | 原有5年MOP／第10年后向任何买家开放 | 原有S$16,000 |
| 2026年5月8日起、8月24日前 | 新10年MOP／第15年后向任何买家开放 | 仍为S$16,000 |
| 2026年8月24日起 | 新10年MOP／第15年后向任何买家开放 | S$18,000 |

表中年数不能直接加在预约买房或收到钥匙的日期上。应让建屋发展局（HDB）／开发商按该项目写明 MOP 及向任何买家开放年限的起算点、实际届满日期、影响计算的期间及限制；TOP 是临时入伙许可，但不能只凭新闻稿里延后付款提到 TOP，就认定所有年限都从那个日期算。

教学虚构：甲项目招标于2026年5月7日截止，乙于6月1日截止，丙于9月1日截止。甲落在5／10年及S$16,000批次；乙已落在10／15年批次，但仍为S$16,000；丙为10／15年及S$18,000。这只是政策分界练习，不是实际项目，亦未假定三者的居住期起算日。

扩大家庭在某些 HDB 项目可用的S$24,000门槛不自动用于新 EC；EC 所列修订门槛仍是S$18,000。请分别核用于 EC 的家庭收入期间、须计算的人、奖金与自雇收入、申请到交付间重新核定的安排；贷款审批又有自己的偿付能力评估。[分类表及适用脚注，第1页](https://www.hdb.gov.sg/-/media/hdb-pulse/news/2026/increase-in-income-ceilings-and-greater-support-for-families-with-children/Annex-A.pdf#page=1)

## 首次购房者优先与补贴记录

适用5月新措施的项目，首次购房者保留份额由70%提高到90%，优先期由项目推出后的第一个月延长到两年。开发商须据此安排销售，个人仍须通过相应购房资格，并按实际可售单位、申请与分配程序选择。[首次购房份额与优先期](https://www.mnd.gov.sg/newsroom/press-releases/view/strengthening-the-executive-condominium-housing-scheme-and-supporting-first-time-home-buyers)

整理自己及家庭过去从 HDB 或开发商买过的住房、补助、出售和退款记录，请主管／开发商确定首次或再次购房类别、受补贴住房次数、是否须付 resale levy（转售征费）、金额及付款时间。不要把“第一次买EC”当作首次享用住房补贴。

如开发商说可获购房补助，要求列明补助名称、家庭与收入条件、实批金额、何时可用于这次房款，以及资格变化后的处理。组屋新房或转售的购房补助条件须分别核，不直接照搬到EC；核预算时只计已经确认且届时可以使用的份额。

## 已有住房与私人住宅怎么办

现有或前私宅业主从开发商买 EC，私人住宅处置后30个月等候期仍保留。2026年7月取消15个月的措施只针对不用 HDB 贷款的不受补贴转售组屋，不是新 EC 的豁免；本地与海外住房都应如实列入供核。[仍适用于开发商EC的等候期](https://www.mnd.gov.sg/newsroom/press-releases/view/removal-of-the-15-month-wait-out-period-for-private-residential-property-owners-purchasing-non-subsidised-hdb-resale-flats)

已有组屋或另一处住宅时，先问是否可以申请、旧房是否已满足自身 MOP、何时必须处置、谁须退出产权，以及新旧贷款和CPF退款怎样衔接。具体截止时间要按本交易的资格与文件核，不把“转售组屋完成后6个月处置私宅”的规则套成所有 EC 换房期限。

准备过渡租住、孩子上学、照护和搬家计划；把“旧房卖出后才能动用的资金”与现在可付的款分开。如出售延期会影响付款或资格，尽早把两笔交易的正式日期交律师及贷款机构，确认仍能履行的安排。[换房资金与税务](/book/life/housing/purchase-costs/)

## 新售付款：按工程节点准备资金

适用5月新批次的未完工 EC，开发商不能再提供 Deferred Payment Scheme（DPS，延后付款方案），改按 Normal Payment Scheme（正常付款方案）的工程节点逐步支付。旧 DPS 的说明是先付20%、余下80%延到 TOP，通常另有价格溢价；这段历史描述不保证旧项目现在仍有该方案。[DPS取消与正常分期](https://www.mnd.gov.sg/newsroom/press-releases/view/strengthening-the-executive-condominium-housing-scheme-and-supporting-first-time-home-buyers)

拿到本单位完整付款表后，逐项列金额、截止日、通知方式及可用现金／CPF／贷款。申请、选房、取得选择权、行使、签买卖协议、各工程节点及交付时分别要付什么，问清后交律师核。

银行估值、批准额度、利率、按进度放款和审批有效期应与付款表配合，先确认正式贷款要约能否覆盖各节点。把印花税、法律费、装修及交付后的管理费留在房价之外；CPF可用金额、按国籍或共同买家计算的税款及融资限制，接[购房成本与贷款](/book/life/housing/purchase-costs/)核清。

教学虚构：某单位总房价S$1,500,000，实际已获批贷款S$950,000，确认可付房款的CPF为S$200,000，则总房款现金缺口为1,500,000−950,000−200,000＝S$350,000，税费另计。这个数不代表所有款都到交屋才付；正常付款方案下，要按每个工程节点另列当时可用的资金。

## 预约、签约与交付要保存什么

签名前核开发商、项目及收款账户，确认写进合同的是实际单位、面积和用途、配件、总价与优惠条件、预计及最终交付安排。把申请资格、主管答复和关键承诺保留为可核的文字，不用广告或销售聊天取代完整附件。[签约前的主体与条款核对](/book/rights/contracts/before-signing/)

| 阶段 | 保存与核对 |
| --- | --- |
| 提交家庭资料 | 成员与关系证明、收入和产权声明、补助记录，提交日期及需补文件；准证续期或成员变动及时通知 |
| 预约或取得购房选择权 | 单位、价格、实付费用、退款条件、选择权期限与实际付款回执；不沿用另一类住房的默认期限 |
| 行使及签约 | 完整买卖协议、附件与改动、资格确认、贷款及CPF安排，双方签署版和律师意见 |
| 工程分期 | 每份正式付款通知、阶段和截止日、银行放款及到账回执，异常金额先核出处 |
| 交付和入住 | 交付通知、余款、钥匙、设备及缺陷记录、保修申请方式与实际期限、管理费和维修责任 |

需要语言、无障碍或海外签署安排时，提前问销售方及律师怎样完成本人认证、文件翻译或授权。家属协助整理资料不等于可以代签；按确认的本人认证或授权路线完成签署。

工程进度、交付、配件或缺陷与合同不符时，保留原版本、通知和有日期的照片，书面列出问题、希望对方说明或修复的事项，并核相关期限。具体保修和迟交救济按本合同与适用规则处理，接[履约、交付与变更](/book/rights/contracts/performance/)及[房屋维修与责任](/book/life/household/home-maintenance/)继续。

## 入住后：MOP、出租与另一处住宅

原批次须先完成5年MOP才可在公开市场卖给公民或PR，第10年后才可卖给任何买家，包括外国人和公司。新批次须完成10年MOP，之后才可整套出租、购买另一处住宅或卖给公民／PR；第15年后才可卖给任何买家。两种批次在MOP内都不能出租整套或购买另一处住宅。[持有、出租及出售限制](https://www.mnd.gov.sg/newsroom/press-releases/view/strengthening-the-executive-condominium-housing-scheme-and-supporting-first-time-home-buyers)

要出租房间、因工作离境、增加或删除业主／成员、离婚或处理遗产时，先问 HDB 与承办律师这种变动会怎样影响 MOP、实际居住、产权或补助，不把允许出租整套后的规则套在MOP内。把入住与离开日期、关系变化和正式通知留存，出售前取得这个单位实际可售日期与买方范围的确认。

管理费、设施规则、装修许可与房内／公共部位维修应看本项目文件和责任分工。用电、漏水、火险及个人家居保险也要按自己单位安排。[维修与通知入口](/book/life/household/home-maintenance/)、[保险范围与理赔](/book/work/finance/insurance/)

## 买EC转售与外国买家

买转售时，要求卖方提供项目批次、产权和已经满足限制的证据，再由律师核这次买方能否受让。年限仍有限制时，国家发展部（MND）的公告说明只开放公民／PR；到适用的第10或15年后才开放任何买家。不要把项目已有一位外国住客、外国配偶或公司租户当成整套已可卖给外国人的证明。[按年限开放的买方范围](https://www.mnd.gov.sg/newsroom/press-releases/view/strengthening-the-executive-condominium-housing-scheme-and-supporting-first-time-home-buyers)

工作、学生、家属准证持有人和访客作为外国买家看已开放转售，仍须分别核产权和共同买家、贷款／CPF、额外买方印花税及自身居留。买到住宅不会代替工作或居留准证；交易准备接[私人住宅的购房核对](/book/life/housing/buying-private/)与[身份、资金及税](/book/life/housing/purchase-costs/)。

转售价格、估值、选择权、付款与完成日期按该笔EC买卖的完整文件和贷款安排确定。取得本交易的完整文件和承办律师说明后，再办理各阶段手续。

## 被拒、成员变化或想退出时

资格被拒或销售方说可以豁免时，要求写清受限制的是哪个成员、何种家庭计划、哪段产权或补贴记录、哪次收入期间，以及由谁作最终判断。把自己的事实与证明一并交主管／开发商，问可否补件或更正、时限及已有预约如何处理；未经确认前不把销售人员的口头意见当成豁免。

失业、结婚或离婚、准证／国籍改变、怀孕或家庭成员退出，都可能使原申请资料和资金计划改变。立即向开发商、HDB及律师说明日期和阶段，问清原资格、补助、贷款与合同怎样继续；未获明确回复前，不通过隐瞒成员变动维持旧申请。

要撤回预约、放弃选择权或终止已签买卖时，先让律师按当前阶段列明哪些费用不退、有哪些已到期款项和赔偿、补助是否须退还，以及对日后购房的影响。

付款争议、拖延或资格复核受阻，保留申请编号、书面决定、合同、账单与日期，资格或项目限制可从[AskHDB公开问题入口](https://ask.gov.sg/hdb/questions/new)说明项目、编号、阶段和具体问题，请HDB确认主管及所需文件；合同付款先书面通知开发商并交律师核下一步，不将停付全部款项当作默认解决办法。[履约与求助](/book/rights/contracts/performance/)
